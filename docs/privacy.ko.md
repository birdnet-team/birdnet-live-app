# BirdNET Live 개인정보 처리방침

**최종 업데이트:** 2026년 8월 6일

본 개인정보 처리방침은 **BirdNET Live**(이하 "**앱**")에 적용됩니다. 이 앱은 **BirdNET-Team**(이하 "**개발자**" 또는 "**저희**")이 개발하여 제공합니다.

## 앱 및 개발자 정보

| | |
|---|---|
| **앱 이름** | BirdNET Live |
| **개발자 이름** | BirdNET-Team |
| **개인정보 문의** | [ccb-birdnet@cornell.edu](mailto:ccb-birdnet@cornell.edu) |

본 방침은 BirdNET-Team이 자체 명의로 제공하며, BirdNET Live가 개인정보를 어떻게 보호하고 처리하는지 설명합니다.

## 기기 내 처리

모든 오디오 분석과 조류 종 동정은 **전적으로 사용자의 기기에서** 이루어집니다. 앱은 로컬에서 실행되는 두 가지 신경망 모델을 사용합니다:

- **BirdNET+ 오디오 분류기** — 마이크 오디오를 분석하여 조류 종을 동정합니다.
- **BirdNET 지리 모델** — 사용자의 위치와 시기에 출현할 가능성이 높은 종을 예측합니다.

오디오 데이터는 어떠한 경우에도 외부 서버로 전송되지 않습니다.

## 개인정보 처리

BirdNET-Team은 앱 백엔드를 운영하지 **않으며**, BirdNET Live를 통해 사용자의 녹음, 위치, Session 데이터 또는 기타 개인정보를 수신하지 않습니다. 앱에는 사용자 계정, 광고, 분석, 추적, 원격 측정 기능이 없습니다. 다만 앱은 사용자의 기기에서 오디오와 위치를 처리하며, 사용자가 선택적 네트워크 기능을 켠 경우에만 **외부 리소스** 항목에 설명된 정보를 명시된 제3자 제공업체에 직접 전송합니다.

### 기기에 로컬로 저장되는 데이터:

| 데이터 유형 | 용도 | 저장 위치 |
|-----------|---------|---------|
| 오디오 녹음 | 조류 동정, 재생, 내보내기 | 로컬 파일 |
| 감지 결과 | 종, 신뢰도, 타임스탬프 | 로컬 JSON Session 파일 |
| GPS 좌표 | 감지 위치 태깅, Survey 경로, 지리 모델 예측 | 로컬 JSON Session 파일 |
| Session 메타데이터 | Session 기록, 검토, 내보내기 | 로컬 JSON Session 파일 |
| 날씨 스냅샷(선택) | **날씨 조회 허용**이 켜져 있을 때 Session마다 한 번 기록되는 기온, 강수, 풍속, 운량, 날씨 코드 | 로컬 JSON Session 파일 |
| 앱 설정 | 사용자 환경 설정 | SharedPreferences |

### 번들로 제공되는 오프라인 데이터

종 이미지, 설명, 분류 데이터는 **앱에 내장되어** 로컬 에셋에서 불러옵니다. 종 정보를 가져오기 위한 네트워크 요청은 발생하지 않습니다.

## 외부 리소스

앱은 다음 외부 리소스에 접근할 수 있습니다. 각 리소스는 **설정 → 개인정보**의 독립적인 토글로 제어되며, 새로 설치한 상태에서는 **세 가지 모두 기본적으로 꺼져 있습니다**. 사용자가 직접 켜기 전까지는 어떤 데이터도 기기를 벗어나지 않습니다.

| 리소스 | 용도 | 제어 설정 | 요청마다 전송되는 정보 |
|----------|---------|----------|----------------------|
| 지도 타일(OpenStreetMap Foundation) | 위치 선택기, Survey 실시간 지도, Session 지도의 배경 지도 | **설정 → 개인정보 → 지도 타일 허용** | 타일 좌표 `(z, x, y)`, 네트워크 연결 과정에서 노출되는 사용자의 IP 주소, BirdNET Live user-agent 문자열 |
| 역지오코딩(OpenStreetMap Foundation Nominatim) | Session 표시를 위해 GPS 좌표를 읽기 쉬운 장소명(예: "독일 베를린")으로 변환 | **설정 → 개인정보 → 장소명 조회 허용** | 해당 Session의 위도/경도, 네트워크 연결 과정에서 노출되는 사용자의 IP 주소, BirdNET Live user-agent 문자열 |
| 날씨 스냅샷(OpenMeteo GmbH) | 녹음 좌표와 종료 시각의 현지 기상 상태(기온, 강수, 풍속, 운량, WMO 날씨 코드)를 한 번 기록 | **설정 → 개인정보 → 날씨 조회 허용** | 해당 Session의 위도/경도와 종료 타임스탬프, 네트워크 연결 과정에서 노출되는 사용자의 IP 주소, BirdNET Live user-agent 문자열 |

지도 타일 요청은 `tile.openstreetmap.org`로 보내는 HTTPS GET 요청입니다. 타일 좌표는 사용자가 보고 있는 지도 영역을 나타냅니다. 다른 모든 직접 인터넷 요청과 마찬가지로, 이 요청도 서비스 제공업체에 사용자의 IP 주소를 노출합니다.

역지오코딩 요청은 해당 Session의 위도와 경도를 HTTPS를 통해 `nominatim.openstreetmap.org`로 전송하며, [Nominatim 사용 정책](https://operations.osmfoundation.org/policies/nominatim/)의 요구에 따라 BirdNET Live user-agent 문자열을 함께 보냅니다. 변환된 장소명은 Session과 함께 로컬에 저장되므로 각 Session은 한 번만 지오코딩됩니다. Session에 GPS 좌표가 없거나 기기가 오프라인이면 요청이 발생하지 않습니다.

날씨 요청은 해당 Session의 위도/경도와 종료 타임스탬프를 HTTPS를 통해 `api.open-meteo.com`으로 전송하며, BirdNET Live user-agent 문자열을 함께 보냅니다. [Open-Meteo](https://open-meteo.com/)는 무료 서비스로, 계정이나 API 키가 필요하지 않습니다. 반환된 날씨 스냅샷은 Session과 함께 로컬에 저장되며, JSON 내보내기 파일, Session별 `metadata.json` 블록, HTML 보고서에도 기록됩니다.

**제3자 처리 및 보관:** BirdNET-Team은 이러한 서비스를 운영하지 않으며 요청 데이터를 수신하지 않습니다. OpenStreetMap Foundation은 자체 [개인정보 처리방침](https://osmfoundation.org/wiki/Privacy_Policy)에 따라 네트워크 접속 데이터와 요청 세부 정보를 처리할 수 있습니다. Open-Meteo는 무료 API 웹 서버 로그에 IP 주소와 지리 좌표가 포함될 수 있으며 90일 후 삭제된다고 명시하고 있습니다. 자세한 내용은 [약관 및 개인정보 보호](https://open-meteo.com/en/terms)를 참조하세요. 이러한 제공업체는 사용자가 거주하는 국가 외의 국가에서 데이터를 처리할 수 있습니다. 반환된 값(장소명과 날씨 스냅샷)은 기기의 로컬 Session 기록에 저장되며, 사용자가 내보내기를 생성할 때만 내보내기 파일에 포함됩니다.

**철회:** 세 가지 서비스는 **설정 → 개인정보**에서 언제든지 끌 수 있습니다. 이미 로컬에 저장된 장소명과 날씨 스냅샷은 수집된 Session에 그대로 남아 있습니다. 이러한 과거 데이터를 삭제하려면 Session 목록에서 해당 Session을 삭제하거나 **설정 → 위험 구역 → 모든 데이터 삭제**를 사용하세요.

**앱 자체에서 시작하는 다른 네트워크 요청은 없습니다.** 앱은 완전히 오프라인으로 작동합니다. 이와 별도로, 외부 링크와 내보낸 HTML 보고서 등 사용자가 의도적으로 브라우저에서 여는 콘텐츠는 아래 설명과 같이 브라우저 요청을 발생시킬 수 있습니다.

## 외부 링크

BirdNET Live에는 사용자가 선택하여 열 수 있는 제3자 웹사이트 링크가 포함되어 있습니다. 예를 들어 종의 **eBird**, **iNaturalist**, **Wikipedia** 페이지, 종 보기의 *"eBird에서 이 종의 소리 듣기"* 오디오 링크, 그리고 **정보** 화면에서 BirdNET 프로젝트 웹사이트, 소스 코드, 사용자 가이드, 후원 페이지로 연결되는 링크가 있습니다. 앱을 벗어나는 링크에는 외부 링크 아이콘(↗)이 표시되어 있어 탭하기 전에 알아볼 수 있습니다.

링크가 화면에 표시되는 것만으로는 어떤 데이터도 전송되지 않으며, 외부 링크가 자동으로 열리는 일은 없습니다. 브라우저는 사용자가 링크를 탭할 때만 열립니다. 링크를 탭하면 기기의 기본 웹 브라우저에서 해당 링크가 열리고 BirdNET Live를 벗어나게 됩니다. 연결되는 사이트는 제3자가 운영하며, 본 방침이 아닌 **해당 사이트 자체의** 개인정보 처리방침과 약관이 적용됩니다. 이러한 사이트는 사용자의 IP 주소, 기기 또는 브라우저 정보, 페이지 이용 방식 등 방문에 관한 정보를 독자적으로 수집하고 자체 쿠키를 설정할 수 있습니다. 저희는 외부 웹사이트의 콘텐츠나 데이터 처리 방식을 통제하지 않으며 이에 대해 책임을 지지 않습니다. 각 사이트의 개인정보 처리방침을 직접 확인하세요.

## GPS 및 위치

앱은 GPS 위치를 다음 용도로 사용합니다:

- **종 필터링** — 사용자의 위치에 출현할 가능성이 높은 종을 예측합니다.
- **Survey 모드** — GPS 경로를 기록하고 조사 경로(transect)를 따라 감지에 위치 정보를 태깅합니다.
- **Point Count 모드** — 관찰 지점을 표시합니다.

GPS 데이터는 로컬에 저장되며, 사용자가 Session을 직접 공유하거나 내보낼 때만 내보내기 파일에 포함됩니다. 위치 접근에는 사용자의 권한 허용이 필요하며, 시스템 설정에서 언제든지 철회할 수 있습니다.

## 데이터 내보내기

Session 데이터는 여러 형식(Raven Selection Table, CSV, JSON, GPX)으로 내보낼 수 있으며, **설정 → 내보내기 → 형식**에서 원하는 형식을 조합하여 한 번에 선택할 수 있습니다. 선택한 형식은 오디오 클립 및 선택 사항인 독립형 HTML 보고서와 함께 하나의 ZIP 파일로 묶입니다. 내보내기 파일은 로컬에서 생성되어 시스템 공유 시트를 통해 공유됩니다. 앱은 내보내기 데이터를 어떤 서버에도 업로드하지 않습니다.

## 데이터 삭제

개별 Session과 그 녹음은 Session 목록에서 삭제할 수 있습니다. 앱 안에서 BirdNET Live의 로컬 Session, 녹음, 음성 메모, 사용자 지정 종 목록, 환경 설정, 캐시를 모두 지우려면 **설정 → 위험 구역 → 모든 데이터 삭제**를 사용하세요. 운영 체제 설정에서 BirdNET Live의 앱 저장 공간을 지우거나 앱을 삭제할 수도 있습니다.

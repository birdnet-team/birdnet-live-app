# 허용 사용 정책

## 목적

BirdNET은 생물다양성 연구, 야생동물 보전, 환경 교육, 시민 과학을 지원하기 위해 개발된 개방형 과학 프로젝트입니다.

저희는 자연을 이해하고 보호하는 데 기여하는 합법적이고 책임 있는 목적으로 BirdNET을 널리 활용하시기를 권장합니다.

## 책임 있는 사용

사용자는 다음을 지켜야 합니다:

- 적용되는 모든 법률과 규정을 준수합니다.
- 개인정보와 현지의 녹음 관련 규정을 존중합니다.
- 모델 출력은 확률에 기반하며 오탐(false positive)이나 미탐(false negative)이 있을 수 있다는 점을 인식하고 BirdNET 예측을 책임 있게 사용합니다.
- 과학, 보전 또는 관리 관련 결정을 내리기 전에 필요한 경우 관찰 결과를 검증합니다.
- 민감한 종의 위치를 공개할 때 발생할 수 있는 생태적 영향을 고려합니다.

## 허용되지 않는 사용

BirdNET은 야생동물, 생태계 또는 사람에게 해를 끼치는 활동을 조장하는 데 사용되어서는 안 됩니다.

다음은 그 예시이며, 이에 한정되지 않습니다:

- 밀렵 또는 야생동물의 불법 포획, 거래, 교란, 착취를 지원하거나 조장하는 행위.
- 유해한 목적으로 멸종위기종이나 민감한 종의 위치를 의도적으로 찾아내는 행위.
- 보전 법률이나 보호구역 규정을 위반하는 활동을 지원하는 행위.
- 무기 시스템, 군사 표적 설정 또는 피해를 입히기 위한 군사 감시의 일부로 BirdNET을 사용하는 행위.
- 적용되는 법률이나 규정을 위반한다는 사실을 알면서도 BirdNET을 사용하는 행위.

## 과학적 진실성

사용자에게 다음을 권장합니다:

- 과학 출판물에서 BirdNET을 인용합니다.
- 의심되는 모델 오류나 편향을 보고합니다.
- 가능한 경우 개선 사항을 공유하고 프로젝트에 기여합니다.
- 모델 예측과 검증된 생물학적 관찰을 명확히 구분합니다.

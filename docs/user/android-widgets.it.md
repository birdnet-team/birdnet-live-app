# Widget Android

BirdNET Live include due widget Android per l'accesso rapido dalla schermata Home e, sui dispositivi supportati, dalla schermata di blocco.

## Disponibilità

- Solo Android. iOS e Windows non usano lo stesso sistema di widget.
- Il posizionamento nella schermata di blocco dipende dalla versione di Android, dal produttore del dispositivo e dall'host dei widget.

## Tipi di widget

### BirdNET Live shortcut

Usa questo widget per entrare in Live Mode con un solo tocco.

- Apre l'app direttamente in **Live Mode**.
- Avvia sempre automaticamente la registrazione non appena il modello è pronto.
- Se sono ancora richiesti onboarding o accettazione dei Terms, l'app completa prima quel flusso, poi apre Live Mode e avvia la registrazione.

Questo comportamento è volutamente diverso dall'impostazione normale **Avvio automatico della registrazione** in [Impostazioni](settings.md): il widget shortcut è sempre un avvio rapido.

### BirdNET Live statistics

Usa questo widget per una panoramica rapida dei dati di sessione.

- Mostra rilevamenti recenti e totali specie delle sessioni salvate.
- Supporta layout compatto ed espanso in base alla dimensione del widget.
- Nel layout espanso è presente un pulsante impostazioni per:
  - intervallo di tempo: 24 ore, 7 giorni o 30 giorni
  - trasparenza dello sfondo
  - dimensione del carattere

Le statistiche si aggiornano automaticamente quando salvi, modifichi o elimini sessioni.

Se il widget appare vuoto, completa e salva prima almeno una sessione.

## Suggerimenti

- Ridimensiona il widget statistiche dopo averlo aggiunto per passare tra layout compatto ed espanso.
- Posiziona il widget shortcut vicino al dock per avvii rapidi sul campo.
- Usa [Libreria sessioni](session-library.md) e [Revisione della sessione](session-review.md) per validare e rifinire i rilevamenti usati dal widget statistiche.

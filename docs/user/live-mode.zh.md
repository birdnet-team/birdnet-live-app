# Live 模式

Live 模式是通过手机麦克风聆听并实时查看检测结果的最快方式。

## 如何打开

在主界面点按带 :app-micRounded: 图标的 **Live 模式**卡片。

## Quick Listen 小组件

**仅 Android。** 主屏幕上的小组件一按即可开始聆听，不必先打开应用再逐层进入——当您听到想要识别的声音、担心它随时停下时，这很有用。

添加方式和其他小组件一样：长按主屏幕空白处，点按**小组件**，找到 **BirdNET Live**，把两个磁贴之一拖出来。

- **Quick Listen**（2×1）— 图标加 **Start Listening** 标签
- **Quick Listen (compact)**（1×1）— 仅图标

两者作用相同。点按任一个都会打开 Live 模式并立即开始聆听，无论**自动开始录音**设置为何。小组件不会修改该设置。

如果 Live 模式已经打开，小组件会回到同一界面，而不是重新构建它。正在进行或已暂停的 Session 会照常继续；如果它已停止，则在现有界面上开始聆听。

Quick Listen 绝不会取代正在运行的其他模式。如果 Point Count、Survey、文件分析或 [ARU 模式](aru-mode.md)的 Session 正在运行或正在启动，应用会切换到前台，并请您先停止那个 Session。它的界面和工作内容仍可访问，不会被打断。

## 顶部栏

顶部栏包含三个元素：

- :app-arrowBackRounded: — 退出 Live 模式
- 中间的状态文字 — `正在初始化`、`正在加载模型`、`就绪`、`正在识别物种`、`已暂停`或`错误`
- :app-tuneRounded: — 打开 Live 模式相关的设置

## 主操作按钮

底部中间的大圆形按钮会切换状态：

- :app-mic: — 开始聆听
- :app-stopRounded: — 停止当前 Session
- :app-playArrowRounded: — 从暂停就绪状态继续

## 聆听时您会看到什么

### 语谱图

只要正在采集音频，语谱图就会持续滚动。它按时间显示频率内容，使用设置中配置的色彩映射、FFT 大小、频率范围和时长。

### 检测列表

最近的检测显示在语谱图下方。每一行可以显示：

- 物种图片
- 常用名
- 可选的学名
- 置信度数值

点按物种所在行可打开物种详情浮层。

### Session 信息栏

语谱图下方的紧凑信息行汇总当前 Session，例如：

- 当前显示的检测
- 独立物种数（`spp`）
- 检测总数（`det`）
- 已用时长
- 启用录音时的预计录音大小

## 录音行为

录音在[设置](settings.md)中控制。

- **完整**录制整个 Session。
- **仅检测**录制检测前后的片段。
- **关闭**则不录音。

停止 Live 模式后，BirdNET Live 会保存 Session 并打开 [Session 回顾](session-review.md)。

启用自动保存 Session 时，Live 模式还会在开始时、每 30 秒以及应用转入后台时保存一个部分 Session。发生崩溃或断电后，最近保存的快照可在 Session 库中找到。该快照之后的更改可能会丢失。关闭自动保存也会同时关闭这些中间保存。

## 屏幕关闭后继续聆听

Live Mode 通常会在锁屏或离开应用时暂停，并在返回时继续同一个 Session。第一次发生这种情况时，对话框会提供限时后台聆听选项。在[录音设置](settings.md)中开启**熄屏后继续运行**，并选择最长 15、30、60 或 120 分钟（默认 30 分钟）。每次离开应用都会单独计算时间；达到上限会结束 Session。Android 会显示带有打开和停止操作的常驻通知。Windows 上，Live Mode 在窗口最小化后仍会继续聆听。

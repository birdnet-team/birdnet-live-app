# Session 목록

Session 목록은 저장된 Session과 처리된 파일의 보관소입니다.

## 열기

홈 화면 하단 바의 :app-libraryMusic: 버튼을 사용하세요.

## 목록에 표시되는 내용

각 Session 항목은 저장된 결과 모음을 요약하며, 유형, 날짜, 길이, 종 수, 감지 수를 보여줍니다.

Session 유형에는 홈 화면과 같은 아이콘이 사용됩니다:

- :app-micRounded: — Live Mode Session
- :app-audioFileRounded: — 파일 분석 Session
- :app-locationOnRounded: — Point Count Session
- :app-routeRounded: — Survey Session

## 앱 바 컨트롤

- :app-searchRounded: — 날짜, Session 유형, 장소명, 좌표, 일반명 또는 학명으로 검색
- 보기 방식 메뉴 — **자세히**, **간단히**, **종별** 사이를 전환
- :app-filterList: — 정렬 순서 변경

## 보기 방식

### 자세히

더 많은 메타데이터가 담긴 전체 Session 카드를 표시합니다.

### 간단히

빠르게 훑어볼 수 있도록 더 촘촘한 행으로 표시합니다. 각 행 오른쪽의 :app-expandMore: 버튼을 누르면 해당 행이 그 자리에서 자세히 보기의 전체 카드 내용으로 펼쳐집니다. 스크롤 위치를 잃지 않고 특정 Session의 통계만 잠깐 확인하고 싶을 때 편리합니다.

### 종별

Session을 종별로 묶고, 펼치면 해당 종이 포함된 Session들을 보여줍니다.

## 정렬

Session은 **날짜**(최신 또는 오래된 순), **이름**(A–Z 또는 Z–A), **길이**(긴 순 또는 짧은 순)로 정렬할 수 있습니다. 길이 정렬은 이번 주에 가장 길었던 Survey를 찾거나, 실수로 저장한 30초짜리 테스트 녹음을 찾을 때 유용합니다.

Session이 날짜별로 묶여 있을 때, 각 날짜 헤더 행에는 하루 전체에 대한 작업을 위한 케밥 메뉴(:app-moreVert:)가 먼저 표시되고, 펼치기/접기 화살표는 행의 끝에 놓입니다. 화살표는 *마지막* 요소이며 — 앱의 다른 모든 펼침 목록과 같은 규칙입니다 — 따라서 오른쪽 가장자리 근처를 누르면 항상 해당 그룹이 펼쳐지거나 접힙니다.

## 현지 시간

Session 목록에 표시되는 모든 타임스탬프 — 목록 행, 날짜 그룹 헤더, "시작" / "종료" 배지 — 는 휴대전화의 *현재* 시간대로 표시됩니다. Session의 기반 타임스탬프는 UTC로 저장되므로, 베를린에서 진행한 Session을 뉴욕에서 열면 단순히 5시간(또는 6시간) 이른 시각으로 표시될 뿐이며 디스크의 데이터는 바뀌지 않습니다. 긴 Survey 도중에 시간대를 이동하면 표시되는 시계가 기기를 따라갑니다.

## 행 작업

각 Session 행에는 두 가지 작업 방식이 있습니다:

- 모든 카드 오른쪽의 **점 세 개 메뉴**(:app-moreVert:)를 누르면 **열기**, **공유**, **삭제**가 있는 작은 메뉴가 열립니다. 공유는 현재 설정 → 내보내기 환경설정(형식과 "오디오 포함")을 사용하여 플랫폼 공유 시트를 바로 엽니다. 동료에게 Session을 보내기 위해 먼저 Session 검토를 열 필요가 없습니다.
- 행을 왼쪽이나 오른쪽으로 **스와이프**하면 삭제됩니다. 삭제 전에 여전히 확인 대화상자가 표시되므로 실수로 스와이프해도 되돌릴 수 있습니다.

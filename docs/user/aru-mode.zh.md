# ARU 模式

!!! note "早期实现"
    ARU 模式目前会保存计划部署的检查点，录制计划中的周期，在活动周期内进行实时推理，在选择相应录音选项时保存保留下来的检测片段，并在 Android 上显示前台通知控件。iOS 的后台行为仍需在野外验证。

ARU（Autonomous Recording Unit，自主录音单元）模式是用于定点计划声学部署的工作方式。

## 当前设置流程

- **详情与分析设置**：
    - **元数据**：输入项目名称、ARU/站点编号和观察者姓名。
    - **位置**：通过自动获取 GPS、手动输入经纬度提供站点坐标，或跳过位置设置。如果使用与日出日落绑定的计划，则必须提供纬度和经度。 图标：GPS :app-myLocation:、手动坐标 :app-editLocationAlt:、跳过位置 :app-locationOff:、地图选点 :app-mapSheet:。
    - **分析**：选择麦克风、推理频率、置信度阈值和灵敏度。
    - **录音格式**：在 FLAC（无损压缩）和 WAV（未压缩）之间选择。
    - **录音**：
        - *完整*：录制每个活动周期的全部时长。
        - *片段*：保存检测到的动物声音前后的短音频片段。您可以自定义片段前后余量（在检测前后各加 0 到 5 秒的缓冲），并选择采样方式（*全部*、*前 N 条*或 *Smart*，以限制存储占用）。
        - *关闭*：在周期内进行实时推理并记录检测，但不保存音频文件。
- **计划**：
    - **时长与重复**：选择每个活动录音周期持续多久、间隔多久重复一次。
    - **录音时段（昼夜节律）**：选择全天候录制（*全天连续*），或把周期限制为*白天*、*夜间*，或*日出前后*、*日落前后*、*日出与日落前后*等特定时段。日出日落时段会根据部署坐标动态计算。
    - **部署结束方式**：选择手动停止部署、在完成固定数量的周期后停止，或在指定日期时间自动停止。
    - **电量管理**：设置低电量停止阈值（0-50%）以暂停部署，避免电量彻底耗尽。设置后还可指定低电量恢复阈值，让录音周期在电量回升时（例如通过太阳能充电）自动继续。
    - **测试运行**：默认启用一次可选的一分钟测试周期，以便启动后立即验证麦克风输入和推理，且不计入计划的周期数量。
    - **Session 分组方式**：设置是把每个周期保存为独立 Session（推荐，加载更快、便于分段查看），还是把所有周期合并为一个多分段 Session。
- **准备就绪**：检查计划、预计音频存储占用和昼夜限制，然后开始部署。

设置控件使用与其他向导相同的图标：:app-micRounded: 麦克风、:app-speedRounded: 推理频率、:app-verifiedRounded: 置信度、:app-hearing: 灵敏度、:app-fiberManualRecordRounded: 录音、:app-timerOutlined: 片段前后余量和周期时长、:app-filterAltRounded: 检测采样，以及 :app-formatListNumberedRounded: 每个物种的片段上限。重复间隔使用 :app-repeatRounded:，低电量控件使用 :app-batteryAlert: 和 :app-batteryChargingFull:，测试运行和 Session 分组使用 :app-scienceRounded: 和 :app-libraryBooks:。点按控件旁的 :app-helpOutline: 按钮可查看说明。

开始部署会立即保存一个带 ARU 计划元数据的 `SessionType.aru` Session。录音周期还会每 30 秒保存一次检查点，包括没有检测结果的周期。发生崩溃或断电后，最近保存的部分部署会作为已结束的 Session 出现在 Session 列表中；录音不会自动重新开始。上次保存之后的数据可能会丢失。

JSON 和 ZIP 导出包含 ARU 部署元数据。ZIP 导出会把已保存的各周期录音文件归入 `aru_cycles/` 目录。

设置流程会记住上一次启动的部署所用的录音和计划选项。部署名称、坐标和结束日期每次都重新填写。

## 部署进行中界面

进行中的 ARU 界面显示部署处于等待、录音还是已完成状态。其布局使用四个标签页：
- **状态**：显示当前部署状态、活动计划计时器，以及实时检测列表。
- **音频**：显示实时滚动的声谱图以核对音频输入，下方仍可看到检测结果。
- **计划**：列出接下来 10 个计划周期时间，并在启用昼夜限制时标明与日出或日落的对应关系。
- **摘要**：汇总已用时间、录制音频总时长和检测统计。

在 Android 上，进行中的部署会显示带“停止”和“打开”操作的前台通知。

停止部署会打开 Session 回顾。如果各周期合并到了一个 Session 中，则打开该合并 Session；如果保存为独立 Session，则打开最近完成的那个周期 Session。

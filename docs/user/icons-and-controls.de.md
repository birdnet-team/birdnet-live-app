# Symbole und Steuerelemente

Auf dieser Seite werden die wiederkehrenden Steuerelemente und Symbole erläutert, die in BirdNET Live verwendet werden. Die folgenden Bezeichnungen entsprechen den Elementen, die bereits in der App sichtbar sind.

## Gemeinsame Navigationssteuerelemente

| Steuerelement | Wo es erscheint | Funktion |
| --- | --- | --- |
| :material-tune: **Einstellungen** | Fußzeile der Startseite, Live, Punktzählung, Transekt, Dateianalyse, Sitzungsrückblick | Öffnet die Einstellungen. Auf Modusbildschirmen werden die für den jeweiligen Workflow relevanten Bereiche angezeigt. |
| :material-magnify: **Erkunden** | Fußzeile der Startseite | Öffnet den Bereich „Erkunden“. |
| :material-music-box-multiple-outline: **Bibliothek** | Fußzeile der Startseite | Öffnet die Sitzungsbibliothek. |
| :material-help-circle-outline: **Hilfe** | Fußzeile der Startseite, Kopfzeile von „Erkunden“, Transekt-Dashboard, Werkzeugleiste der Sitzungsüberprüfung | Öffnet die Hilfe oder ein bildschirmspezifisches Hilfeblatt. |
| :material-information-outline: **Info / Über** | Fußzeile der Startseite, Infoleisten, Hilfeblätter | Zeigt allgemeine Informationen oder zusammenfassenden Kontext an. |
| :material-arrow-left: **Zurück** | Live-Modus | Kehrt zum vorherigen Bildschirm zurück. |
| :material-open-in-new: **Extern öffnen** | Bildschirm „Über“, Dokumentationslinks | Öffnet eine externe Seite, zum Beispiel das Online-Benutzerhandbuch. |

## Start-, Stopp- und Sitzungssteuerung

| Steuerelement | Bedeutung |
| --- | --- |
| :material-microphone: **Mikrofon** | Startet das Live-Hören. |
| :material-stop: **Stopp** | Stoppt eine aktive Aufnahme, Punktzählung oder einen Transektlauf. |
| :material-play: **Start** | Startet einen konfigurierten Ablauf oder setzt ihn aus einem angehaltenen Bereitschaftszustand fort. |
| :material-close: **Schließen / Abbrechen** | Bricht eine aktive Dateianalyse ab. |
| :material-timer: **Timer** | Zeigt Dauer oder verbleibende Zeit an. |
| :material-alert-circle-outline: **Fehler** | Kennzeichnet Modell- oder Verarbeitungsfehler. |

## Orts- und Zeitkontrollen

| Steuerelement | Bedeutung |
| --- | --- |
| :material-crosshairs-gps: **Aktueller Standort** | Verwenden Sie die aktuelle GPS-Position des Geräts. |
| :material-map-marker-plus: **Manuelle Koordinaten** | Geben Sie die Koordinaten manuell ein. |
| :material-map-marker-off: **Kein Standort** | Standort überspringen oder anzeigen, dass der Standort nicht verfügbar ist. |
| :material-map-marker: **Hat Standort** | Bestätigen Sie einen Standort, zeigen Sie Koordinaten an oder kennzeichnen Sie eine kartierte Sitzung. |
| :material-refresh: **Aktualisieren** | Lesen Sie den aktuellen Standort erneut oder aktualisieren Sie eine Vorhersageliste. |
| :material-map: **Kartenauswahl** | Wählen Sie Koordinaten aus der Kartenauswahl aus. |
| :material-calendar: **Datum** | Legt ein Datum fest oder zeigt es an. |
| :material-close: **Klar** | Ein ausgewähltes Datum entfernen. |

## Erkunden und Artensymbole

| Steuerelement | Bedeutung |
| --- | --- |
| Miniaturansicht der Art | Gebündeltes Bild für die Art, sofern verfügbar. |
| Vertrauens- oder Geomodell-Prozentabzeichen | Eine kurze numerische Zusammenfassung der Modellausgabe. Höhere Zahlen weisen auf eine stärkere Unterstützung im Kontext dieses Bildschirms hin. |
| Monatsetiketten („Jan“, „Apr“, „Jul“, „Okt“, „Dez“) | Referenzpunkte auf dem wöchentlichen Diagramm der erwarteten Häufigkeit im Arten-Overlay. |

## Sitzungsüberprüfungssymbolleiste

Diese Steuerelemente werden auf dem Bildschirm „Sitzungsüberprüfung“ verwendet.

| Steuerelement | Bedeutung |
| --- | --- |
| :material-plus-circle-outline: **Hinzufügen** | Fügen Sie Inhalte hinzu, z. B. eine Art oder eine Anmerkung. |
| :material-undo-variant: **Rückgängig machen** / :material-redo-variant: **Wiederherstellen** | Gehen Sie durch die Überprüfungsänderungen vor oder zurück. |
| :material-content-cut: **Zuschneiden** | Wechselt in den Zuschneidemodus oder zeigt an, dass der Zuschneidemodus aktiv ist. |
| :material-content-save: **Speichern** | Speichert Änderungen in der Sitzungsüberprüfung. |
| :material-share-variant: **Teilen** | Exportieren oder teilen Sie die Sitzung. |
| :material-delete-outline: **Löschen** | Verwerfen Sie die Sitzung. |
| :material-play: **Weiter** | Setzt einen noch nicht abgeschlossenen Transektlauf aus der Sitzungsüberprüfung fort, wenn diese Aktion verfügbar ist. |

## Bildschirmspezifische Statusleisten

### Live-Modus

Die Live-Infoleiste verwendet :material-information-outline: gefolgt von kompakten Beschriftungen wie:

- „Jetzt“ – Detektionen, die aktuell in der Live-Liste sichtbar sind
- „spp“ – einzigartige Artenzahl
- „det“ – Gesamtzahl der Detektionen
- Dauer und geschätzte Aufnahmegröße, wenn die Aufnahme aktiv ist

### Punktzählung

Die Timerleiste der Punktzählung kombiniert :material-stop: **Stopp**, :material-timer: **Timer** und einen Fortschrittsbalken, um die verbleibende zeitgesteuerte Sitzung anzuzeigen.

### Transekt

Das Transekt-Dashboard verwendet:

- :material-map-outline: **Karte** – Registerkarte „Live-Karte“.
- :material-equalizer: **Spektrogramm** – Registerkarte „Spektrogramm“.
- :material-chart-bar: **Zusammenfassung** – Registerkarte „Zusammenfassung“.
- :material-chart-bar: Statistikbeschriftungen in der Übersichtsansicht des Transekts

## Im Zweifelsfall

Wenn Sie nicht sicher sind, was ein Steuerelement bewirkt, öffnen Sie das nächstgelegene Hilfeblatt in der App oder sehen Sie sich die Workflow-Seite für diesen Bildschirm in diesem Benutzerhandbuch an.

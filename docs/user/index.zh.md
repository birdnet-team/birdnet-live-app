# 用户指南

本指南把 BirdNET Live 当作野外工作工具来介绍：每个界面做什么、反复出现的图标是什么意思，以及各项设置如何影响应用的行为。

它写给已经熟悉野外方法、只想清楚了解应用本身的生态学工作者和鸟类调查人员。

## 从这里开始

### [入门](getting-started.md)

安装、权限、首次启动，以及主界面上的主要导航。

### [图标与控件](icons-and-controls.md)

贯穿 BirdNET Live 的通用图标、按钮、符号和状态指示。

### [设置](settings.md)

应用目前提供的全部设置，分组方式与应用内的设置界面一致。

## 各模式指南

### [Live 模式](live-mode.md)

用麦克风持续聆听、实时检测、语谱图和 Session 信息栏。

### [探索](explore.md)

针对当前位置和季节预测的物种，以及物种详情浮层。

### [Session 库](session-library.md)

已保存的 Session、搜索、排序、视图模式，以及按物种分组浏览。

### [Session 回顾](session-review.md)

回放、编辑、裁剪、批注、导出，以及回顾界面的工具栏。

### [Point Count 模式](point-count-mode.md)

样点计数的设置流程、位置选项和计时界面。

### [Survey 模式](survey-mode.md)

Survey 的设置、实时 Survey 面板，以及地图、语谱图和汇总三个标签页。

### [文件分析](file-analysis.md)

四步文件分析向导、参数选择，以及结果如何进入 Session 回顾。

### [批量分析](batch-analysis.md)

批量处理和分析多个音频文件。（即将推出）

### [ARU 模式](aru-mode.md)

创建计划中的 ARU 部署 Session，录制完整周期音频或保留的检测片段，在活动周期内进行实时推理，并跟踪计划中的录音周期。

## 阅读顺序

1. 阅读[入门](getting-started.md)。
2. 浏览[图标与控件](icons-and-controls.md)，以便看懂反复出现的符号。
3. 打开您最常用模式的指南。
4. 当需要针对不同工作方式调整应用时，查阅[设置](settings.md)。

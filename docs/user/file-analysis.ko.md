# 파일 분석

파일 분석은 실시간 모드를 구동하는 것과 같은 BirdNET 파이프라인으로 기존 녹음을 처리합니다.

## 열기

홈 화면에서 :app-audioFileRounded: 아이콘이 있는 **파일 분석** 카드를 누르세요.

### 다른 앱에서 열기

다른 앱에서 BirdNET Live로 녹음을 넘길 수도 있습니다. Android에서는 오디오 파일을 **BirdNET Live**에 공유하거나 **다음으로 열기**를 선택하면 파일 분석이 즉시 열립니다. iOS에서도 **다음으로 열기**는 즉시 적용됩니다. 공유 시트를 사용한 뒤에는 BirdNET Live를 열거나 다시 돌아오면 대기 중인 녹음이 자동으로 선택됩니다. 앱은 분석 전에 녹음을 자체 임시 저장 공간으로 복사합니다.

## 앱 바

- :app-tuneRounded: — 파일 분석 설정 열기
- :app-helpOutlineRounded: — 파일 분석 도움말 열기
- :app-close: — 진행 중인 분석 취소

## 지원 입력 형식

현재 파일 선택기는 다음 형식을 받습니다.

- WAV / WAVE
- FLAC
- MP3
- OGG / OGA / Opus
- M4A / AAC / MP4
- WMA / AMR

## 4단계 마법사

### 1. 파일 선택

파일을 선택하고 메타데이터 카드를 확인하세요.

- 파일 이름
- 형식
- 길이
- 파일 크기
- 샘플 레이트

### 2. 위치와 날짜

다음을 할 수 있습니다.

- 현재 GPS 위치 사용 :app-myLocation:
- 좌표 직접 입력 :app-editLocationAlt:
- 위치 건너뛰기 :app-locationOff:
- 지도에서 지점 선택 :app-mapSheet:
- 녹음 날짜 설정(선택 사항) :app-calendarTodayRounded:

### 3. 매개변수

마법사에서 다음을 설정합니다.

- 분석 구간 길이
- 구간 중첩
- 민감도
- 신뢰도 임계값
- 종 필터 모드

| 설정 항목 | 아이콘 |
|---|---|
| 분석 구간 길이 | :app-timerOutlined: |
| 구간 중첩 | :app-swapHoriz: |
| 민감도 | :app-hearing: |
| 신뢰도 임계값 | :app-verifiedRounded: |
| 종 필터 | :app-filterAltRounded: |

설정 항목 옆의 :app-helpOutline: 버튼을 누르면 설명을 볼 수 있습니다. 파일, 위치, 녹음 날짜 단계에도 도움말 버튼이 있습니다.

구간 중첩은 각 분석 구간이 얼마나 전진하는지를 정하며 파일 분석에만 있는 설정입니다. 파일 전체는 항상 검사되고, 중첩을 늘리면 더 촘촘히 검사할 뿐입니다. 실시간 모드는 대신 추론 빈도를 사용하는데, 고정된 녹음을 얼마나 촘촘히 훑을지가 아니라 들어오는 오디오에 대해 모델을 얼마나 자주 실행할지를 정해야 하기 때문입니다.

파일 분석이 어떤 방식으로 구간을 얻든, Live Mode, Point Count, Survey와 같은 규칙으로 구간을 감지로 바꿉니다. 감지는 이를 뒷받침하는 가장 이른 구간에서 시작하고, 뒷받침 구간 중 가장 높은 점수를 가지며, 마지막 뒷받침 구간의 끝에서 끝납니다.

### 4. 분석

진행 화면에는 다음이 표시됩니다.

- 처리한 구간 수
- 발견한 감지 수
- 발견한 종 수
- 취소 버튼

## 결과

분석이 끝나면 BirdNET Live는 결과를 저장된 Session으로 변환하고 [Session 검토](session-review.md)를 엽니다.

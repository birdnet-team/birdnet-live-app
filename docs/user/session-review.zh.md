# Session 回顾

在 Session 回顾中，BirdNET Live 把原始检测结果变成可编辑的记录。

## 如何进入

在完成以下操作后，BirdNET Live 会自动打开 Session 回顾：

- 一次 Live 模式的 Session
- 一次样点计数
- 一次 Survey
- 一次文件分析

您也可以从 [Session 库](session-library.md)重新打开任何已保存的 Session。

## 主要区域

### 概要与回放

Session 回顾把回放、语谱图浏览和物种列表结合在一起。对于 Survey 模式的 Session，它还可以显示地图上下文。

界面顶部的概要标题包含日期、位置标签（经纬度，以及在**设置 → 隐私 → 允许地名查询**开启时解析出的地名），并且——如果录音时开启了**设置 → 隐私 → 允许查询天气**——在位置下方显示一行**天气**，记录 Session 结束时的天气状况：形如*"20.1 °C · 小雨 · 3.2 m/s 西南风"*的一行文字，前面带天气图标。点按该行可展开一个小面板，列出温度、风、降水和云量，并注明 Open-Meteo 来源。同一份快照也会写入 JSON 导出、Session 元数据块和 HTML 报告。

播放器上方的语谱图条是可交互的：点按可跳转，单指拖动可拖拽时间轴，**双指捏合可放大**较窄的时间窗口——当您想查看叠加鸣声的时间关系或拆解一段快速颤音时很有用。反向张开手指即可回到默认的 10 秒概览。物种标题上的播放按钮总是选择第一个确实录有片段的聚类，因此只要该物种有任意一条检测可播放，按钮就可用。

### 物种列表

物种被分组为可展开的行。您可以按物种查看检测，并在查看过程中在录音中移动。展开物种下的聚类行会缩进，使父级物种卡片在视觉上与其子行保持区分。

列表上方的搜索框可按常用名或学名筛选物种，因此在包含 100 个物种的 Session 中找到某一种鸟只需敲几个字，而不必长时间滚动。旁边的 :material-sort: 按钮可更改物种排序：

- **置信度最高**（默认）— 单条检测置信度最高的物种排在前面。适合优先处理最确定的鉴定结果。在该模式下展开某个物种时，带可播放音频片段的检测会排在没有片段的检测之前，之后再按置信度排序。
- **检测最多** — 检测数量最多的物种排在前面。适合发现占主导的鸣唱者。
- **A → Z** — 按常用名的字母顺序排列。可预期、遵循语言习惯，在 Session 物种较多时便于浏览。
- **首次检测时间** — 按首次检测时间的先后排列。这是历史上的默认方式；在与语谱图时间轴对照查看时很有用。

所选排序方式会在多个 Session 之间保留。

### 手动添加物种

工具栏上的 :material-plus-circle-outline: 按钮会为 BirdNET 漏掉的鸟类打开物种选择器。选中搜索结果并不会立刻添加——会先滑出一个确认面板，显示您选择的物种和两个复选框：

- :material-ear-hearing: **听到** — 您听到了这只鸟。
- :material-eye: **看到** — 您看到了这只鸟。

勾选其中一个、两个或都不勾选，然后点按**添加**。**取消**——或向下滑动——会回到搜索，因此点错并无代价。**听到**默认勾选，而且您的选择会延续到下一个添加的物种，所以在连续记录一批只看到的鸟时，只需勾选一次**看到**。两个都不勾选时，条目会以"无观察类型"保存，而不是保存为"两者皆非"。

该选择会存储在检测记录上，并在这条检测出现的所有位置——物种标题、聚类行、片段播放面板以及实时 Survey 列表——以手动标记旁的小耳朵和/或眼睛符号显示。它同样会进入导出：CSV 和 Raven 选择表中的 `Evidence` 列、JSON 中的 `evidence` 字段，以及 HTML 报告中的一个标记。执行**替换物种**时也会出现同一个面板，并按该记录原有的内容预先填好。

### 单条检测的操作

检测出现的所有位置——物种列表、片段播放面板、实时 Survey 列表和 Survey 地图标记——都使用同一组操作：

- :material-check: **确认** — 一按即可内联打勾，把某条检测标记为已通过视觉或听觉核实。已确认的聚类和地图标记会出现一个绿色小勾，便于一眼识别，该标记也会随各种导出格式一同保留。
- :material-dots-vertical: **更多** — 打开一个菜单，包含：
    - :material-share-variant: **分享检测** — 参见下方的*分享*。
    - :material-swap-horizontal: **替换物种** — 为这条检测选择另一个物种。
    - :material-delete-outline: **删除检测** — 立即移除该行。会出现几秒钟的 SnackBar 可撤销，因此误操作可以挽回。没有确认对话框。
    - :material-delete-sweep-outline: **删除物种** — 一次性从 Session 中移除该物种的全部检测，同样可通过 SnackBar 撤销。适合快速清除被误判的噪声源，而不必展开物种再逐个删除聚类。

#### 回顾列表行的滑动快捷方式

在物种列表中，您也可以通过水平滑动某一行来操作检测：

- 向**右**滑 → 删除（可撤销）
- 向**左**滑 → 打开替换物种浮层

两种背景使用不同颜色（错误红与主色蓝），因此在您完成手势之前就能看清效果。

滑动**物种标题**行（向左或向右）会一次性删除该物种的全部检测，同样可通过 SnackBar 撤销。在整理满是误判噪声的 Session 时很有用。

### 分享单条检测

:material-share-variant: **分享检测**会打开系统分享面板，附带一份简洁、便于野外工具使用的内容——常用名与学名、置信度、ISO 8601 UTC 时间戳，以及在检测带 GPS 时的 `geo:` URI——并在有音频片段时一并附上。分享的文件命名为 `BirdNET_Live_<timestamp>_<species>.<ext>`，与 ZIP 导出的命名方案一致。

音频附件按以下顺序确定：

1. 该条检测在磁盘上自有的片段。
2. **对于录制为单个连续文件的 Session**：相关的音频窗口会即时从录音中截取。连续的 WAV 和 FLAC 录音均受支持，截取结果与源文件使用同一容器（WAV 进 → WAV 出，FLAC 进 → FLAC 出）。
3. 如果两者都没有，则只分享文本——位置和时间戳仍会包含在内容中。

### 语音备忘

您可以为单条检测记录附上简短的语音说明：

- **录制**：点按检测聚类上的 :material-dots-vertical: 按钮并选择**录制语音备忘**，打开语音备忘对话框。点按大号麦克风按钮开始录制。实时波形会同步反映您的声音。完成后点按停止按钮。
- **回听**：录制完成后，可用内嵌播放器回听。要重录，点按**重新录制**按钮。要保存，点按**保存**按钮。
- **删除**：如果某条检测已附有语音备忘，您可以从更多菜单或语音备忘对话框中删除它。
- **各平台格式**：在 Android 及其他平台上，语音备忘以高压缩的 AAC 格式（`.m4a`）、16 kHz 录制。在 iOS 上会自动使用 WAV/PCM16 格式（`.wav`），以避免 CoreAudio 与应用正在使用的音频会话之间的兼容问题。两种格式都完全支持 ZIP 导出打包。
- **导出**：把 Session 导出为 ZIP 时，语音备忘会打包到 `memos/` 目录中，其相对路径会记录在 JSON 和 CSV 元数据里。

### Survey 轨迹地图

Survey 模式的 Session 会显示一张内嵌小地图，展示 GPS 轨迹和检测标记。点按内嵌地图上的标记可聚焦某条检测——内嵌地图会以其为中心。点按 :material-fullscreen: **展开**按钮（内嵌地图右上角）可打开**全屏地图**；如果之前聚焦了某条检测，全屏地图会以该检测为中心并放大打开，以便您保持当前位置。

#### 标记的含义

- **置信度以颜色编码**，使用对色觉障碍友好的色阶：从低到高置信度依次为紫蓝、青绿/黄色直到红色。色阶的明度单调变化，因此在单色显示和红绿色觉障碍下依然可读。
- **带音频的检测**在物种照片周围显示彩色圆环，角上带播放标记——点按可打开与其他地方相同的片段播放面板，其中确认、分享、替换和删除均可用。
- **无声检测**（磁盘上没有片段）显示得更小、更淡，并带中性灰色圆环，因此带音频的检测始终作为主要内容突出显示。
- **同一位置的重叠标记**按重要性分层：高亮 > 带音频 > 置信度更高，因此低置信度的无声标记绝不会遮住强的带音频检测。
- **在缩放级别 14.5 以下**，剪影会退化为按置信度确定大小的彩色圆点，密集的聚集会折叠成计数气泡（缩放到 15 级时聚合关闭）。

#### 筛选

全屏地图右上角固定有一个**筛选标签**。点按可打开筛选面板；标签文字始终显示当前生效的条件（*"全部物种"*、*"含音频"*、*"≥ 80%"*，或某个物种名）。可用筛选：

- **全部检测**（默认）。
- **含音频片段** — 只显示片段仍在磁盘上且可播放的检测。
- **手动添加** — 只显示您在 Session 回顾中添加的检测（不含自动检测的）。

您也可以按置信度水平限制检测。滑块设置置信度下限（从 10% 起）。

置信度滑块下方是**限定物种**选择器，可把地图收窄到单一物种——适合回答"我究竟在路线的哪一段听到了欧歌鸫？"这类问题。选择*全部物种*可解除物种限制。各筛选条件可以组合：例如*含音频片段* + *欧歌鸫* + *> 80%*，只会显示得分高于 80% 且可播放的欧歌鸫标记。

有筛选生效时，应用栏标题会加上一行匹配数量的副标题（例如*"7 条检测"*）。面板中的*重置*可恢复默认。

## 工具栏图标

工具栏使用与[图标与控件](icons-and-controls.md)中所述相同的图标含义：

- :material-plus-circle-outline: — 添加内容
- :material-undo-variant: / :material-redo-variant: — 在编辑记录中前后移动
- :material-content-cut: — 裁剪模式
- :material-content-save: — 保存修改
- :material-share-variant: — 导出或分享
- :material-delete-outline: — 丢弃 Session
- :material-play: — 在该操作可用时继续 Survey
- :material-help-circle-outline: — 打开 Session 回顾帮助面板
- :material-tune: — 打开设置

## 常见的回顾工作

- 对照回放和语谱图上下文核对检测
- 添加物种或批注
- 把录音裁剪到有用的区间
- 导出已回顾的结果集

## 导出

导出行为取决于您在[设置](settings.md)中选择的选项。应用可以把检测以及（可选的）音频打包成所选的导出格式。每次导出都附带来源元数据——应用版本、模型名称和版本、物种语言、导出时间戳、随 Session 保留的设置，以及相关导出选项——写入 `<prefix>.metadata.json` 附属文件（ZIP）或顶层 `meta` 块（JSON），使导出内容自带说明且可复现。

JSON 导出中的 `settings` 块记录的是*实际应用于本次 Session* 的取值——灵敏度、score-pooling 模式与窗口数、麦克风增益和高通截止频率——而不是您现在设置里恰好是什么。这样，您几个月后仍能复现某个结果，或者比较两次 Survey，而不必回忆当时各个滑块的位置。

导出文件名（`BirdNET_Live_<date>_<time>_…`）以及 CSV / JSON 内容中的所有时间戳，都按手机*当前*的本地时间格式化。底层记录以 UTC 存储，导出时再转换。

# Режим Point Count

Режим Point Count — стационарный рабочий процесс по таймеру в BirdNET Live.

## Как его открыть

На главном экране нажмите карточку **Режим Point Count** со значком :app-locationOnRounded:.

## Настройка

Настройка точечного учёта состоит из четырёх шагов.

### 1. Длительность и место

Выберите:

- одну из доступных длительностей: 3, 5, 10, 15, 20, 25 или 30 минут
- продолжать ли учёт при выключенном экране (по умолчанию включено)
- текущую позицию GPS кнопкой :app-myLocation:
- координаты вручную кнопкой :app-editLocationAlt:
- отсутствие местоположения кнопкой :app-locationOff:
- выбор на карте кнопкой :app-mapSheet:

Экран настройки обновляет GPS, когда вы возвращаетесь из системного окна
разрешений или из настроек приложения, поэтому только что выданное
разрешение на местоположение должно обновить координаты без перезапуска
мастера. В этом же разделе есть карточка погоды. Если доступ к данным о
погоде выключен, карточка запрашивает согласие **Разрешить запрос погоды**;
после включения она показывает предварительный просмотр места со значком
погоды, температурой и ветром. Тот же сохранённый в кеше снимок Open-Meteo
используется повторно при сохранении точечного учёта.

### 2. Параметры вычислений

Выберите настройки анализа для этой Session: частоту
вычислений, порог достоверности и режим фильтра видов. Они берутся из ваших
глобальных настроек, но их можно изменить для этого учёта, не меняя значения
по умолчанию.

| Элемент настройки | Значок |
|---|---|
| Микрофон | :app-micRounded: |
| Режим записи | :app-fiberManualRecordRounded: |
| Контекст фрагмента | :app-timerOutlined: |
| Частота вычислений | :app-speedRounded: |
| Порог достоверности | :app-verifiedRounded: |
| Чувствительность | :app-hearing: |
| Фильтр видов | :app-filterAltRounded: |

Кнопка :app-helpOutline: рядом с каждым элементом объясняет его действие. Такая же кнопка справки есть на первом шаге у выбора длительности :app-timerRounded: и выбора местоположения.

Выберите **Полный**, чтобы сохранять непрерывное аудио (по умолчанию), **Клипы**, чтобы сохранять фрагмент каждой обнаруженной вокализации, или **Выключенный**, чтобы не сохранять аудио. Выбор независим от настройки записи Live Mode и запоминается для следующего Point Count. Фрагменты используют тот же выбор окна с максимальной оценкой и контекст, что и Live Mode, без сокращения по местоположению. При выборе **Клипы** ползунок **Контекст клипа** задаёт секунды до и после каждого анализируемого окна; он также обновляет контекст Live Mode.

### 3. Полевые советы

Этот экран показывает краткий контрольный список, который стоит просмотреть перед началом.

### 4. Готово

Экран готовности показывает длительность, вариант записи и поведение при выключенном экране. Начните кнопкой :app-playArrowRounded:.

## Экран идущего точечного учёта

Экран идущего точечного учёта построен вокруг панели с таймером.

### Верхняя панель

- :app-stopRounded: — завершить точечный учёт досрочно
- :app-timerRounded: — показать оставшееся время
- :app-helpOutlineRounded: — открыть справку Point Count
- :app-tuneRounded: — открыть настройки режима Point Count

### Основные показатели

- полоса обратного отсчёта
- компактная информационная строка с текущими обнаружениями, числом уникальных видов и общим числом обнаружений
- вид спектрограммы
- список обнаружений

## После учёта

При включённом **Продолжать при выключенном экране** в настройке Point Count учёт продолжается после блокировки экрана или перехода в другое приложение, даже если экран остаётся включённым. Он заканчивается через выбранное время; отсчёт использует реально прошедшее время, поэтому приостановленный экран не продлевает учёт. Android показывает постоянное уведомление с действиями Открыть и Остановить. Выключите переключатель, чтобы эти действия завершали учёт досрочно. Point Count не приостанавливается и не возобновляется, поскольку это нарушило бы учёт по времени. Если выйти во время запуска, учёт отменяется с сообщением; настройте его заново. В Windows сворачивание окна не завершает учёт.

После завершения Point Count BirdNET Live открывает [Просмотр Session](session-review.md). Если автосохранение включено, Session сохраняется автоматически; иначе сохраните её из просмотра, если хотите оставить.

При включённом автоматическом сохранении незавершённый учёт также сохраняется при запуске, каждые 30 секунд и когда приложение уходит с переднего плана. После сбоя или отключения питания последний частичный учёт доступен в Библиотеке Sessions.

# 设置

BirdNET Live 在多种工作方式中复用同一个设置界面。:material-tune: 按钮会打开与您来时所在界面相关的设置区块。

## 设置范围如何工作

- 从主界面打开设置会显示完整界面。
- 从 Live、Survey、Point Count 或文件分析打开设置，界面会筛选为相关区块。

## 常规

### 主题

选择**深色**、**浅色**或**跟随系统**。

如果启用了**动态取色**，BirdNET Live 还会尝试匹配您 Android 设备的系统配色。这只在受支持的 Android 设备上生效；在 iPhone 和 iPad 上应用仍使用标准的 BirdNET Live 主题，因此在这些设备上打开开关不会有任何变化。

启用**高对比度主题**可使用黑白的浅色或深色界面配色，文字更粗、界面元素带边框，而不是使用带色卡片。它遵循**深色**、**浅色**或**跟随系统**的选择，在启用期间会覆盖动态取色，并保留危险、警告、校验、模式、分数和语谱图的配色。

### 应用语言

设置界面语言。

### 物种名称

控制物种名称使用的语言。**跟随系统**在有对应名称时使用手机的首选语言，即使界面回退到英文也是如此。**跟随应用**则改用界面语言。

### 显示学名

在应用各处的常用名下方显示学名。

### 显示全部已检测物种

仅 Live 模式和 Point Count。默认关闭，因此这些界面只显示最近一个推理周期检测到的物种——实际上就是当前正在鸣叫的物种。打开后，本次 Session 中检测到的每个物种都会留在列表中，即使它已经停止鸣叫或降到置信度阈值以下。

启用后会出现**物种列表排序**。**最新优先**把当前正在鸣叫的物种排在前面并按当前置信度排序，随后是按最近一次检测排序的保留物种。**置信度**按各物种在本次 Session 中达到的最高置信度排序，**按字母**按本地化常用名排序，**出现次数**按检测次数排序。在任何排序模式下，置信度百分比和进度条只在该物种正在鸣叫时显示（已停止鸣叫的保留行会变暗），重复检测则在常用名一行末尾显示计数标签。

### 观察者姓名

Survey、Point Count 和 ARU 设置会记住在这些模式中最近输入的非空观察者姓名，并在您下次准备野外 Session 时自动填入。这样在个人野外手机上重复使用时更快捷，同时仍可在开始 Session 前修改或清空观察者。

### ARU/站点编号

ARU 设置会记住最近使用的非空 ARU/站点编号，并为下次部署预填。若已填写，该编号会写入 ARU Session 名称和导出文件名，使定点重复部署在应用之外也易于识别。

### 时间戳显示

控制单条检测的时间在 Session 回顾中如何显示。

- **相对**显示相对录音开始的偏移，例如 `00:12:34`。最适合查看单个 Session 并与语谱图播放指针对应。
- **绝对**显示检测被采集时的本地时钟时间，例如 `08:42:17`。最适合与野外记录、天气日志或同步录音对照。

如果某条检测落在与 Session 起始不同的自然日（例如通宵调查），绝对时间会加上 `+1d` 后缀，以免查看者把明天的晨鸣误当作今天的。

选择**绝对**时会出现额外的**在时间戳中显示秒**开关。如果您更喜欢紧凑的 `08:42` 而非 `08:42:17`，可以关掉它——浏览长检测列表时很有用。相对偏移始终显示秒，因为查看时需要亚分钟级精度才能与语谱图播放指针对齐。

无论此设置如何，存储和导出始终使用 UTC 时刻，因此该选择绝不影响数据本身，只影响显示方式。

## 音频

这些控件出现在以音频驱动的实时工作方式中。

### 音频源

一个面板中有两个相互独立的控件：**麦克风**——从哪个输入录音——以及**处理**——允许手机在输入环节对信号做多少改动。两者可自由组合，因此用 USB 麦克风以*不处理*方式录音是完全合理的配置。您的选择会在应用重启后保留，同样的选择器也出现在 Survey、Point Count 和 ARU 的设置界面上。更改立即生效——即使在录音途中，应用也会在正在进行的 Session 下替换麦克风，而不是等到下一次。

**麦克风**按名称列出手机提供的每个输入：USB、有线和蓝牙麦克风，在许多手机上还包括各个内置麦克风（例如*底部*和*背面*）。像 Rode Wireless GO 或 DJI Mic 这类无线麦克风套装通过 USB-C 接收器连接，因此在这里会以普通 USB 音频设备的形式出现，音质完整。

**处理**是最关键的部分，而且**仅适用于 Android**。手机默认会对麦克风音频应用为语音调校的 DSP——降噪、频谱整形和自动增益——因为麦克风绝大多数时候用于通话。这类处理会把鸟鸣当作需要抑制的噪声，而且没有任何常规设置能关掉它。唯一的办法是向 Android 请求不同的*音频源*：

| 选项 | 作用 |
|---|---|
| **手机默认** | 您的手机通常的行为，包含语音处理。这是最初的行为，也仍是默认值，以免改变现有用户的体验。 |
| **不处理** | 麦克风的原始信号——没有降噪，没有自动增益。对鸟类通常是最佳选择。 |
| **语音识别** | 同样会关闭降噪和自动增益，并且几乎在所有手机上都有效。 |

**请实际试用并比较。** 哪个更好确实取决于具体机型。*不处理*是理想选择，但 Android 只在厂商声明支持的手机上真正执行它——在其他手机上它会静默回退，听起来与*系统默认*完全一样。*语音识别*正是为此准备的：Android 的兼容性规则**要求**在该模式下关闭自动增益和降噪，因此即使在忽略*不处理*的手机上，它也能可靠地提供未经处理的音频。如果切换到*不处理*没有任何变化，请改用*语音识别*。

请预期未处理的选项听起来会**更轻**——这是自动增益消失所致，并非故障。如果电平表偏低，可提高**增益**来补偿。

**在 iOS 上**，处理控件会隐藏，该面板就只是一个麦克风列表。iOS 本来就把基本未经处理的音频交给应用，因此这里没有相应的选项可选。

### 增益

在进入语谱图和分类器之前，对输入音频施加的线性放大。除非您的输入始终太轻，否则请保持 **1.0×**——例如接在手机上的高阻抗领夹麦克风，或前置放大设置过低的 USB 声卡。把增益推到 1.0 以上并不会凭空显现麦克风从未捕捉到的鸣声；它只是对麦克风送来的信号重新缩放，因此附近的响亮声音可能削波。低于 1.0 只在少见情况下有用，即输入过强导致语谱图饱和时。

### 高通滤波（Hz）

在推理前用 24 dB/倍频程的巴特沃斯滤波器切掉低频内容——滑块数值即 −3 dB 截止频率。**0 Hz 表示关闭。** 100–200 Hz 的截止可去除风声、交通轰鸣和手持噪声，而不影响大多数物种；推到 500–1000 Hz 则会开始削掉低沉的鸣叫、猫头鹰、松鸡和大麻鳽的"闷响"，因此只有当您有意忽略这些物种、以换取嘈杂城市环境中干净得多的语谱图时，才应设得这么高。您选择的截止频率应当在实时语谱图上呈现为一条清晰的水平线。

## 推理

### 窗口时长

控制分析窗口的长度。可选档位为 **1**、**3**、**5**、**7**、**10** 和 **15** 秒。

### 置信度阈值

设定检测应当多么保守。默认为 **35%**，可让实时列表聚焦于较强的匹配，同时仍为远处或被部分掩盖的鸣声留有余地。如果您在调查稀有或安静的物种并打算稍后查看更多候选，可以调低；当背景噪声或常见误报把 Session 挤满时，则调高。

### 灵敏度

在 score pooling、地理筛选和置信度阈值之前，施加于模型原始概率分数的 x 轴偏移。BirdNET 的音频模型本身已包含 sigmoid 激活，因此 BirdNET Live 会先把每个概率换算回 logit 空间，加上灵敏度偏置，再换算回概率。数值越高，检测器越宽松——较弱或较含糊的鸣声也会越过阈值，代价是误报增多。数值越低越严格，只让确信的检测通过。默认值 **1.0** 不施加偏移，与 BirdNET 参考实现一致。如果您怀疑模型漏掉了远处的鸣声，可以试 **1.25**；如果您被常见物种的低质量检测淹没，可以降到 **0.75**。灵敏度即时生效：在 Session 途中修改会从下一个推理窗口开始起作用。

### 推理频率

控制 BirdNET 运行推理的频率。滑块使用与 Survey 和 ARU 设置相同的 **0.10–1.00 Hz** 档位。

BirdNET Live 在内部会对近期推理窗口的分数做平滑，以减少一次性误报。该
pooling 未开放为用户设置；默认使用自适应 pooling 模式，取最近五个窗口并设
10 秒的实时时效上限。在高推理频率下使用平均 pooling，以获得稳定的实时判定；
在 Survey 和 ARU 较慢的节奏下使用 LME pooling，以在长时间运行中保持较高的
精确率。被接受的检测会显示近期最强的、有支持的模型置信度，因此明确的鸣声
仍可显示较高置信度，而不会被平滑压平。

## 语谱图

### FFT 大小

控制语谱图的频率分辨率。

### 色彩映射

可选 **Viridis**、**Magma**、**Plasma**、**Cividis**、**Jet**、**Turbo**、**灰度**或 **BirdNET**。**Turbo** 是类似 Jet 的现代彩虹配色。

### 时长（滚动速度）

控制语谱图窗口中可见的时间长度。

### 频率范围

设置显示的频率上限。

### 对数幅度

对语谱图应用对数缩放，使其更易于观察。

### 质量

控制语谱图图像缩放的平滑程度。**中**是默认的折中值。在较旧的手机上，如果滚动卡顿或设备发热，请选择**低**；如果您偏好更平滑的画面且设备的 GPU 有余量，请选择**高**。可以这样理解：它只改变渲染开销，不影响音频分析或检测结果。

## 语音播报

本区块控制 BirdNET Live 是否在 Session 录音期间**通过耳机或手机扬声器把检测结果朗读出来**。整个功能**默认关闭**，因为它会改变麦克风周围的声学环境——启用它是一个有意为之的取舍。这里没有设置向导：下面的详略程度 × 频率选择器*就是*全部设置，因此您随时可以点选另一个预设并立刻听出差别。可以这样理解：在长时间调查中您没法一直盯着屏幕；耳边一个不打扰的声音，能让您把视线留在生境上，同时仍知道刚才听到了什么。

### 朗读检测结果（主开关）

默认关闭。开启后，应用会用设备内置的语音合成朗读每条被接受的检测。**强烈建议使用耳机**——使用手机扬声器时，播报可能被麦克风拾取并被再次检测，因此应用会在每次朗读前后短暂静音录音以避免这一循环（参见下方*朗读时静音麦克风*）。

### 详略程度预设

应用对每条检测说多少话。**最简**只说物种名称（最适合只想要提示信号的超长调查）。**均衡**是默认值——简短且富于变化的说法，例如*"知更鸟"*、*"听到一只知更鸟"*、*"又是知更鸟"*。**健谈**会补充一点上下文，更接近有人在旁边解说。当您手动调整"高级"中的数值时，**自定义**会自动出现。可以这样理解：同样的限流设置，视措辞不同可能显得太安静或太啰嗦——详略程度让您保持节奏，只调整话语的多少。

### 频率预设

应用总体上多久可以说一次话。从最安静到最健谈共五档。**很少**和**稀疏**在两次播报之间等待较久并限制速率——很适合多小时的调查，您希望感知到活动情况，但不需要不间断的解说。**正常**是默认的对话式节奏。**频繁**缩短间隔并提高上限；适合较短的 Live Session，或您希望获得更接近实时的反馈时。**持续**完全取消启动延迟，让应用几乎在每个检测周期都说话——适用于演示、无障碍需求，或当您觉得*频繁*下首次播报前的等待太长时。当您修改"高级"中的时间字段时，**自定义**会出现。可以这样理解：这是决定应用停留在背景还是成为一种存在感的唯一旋钮——点选另一个预设，您会在下一个检测周期内听到新的节奏，不需要保存按钮。

### 语音

点按语音一行，即可在为播报语言安装的语音合成音色中选择，或保持**默认语音**由设备决定。语音的可用性和质量取决于操作系统和已安装的语音包；您可以在设备的语音合成设置中安装更多语音。

**语速**范围为 0.5×–1.5×，默认的 1.0× 是平台的"正常"语速。**音调**范围为 0.7×–1.3×。略微降低音调并稍微放慢，可让播报在有风或流水背景的户外更易听清。*试听一段*可在不离开设置的情况下预览所选语音、当前措辞风格、语速和音调。更改从下一次播报开始生效。

### 高级

一个可展开区块，提供若干音频路由开关以及触发模式选择器。通常您不需要打开它——上面的详略程度和频率预设才是日常真正重要的旋钮。限流相关的数值（启动宽限、最小间隔、每分钟上限、连续静默、时效重置）都被整合进**频率**滑块，因此调高或调低节奏只有一个显而易见的入口。

- **允许使用手机扬声器** — 关闭时，若未连接耳机或外接扬声器，播报会被静默跳过。开启时，手机扬声器会作为备选。在家随意收听时可以打开；野外作业时请保持关闭，以确保不会有声音回授进麦克风。
- **朗读时静音麦克风** — 在应用说话期间把输入音频替换为静音，使扬声器输出无法被麦克风拾取并再次检测。强烈建议开启（也是默认值）。只有当您的麦克风与手机扬声器在声学上相互隔离时才关闭它——例如另一条线缆上的领夹麦克风，或蓝牙耳机。
- **降低其他音频** — 在播报期间短暂降低其他应用中音乐或播客的音量，之后恢复。默认开启。关闭时会以完整音量继续播放。
- **朗读前提示音** — 在每次朗读前播放一声短促轻柔的提示音，让您的耳朵有片刻从被动聆听切换到留意语音。默认开启。当播报较为稀少或背景有音乐时尤其有用。
- **播报哪些内容** — 决定哪些检测才有资格被播报。*每一条检测*（默认）把决定权交给限流。*每个 Session 首次*只在某个物种在当前 Session 中首次出现时播报。*仅关注列表*把播报限制在您关注列表中的物种（适合有针对性的调查工作，您只想听到重点类群，其他一概不播）。

## 录音

### 模式

- **完整** — 保存整段录音
- **仅检测** — 保存检测前后的片段
- **关闭** — 不录制音频

### 片段上下文

当**仅检测**生效时，应用会显示一个**片段上下文**滑块（0–5 秒），用于设定在每条检测**两侧**各保留多少音频。每个片段的长度为`分析窗口 + 2 × 片段上下文`，因此在 3 秒分析窗口和默认 1 秒上下文下，保存的片段为 5 秒。把上下文设为 2 秒可得到 7 秒的片段（2 秒前导 + 3 秒被分析音频 + 2 秒后续）。数值越大，越便于目视检查或用外部工具复核，代价是占用更多磁盘空间；设为 0 则只保存被分析的窗口本身。

### 格式

选择 **WAV** 或 **FLAC**。WAV 文件更大，但兼容性广、便于快速检查。FLAC 在保持同样无损音质的同时占用更少存储，长时间 Session 通常更合适。

该设置适用于 BirdNET Live 录制的音频。**文件分析**会以原始格式保留一份由应用管理的导入文件副本，因此 MP3、AAC、WAV 和 FLAC 上传的文件无需额外转换即可继续回顾。

### 自动开始录音（仅 Live 模式）

启用后，Live 模式会在界面打开且模型加载完成时立即开始录音——不需要点按麦克风按钮。适用于类似展台的部署、免手操作（例如把设备固定在野外），或任何"打开 Live 就意味着现在开始"的工作方式。默认关闭，以免在主界面误触 Live 磁贴时悄悄开始一次 Session。自动开始在每次进入该界面时只触发一次，因此停止 Session 后再次点按麦克风仍可作为手动重新开始。

该设置针对从应用内部打开 Live 模式的情形。[Quick Listen 小组件](live-mode.md)在被点按时就会开始聆听，无论此设置为何，并且不会改动该设置。如果 Point Count、Survey、文件分析或 ARU 模式的 Session 已在运行或正在启动，它会保留那个 Session，并请您先停止它。

### 自动保存 Session（Live 和 Point Count）

启用时（默认），完成的 Live 或 Point Count Session 会在结束的那一刻自动加入您的库。关闭时，结束的 Session 会以**未保存**状态在回顾中打开：保存图标会高亮，您必须点按它才能保留该 Session。未保存就离开回顾会丢弃该 Session 及其录音。这适合随手听听的场景——您只想偶尔保留值得注意的结果，而不是把每段短录音都攒下来。Survey 和 ARU 部署始终自动保存——长时间无人值守的运行太宝贵，不能因忘记点保存而丢失——因此该开关在那里不适用。

## 回放

### 回顾中的播放浮层

启用时（默认），在只有片段的 Session 回顾中（没有完整录音/语谱图可用）收听音频片段，会打开一个带播放控件和语谱图预览的独立模态播放浮层，而不是在后台播放该片段。如果某个 Session 有完整音频，则跳过该设置，播放浮层不会出现。

### 自动播放语音备忘

默认关闭。启用后，附加在带时间批注上的语音备忘，会在 Session 回顾中播放指针经过其记录位置时自动播放。备忘会叠加混音在录音之上，而不是让录音暂停，因此您能在原始音频的语境中听到自己的口述备注。如果您更喜欢通过点按批注标签手动触发备忘，请保持关闭。

### 语音备忘闪避

仅在**自动播放语音备忘**启用时显示。控制自动语音备忘播放期间主录音被压低的程度。数值越高，口述备忘越清晰；数值越低，备忘之下保留的原始录音越多。

## 位置

### 使用 GPS

使用设备 GPS 而非手动坐标。在 Android 上，定位来自平台的位置服务而非
Google Play 服务，因此应用不会触发 Google 的定位精度弹窗。关闭该项后，
应用绝不会主动读取 GPS 或申请位置权限：Survey、Point Count 和 ARU 的设置
向导会以手动输入方式打开并使用您保存的坐标，Survey 的 GPS 轨迹不会运行，
离线地图准备也同样以这些坐标为中心。

### 手动坐标

**使用 GPS** 关闭时所采用的坐标。纬度和经度都是可编辑的文本框，因此您可以**输入**精确数值，或**粘贴**从其他应用复制的数值——这比在触摸屏上拖动滑块精确得多。请输入十进制度数（例如 `52.5200` 和 `13.4050`）。您也可以把`纬度, 经度`这样的组合字符串（用逗号、分号或空格分隔）粘贴到*任一*文本框中，两个框会同时填好——这与大多数地图和网站放进剪贴板的格式一致。超出范围或非数字的输入会就地标出且不会保存；有效数值在输入过程中即被保留。可以这样理解：手动设置位置最常见的原因，是要鉴定在别处录下的声音，而那个位置通常以文字形式从别处而来——输入和粘贴让这一步既准确又只需一次操作。如果您更愿意指点位置而不是输入数字，**在地图上选择**会打开与设置界面相同的全屏地图选择器，并以当前坐标为起点，把您点按的位置填入两个框。

### 立即刷新 GPS

强制重新定位，而不是复用应用上次缓存的数值。可以这样理解：GPS 查询按界面分别缓存，这样设置界面不必每次打开都等待卫星定位——但如果您在上次 Session 之后开车换了地方，这个缓存可能已经偏差数公里。当您移动过位置、希望地理筛选使用*此处*而非清晨出发地时，请点按它。当前缓存的坐标显示在副标题中，方便您核对应用认为您在哪里。如果约 10 秒内无法定位，应用会回退到操作系统提供的最后已知位置，并用 SnackBar 提醒您该数值已过时。

### 离线地图下载

在 BirdNET Live 使用 OpenStreetMap 公共瓦片服务期间，离线地图下载暂时隐藏。OpenStreetMap 允许在注明来源、使用清晰的 user agent 并进行本地缓存的前提下正常交互式浏览地图，但不允许从 `tile.openstreetmap.org` 批量预取或提供离线地图下载功能。下载器的实现被保留下来，以备将来采用明确允许离线包的瓦片来源。

### 物种筛选

- **关闭** — 不做地理筛选
- **位置筛选** — 排除低于地理阈值的物种
- **位置加权** — 把地理模型作为附加的加权信号

## 导出与同步

### 格式

勾选任意组合的导出格式——每次保存/分享都会把所选的全部格式一起打包进一个 ZIP。若只选一种格式且不含音频片段和 HTML 报告，出于向后兼容，您会得到一个原始文件（例如 `session.csv`）而非 ZIP：

- Raven Selection Table — 用于 Cornell Raven Pro。
- CSV — 可用任意电子表格软件打开。
- JSON — 最便于程序化处理；包含完整的 Session 元数据。
- GPX — 轨迹和途经点，可用于地图工具（仅在开启了 GPS 时才有意义）。

可以这样理解：很多工作流程需要同时用到不止一种格式——CSV 给电子表格，Raven 表给桌面端复核者，JSON 给分析脚本。过去用单格式开关处理这件事，意味着把同一个 Session 导出三遍。现在您一次勾选三项，它们会一起放进 ZIP。

### 包含音频文件

在导出流程支持时，把已保存的音频与导出的表格或元数据一并包含进来。分享单条检测也遵循此设置：完整的 Session 录音会裁剪到该检测精确的开始和结束时间戳，而仅含检测的 Session 会使用其保留的片段。

### 始终以 WAV 分享音频

仅在**包含音频文件**开启时显示。启用后，FLAC 录音会在分享或导出前转换为 WAV。WAV 具有通用兼容性，但比 FLAC 大得多，因此除非接收端的工具无法读取 FLAC，请保持关闭——一些较旧的桌面分析软件和少数上传表单至今仍不支持 FLAC。

### 包含应用元数据

开启后，导出的 ZIP 会带上一个 `*.metadata.json` 附属文件，描述该 Session 是如何产生的：BirdNET Live 版本、模型标识、Session 开始时采集的天气快照，以及录音期间检测到的任何音频完整性警告。可以这样理解：正是这些来源信息，让您（或复核者）在数月之后仍能复现或核查一个 Session。如果您只想干净地分享音频和所选格式，请关闭它——例如把单个 WAV 文件放到 iNaturalist 或 eBird 上，而不夹带任何应用专属文件。

### 包含 HTML 报告

开启后，每个导出的 ZIP 会在表格、音频片段和 GPX 之外，另含一个 `<session>_report.html` 文件。用任意浏览器打开它，您会得到一份可直接打印的 Session 摘要：包含日期、位置、观察者和总计的头部卡片；GPS 轨迹和检测标记的交互式地图；每条检测一张卡片，含 Cornell 分类学缩略图、名称、分数标记、您的确认、您输入的备注，以及以内嵌播放器形式呈现的原始音频片段；还有所用的分析设置。可以这样理解：CSV 很适合分析流水线，却不适合分享给非技术协作者或打印一份简短的野外摘要——HTML 报告一按即可填补这一空白。物种缩略图和地图瓦片在首次打开该文件时需要联网（它们会实时从 BirdNET 分类学 API 和 OpenStreetMap 获取），但其余部分——文字、排版、音频回放、链接——完全可以离线使用。如果您只需要原始数据并希望 ZIP 小上几 KB，请关闭它。

### 仅分享音频

取消勾选所有格式**以及** HTML 报告**以及**应用元数据一项，只保留**包含音频文件**，此时"分享"会把原始录音（例如 `BirdNET_Live_…flac`）交给系统面板，而不是 ZIP。这是把 Session 直接发送到 iNaturalist、eBird 或任何需要未打包音频文件的应用的最省事路径。包含多个检测片段的 Session 仍会生成 ZIP；分享单条检测时会交付这一个原始片段。

## 隐私

本区块控制 **BirdNET Live 可以代表您联系哪些第三方服务**。推理本身完全在您的设备上运行——这些开关只管理可选的网络功能，用于丰富使用体验。全新安装时，三个开关**默认全部关闭**；在您同意之前，不会有任何数据发出。可以这样理解：每个开关都只对应一项具体服务和一项具体收益，因此您可以只选用对自己工作真正有用的部分，其余一概不启用。

### 允许地图瓦片

应用中任何交互式地图（位置选择器、Survey 实时地图和 Session 地图）都需要它。开启后，地图组件会从 **OpenStreetMap** 的公共服务器获取栅格瓦片；瓦片坐标请求会透露您正在查看世界上的哪个区域。瓦片会在本地缓存最多六个月，上限为 6000 块，使重复查看地图保持高效而不会无限增长。开启它同时也会启用**允许地名查询**，因为大多数加载地图的用户也希望 Session 显示可读的地名。您之后可以单独把地名查询再关掉。地图瓦片关闭时，每个地图界面都会退化为占位卡片，因此应用的其余部分仍可使用，且不会有网络外泄。

### 允许地名查询

开启后，应用会把您记录的坐标发送到 **OpenStreetMap 的 Nominatim** 服务，以解析出一个简短地名（例如*"德国柏林"*），显示在 Session 库和 Session 回顾中该 Session 的旁边。可以这样理解：数字坐标虽精确，但在长长的 Session 列表中滚动时难以快速辨认——地名让列表变得一眼可读。关闭时，Session 只显示原始经纬度，且绝不会联系 Nominatim。

### 允许查询天气

开启后，每个保存的 Session 都会通过 **Open-Meteo** 采集一次当地状况快照（温度、降水、风、云量），对应录音坐标和结束时间。该快照会出现在 Session 回顾的位置一行下方，并同步写入 JSON 导出、Session 元数据块和 HTML 报告。可以这样理解：天气是鸟类活动最强的预测因子之一，把它自动记录下来——不必您记着去查另一个应用——能让每个 Session 成为更完整的记录。Open-Meteo 是免费服务，既不需要账号也不需要 API 密钥。关闭时不会获取或存储任何天气数据。Point Count 和 Survey 的设置界面也会在位置控件附近显示一张紧凑的天气卡片：它只在需要时请求该授权，启用后以图标 + 温度 + 风力的形式预览结果，并在保存 Session 时复用同一份缓存快照。

## 危险区域

### 重置引导

在下次启动应用时重新显示引导流程。

### 重置全部设置

把该界面上的每一项偏好恢复为默认值。Session、录音、语音备忘、导出文件和缓存的地图瓦片都不受影响——只有已保存的偏好（滑块、开关、选择项）会被清除。确认后应用会关闭，以便新的默认值在下次启动时生效。

当您不确定是自己拨动了哪个滑块导致出问题，或者要把设备交给别人、希望在不丢失已采集数据的前提下得到一份干净配置时，这很有用。

### 清除全部数据

永久删除 Session、检测、录音、语音备忘、自定义物种列表、已保存的偏好，以及缓存的地图、地名、天气、回放、回顾和分享数据。确认对话框要求输入 `DELETE`，随后关闭应用，使下次启动从干净的本地状态开始。

在把设备交给另一位观察者、退役某台野外手机，或从应用中移除与位置相关的历史记录之前，请使用该功能。请先导出您需要的一切；此操作无法撤销。

# Session 검토

Session 검토는 BirdNET Live가 원시 감지 결과를 편집 가능한 기록으로 바꾸는 곳입니다.

## 들어가는 방법

BirdNET Live는 다음을 완료하면 Session 검토를 자동으로 엽니다:

- Live Mode Session
- Point Count
- Survey
- 파일 분석 실행

저장된 Session은 [Session 목록](session-library.md)에서 언제든 다시 열 수 있습니다.

## 주요 영역

### 요약과 재생

Session 검토는 재생, 스펙트로그램 탐색, 종 목록을 한 화면에 결합합니다. Survey Session의 경우 지도 정보도 함께 표시할 수 있습니다.

화면 상단의 요약 헤더에는 날짜, 위치 칩(위도/경도와, **설정 → 개인정보 → 장소명 조회 허용**이 켜져 있을 때 변환된 장소명), 그리고 녹음 당시 **설정 → 개인정보 → 날씨 조회 허용**이 켜져 있었다면 위치 아래에 Session 종료 시점에 기록된 기상 상태를 보여주는 **날씨 행**이 있습니다. 날씨 행은 날씨 아이콘 뒤에 *"20.1 °C · 약한 비 · 3.2 m/s SW"* 같은 한 줄로 표시됩니다. 행을 누르면 기온, 바람, 강수, 운량이 Open-Meteo 출처 표기와 함께 작은 시트에 펼쳐집니다. 같은 스냅샷이 JSON 내보내기, Session별 메타데이터 블록, HTML 보고서에도 그대로 들어갑니다.

플레이어 위의 스펙트로그램 띠는 상호작용이 가능합니다. 눌러서 이동하고, 한 손가락으로 끌어 타임라인을 훑고, **두 손가락으로 핀치하여** 좁은 시간 구간을 **확대**할 수 있습니다. 겹치는 울음소리의 타이밍을 살피거나 빠른 트릴을 분해해 볼 때 유용합니다. 반대로 손가락을 벌리면 기본 10초 개요로 돌아갑니다. 종 헤더의 재생 버튼은 항상 실제로 녹음된 클립이 있는 첫 클러스터를 선택하므로, 해당 종의 감지 중 하나라도 재생 가능하면 버튼을 사용할 수 있습니다.

### 종 목록

종은 펼칠 수 있는 행으로 묶여 있습니다. 종별로 감지를 살펴보고, 검토하는 동안 녹음 내에서 이동할 수 있습니다. 펼친 종 아래의 클러스터 행은 들여쓰기되어 상위 종 카드와 하위 행이 시각적으로 구분됩니다.

목록 위의 검색 필드는 일반명이나 학명으로 종을 필터링하므로, 100종이 담긴 Session에서 특정 새 한 종을 찾는 데 긴 스크롤 대신 몇 글자만 입력하면 됩니다. 옆의 :app-sort: 버튼은 종의 순서를 바꿉니다:

- **신뢰도 높은 순**(기본값) — 단일 감지 신뢰도가 가장 높은 종이 먼저 옵니다. 가장 확실한 동정 결과를 우선 가려낼 때 좋습니다. 이 모드에서 종을 펼치면 재생 가능한 오디오 클립이 있는 감지가 클립 없는 감지보다 앞에 오고, 그다음 신뢰도 순으로 정렬됩니다.
- **감지 많은 순** — 감지 수가 가장 많은 종이 먼저 옵니다. 가장 활발하게 우는 종을 찾아내기에 좋습니다.
- **가나다순** — 일반명의 사전 순입니다. 예측 가능하고 언어 설정을 따르며, Session에 종이 많을 때 훑어보기 쉽습니다.
- **첫 감지 순** — 첫 감지 시각의 시간순입니다. 예전의 기본값으로, 스펙트로그램 타임라인과 함께 검토할 때 유용합니다.

선택한 정렬 방식은 Session 간에 유지됩니다.

### 종 직접 추가

툴바의 :app-addCircleOutline: 버튼은 BirdNET이 놓친 새를 위한 종 선택기를 엽니다. 검색 결과를 선택해도 바로 추가되지는 않습니다. 먼저 확인 시트가 올라와 선택한 종과 두 개의 체크박스를 보여줍니다:

- :app-hearing: **청취** — 새 소리를 들었습니다.
- :app-visibility: **목격** — 새를 눈으로 보았습니다.

하나만, 둘 다, 또는 아무것도 체크하지 않은 뒤 **추가**를 누르세요. **취소** — 또는 아래로 스와이프 — 하면 검색으로 돌아가므로 잘못 눌러도 아무 손해가 없습니다. **청취**가 기본으로 체크되어 있고 선택은 다음에 추가하는 종에도 이어지므로, 눈으로만 본 새를 연달아 기록할 때는 **목격**을 한 번만 체크하면 됩니다. 둘 다 체크하지 않으면 항목은 "둘 다 아님"이 아니라 관찰 유형 없음으로 저장됩니다.

이 선택은 감지에 저장되며, 해당 감지가 나타나는 모든 곳 — 종 헤더, 클러스터 행, 클립 플레이어 시트, 실시간 Survey 목록 — 에서 직접 추가 배지 옆에 작은 귀 및/또는 눈 기호로 표시됩니다. 내보내기에도 포함됩니다: CSV와 Raven Selection Table의 `Evidence` 열, JSON의 `evidence` 필드, HTML 보고서의 알약형 표시입니다. **종 교체**를 할 때도 같은 시트가 나타나며, 그 기록이 이미 가지고 있던 내용이 미리 채워져 있습니다.

### 감지별 작업

감지가 나타나는 모든 곳 — 종 목록, 클립 플레이어 시트, 실시간 Survey 목록, Survey 지도 마커 — 에서 같은 작업 세트를 사용합니다:

- :app-checkCircleOutline: **확인** — 한 번 누르면 인라인 체크 표시가 붙어 감지가 시각 또는 청각으로 검증되었음을 표시합니다. 확인된 클러스터와 지도 마커에는 작은 녹색 체크가 생겨 한눈에 띄며, 이 표시는 모든 내보내기 형식에 함께 담깁니다.
- :app-moreVert: **더보기** — 다음 항목이 있는 오버플로 메뉴를 엽니다:
    - :app-share: **감지 공유** — 아래 *공유*를 참고하세요.
    - :app-swapHoriz: **종 교체** — 이 감지에 다른 종을 지정합니다.
    - :app-deleteOutline: **감지 삭제** — 행을 즉시 제거합니다. 몇 초 동안 실행 취소 SnackBar가 표시되므로 실수를 되돌릴 수 있습니다. 확인 대화상자는 없습니다.
    - :app-deleteSweep: **종 삭제** — 해당 종의 모든 감지를 Session에서 한 번에 제거하며, 같은 SnackBar 실행 취소를 제공합니다. 종을 펼쳐 클러스터를 하나씩 지우지 않고 잘못 동정된 소음원을 한꺼번에 치울 때 유용합니다.

#### 검토 행의 스와이프 단축 동작

종 목록에서는 행을 가로로 스와이프하여 감지에 대한 작업을 할 수도 있습니다:

- **오른쪽**으로 스와이프 → 삭제(실행 취소 가능)
- **왼쪽**으로 스와이프 → 종 교체 오버레이 열기

두 배경은 색상으로 구분되므로(오류 빨간색 대 기본 파란색) 동작을 완료하기 전에 효과를 미리 알 수 있습니다.

**종 헤더** 행을 (왼쪽이나 오른쪽으로) 스와이프하면 해당 종의 모든 감지가 한 번에 삭제되며, 같은 실행 취소 SnackBar가 표시됩니다. 잘못 동정된 소음으로 가득한 Session을 정리할 때 유용합니다.

### 감지 하나만 공유

:app-share: **감지 공유** 항목은 **설정 → 내보내기 및 동기화**와 같은 선택지를 사용합니다. 선택한 Raven, CSV, JSON, GPX, HTML, 앱 메타데이터 산출물에 해당 감지만 내보냅니다. **오디오 파일 포함**이 켜져 있으면 번들에 감지 오디오도 들어가며, **오디오를 항상 WAV로 공유**도 적용됩니다. 모든 보조 형식, HTML, 앱 메타데이터 옵션이 꺼져 있으면 플랫폼 공유 시트는 ZIP 대신 원본 오디오 클립을 받습니다.

오디오 첨부 파일은 다음 순서로 결정됩니다:

1. **연속 파일 하나로 녹음한 Session의 경우**: 감지의 시작 타임스탬프부터 종료 타임스탬프까지의 오디오를 녹음에서 즉시 잘라냅니다. WAV와 FLAC 연속 녹음을 모두 지원하며, 잘라낸 구간은 원본과 같은 컨테이너로 전달됩니다(WAV 입력 → WAV 출력, FLAC 입력 → FLAC 출력).
2. 그렇지 않으면 감지 자체의 보관된 클립이 디스크에 있을 때 그 클립을 사용합니다.
3. 두 오디오 소스가 모두 없고 내보내기 산출물도 선택되지 않았다면, 종, 신뢰도, UTC 타임스탬프, 위치가 담긴 짧은 텍스트로 대체하여 공유합니다.

### 음성 메모

개별 감지 기록에 짧은 음성 설명을 첨부할 수 있습니다:

- **녹음**: 감지 클러스터의 :app-moreVert: 버튼을 누르고 **음성 메모 녹음**을 선택하여 음성 메모 대화상자를 엽니다. 큰 마이크 버튼을 누르면 녹음이 시작됩니다. 실시간 파형이 목소리를 그대로 반영합니다. 끝나면 중지 버튼을 누르세요.
- **확인**: 녹음이 끝나면 인라인 플레이어로 메모를 들을 수 있습니다. 메모를 교체하려면 **다시 녹음** 버튼을, 저장하려면 **저장** 버튼을 누르세요.
- **삭제**: 감지에 이미 음성 메모가 첨부되어 있으면 오버플로 메뉴나 음성 메모 대화상자에서 삭제할 수 있습니다.
- **플랫폼별 형식**: Android와 기타 플랫폼에서는 음성 메모가 고압축 AAC(`.m4a`) 형식, 16kHz로 녹음됩니다. iOS에서는 앱이 사용 중인 오디오 세션과 CoreAudio 사이의 호환성 문제를 피하기 위해 자동으로 WAV/PCM16 형식(`.wav`)을 사용합니다. 두 형식 모두 내보내기 ZIP 패키징에서 완전히 지원됩니다.
- **내보내기**: Session을 ZIP으로 내보낼 때 음성 메모는 `memos/` 디렉터리에 함께 묶이고, 상대 경로가 JSON과 CSV 메타데이터에 기록됩니다.

### Survey 트랙 지도

Survey Session에는 GPS 트랙과 감지 마커를 보여주는 작은 인라인 지도가 표시됩니다. 인라인 지도의 마커를 누르면 해당 감지에 초점이 맞춰지고 인라인 지도가 그 위치를 중심으로 이동합니다. 인라인 지도 오른쪽 위의 :app-fullscreen: **펼치기** 버튼을 누르면 **전체 화면 지도**가 열립니다. 감지에 초점이 맞춰져 있었다면 전체 화면 지도는 그 감지를 중심으로 확대된 상태로 열리므로 보던 자리를 그대로 이어갈 수 있습니다.

#### 마커 표시 방식

- **신뢰도는 색상으로 표시**되며, 색각 이상에도 안전한 색상 램프를 사용합니다. 낮은 신뢰도에서 높은 신뢰도로 보라-파랑에서 청록/노랑을 거쳐 빨강으로 이어집니다. 램프의 명도가 단조롭게 변하므로 흑백 화면이나 적록 색각 이상 사용자에게도 읽기 쉽습니다.
- **오디오가 있는 감지**는 종 사진 둘레에 색 테두리와 모서리의 재생 배지가 표시됩니다. 누르면 다른 곳에서 쓰는 것과 같은 클립 플레이어 시트가 열리며 확인, 공유, 교체, 삭제를 모두 사용할 수 있습니다.
- **소리 없는 감지**(디스크에 클립 없음)는 더 작고 흐리게, 중립적인 회색 테두리로 표시되어 오디오가 있는 감지가 항상 주된 내용으로 읽힙니다.
- **같은 지점에 겹치는 마커**는 중요도에 따라 층이 정해집니다: 강조됨 > 오디오 있음 > 더 높은 신뢰도 순이므로, 신뢰도가 낮은 소리 없는 마커가 강한 오디오 감지를 가리는 일은 없습니다.
- **줌 레벨 14.5 미만**에서는 실루엣이 신뢰도에 따라 크기가 정해지는 색 점으로 단순화되고, 밀집된 클러스터는 개수 말풍선으로 합쳐집니다(줌 레벨 15에서 클러스터링이 해제됩니다).

#### 필터링

전체 화면 지도에는 지도 오른쪽 위에 고정된 **필터 칩**이 있습니다. 누르면 필터 시트가 열리며, 칩의 레이블은 항상 현재 적용 중인 조건을 보여줍니다(*"모든 종"*, *"오디오 있음"*, *"≥ 80%"*, 또는 단일 종 이름). 사용할 수 있는 필터:

- **모든 감지**(기본값).
- **오디오 클립 있음** — 클립이 아직 디스크에 있어 재생 가능한 감지만 표시합니다.
- **직접 추가** — Session 검토에서 사용자가 직접 추가한 감지만 표시합니다(자동 감지는 제외).

신뢰도 수준으로 감지를 제한할 수도 있습니다. 슬라이더로 신뢰도 하한을 설정합니다(10%에서 시작).

신뢰도 슬라이더 아래에는 지도를 단일 종으로 좁힐 수 있는 **종 제한** 선택기가 있습니다. "경로의 정확히 어디에서 호랑지빠귀 소리를 들었지?" 같은 질문에 답할 때 유용합니다. *모든 종* 항목을 선택하면 종 제한이 해제됩니다. 필터는 조합할 수 있습니다. 예를 들어 *오디오 클립 있음* + *호랑지빠귀* + *> 80%*는 80%를 넘는 점수의 재생 가능한 호랑지빠귀 마커만 표시합니다.

필터가 적용되면 앱 바 제목에 일치 수를 보여주는 부제가 추가됩니다(예: *"감지 7개"*). 시트의 *초기화*를 누르면 기본값으로 돌아갑니다.

## 툴바 아이콘

툴바는 [아이콘과 컨트롤](icons-and-controls.md)에 설명된 것과 같은 아이콘 의미를 사용합니다:

- :app-addCircleOutline: — 내용 추가
- :app-undo: / :app-redo: — 편집 내역을 앞뒤로 이동
- :app-contentCut: — 자르기 모드
- :app-save: — 편집 내용 저장
- :app-share: — 내보내기 또는 공유
- :app-deleteOutline: — Session 삭제
- :app-playArrowRounded: — 해당 동작이 가능할 때 Survey 계속하기

## 내보내기

내보내기 동작은 [설정](settings.md)에서 선택한 옵션에 따라 달라집니다. 앱은 감지와 선택적으로 오디오를 선택한 내보내기 형식으로 패키징할 수 있습니다. 모든 내보내기에는 출처 메타데이터 — 앱 버전, 모델 이름과 버전, 종 이름 언어, 내보내기 타임스탬프, Session과 함께 보관된 설정, 관련 내보내기 옵션 — 가 `<prefix>.metadata.json` 부속 파일(ZIP) 또는 최상위 `meta` 블록(JSON)에 기록되어, 내보낸 결과가 스스로를 설명하고 재현 가능하도록 합니다.

기기가 GPS 측위와 함께 고도를 제공하면 내보내기에는 미터 단위 높이, 사용 가능한 수직 정확도, 기준면, 측위 시각이 포함됩니다. JSON은 이 모두를 관련 좌표와 함께 담고, GPX는 Survey 트랙 포인트와 감지 웨이포인트에 담습니다. CSV와 Raven은 위도와 경도 옆에 `Altitude (m)` 열만 추가합니다. 직접 입력했거나 지도에서 선택한 좌표에는 추정 고도가 없습니다. Survey 검토 중 특정 시각에 추가한 감지는 주변 트랙 포인트 사이를 보간한 위치를 가지며, 자체 측위 시각은 없습니다. 기기 높이는 서로 다른 기준면을 사용할 수 있으므로, 내보낸 `altitudeReference` 필드를 확인한 뒤에만 값을 비교하세요. 기준이 `unknown`이면 플랫폼이 기준면을 식별하지 못했다는 뜻입니다.

JSON 내보내기의 `settings` 블록은 *이 Session에 실제로 적용된* 값 — 민감도, 점수 통합 모드와 통합 구간 수, 마이크 Gain, 고역 통과 차단 주파수 — 을 기록하며, 지금 설정에 우연히 들어 있는 값이 아닙니다. 따라서 몇 달 뒤에 결과를 재현하거나 두 Survey를 비교할 때, 당시 슬라이더가 어디에 있었는지 기억할 필요가 없습니다.

내보내기 파일 이름(`BirdNET_Live_<date>_<time>_…`)과 CSV / JSON 내용 안의 모든 타임스탬프는 휴대전화의 *현재* 현지 시간으로 표시됩니다. 기반 기록은 UTC로 저장되며 내보낼 때 변환됩니다.

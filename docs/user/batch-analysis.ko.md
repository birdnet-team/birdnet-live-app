# 일괄 분석

!!! note "출시 예정"
    이 기능은 개발 중이며 향후 릴리스에서 제공될 예정입니다.

일괄 분석을 사용하면 사용자 지정 분석 매개변수로 여러 오디오 파일(예: USB 리더로 연결한 SD 카드의 파일)을 한 번에 처리하고 분석할 수 있습니다.

## 계획된 기능

- **외부 저장소 접근**: 외부 SD 카드나 USB 드라이브의 폴더를 직접 검색하고 읽습니다.
- **일괄 처리**: 오디오 파일이 든 디렉터리 전체를 한 번의 일괄 실행으로 분석합니다.
- **유연한 내보내기**: 결과를 Raven Selection Table, CSV, TSV, JSON 형식으로 외부 저장소에 직접 저장합니다.
- **Session 서브샘플링**: 데이터베이스가 비대해지는 것을 막기 위해 스마트 서브샘플링 필터를 적용해 결과를 앱 데이터베이스로 가져오는 옵션입니다.

# Widgets Android

BirdNET Live propose deux widgets Android pour un accès rapide depuis l'écran d'accueil et, sur les appareils compatibles, depuis l'écran de verrouillage.

## Disponibilité

- Android uniquement. iOS et Windows n'utilisent pas le même système de widgets.
- Le placement sur l'écran de verrouillage dépend de la version d'Android, du fabricant de l'appareil et de l'hôte de widgets.

## Types de widgets

### BirdNET Live shortcut

Utilisez ce widget pour ouvrir Live Mode en un appui.

- Ouvre l'appli directement en **Live Mode**.
- Démarre toujours l'enregistrement automatiquement dès que le modèle est prêt.
- Si l'onboarding ou l'acceptation des Terms est encore requis, l'appli termine d'abord ce flux, puis ouvre Live Mode et démarre l'enregistrement.

Ce comportement est volontairement différent du réglage normal **Démarrage automatique de l'enregistrement** dans [Paramètres](settings.md) : le widget shortcut est toujours un démarrage rapide.

### BirdNET Live statistics

Utilisez ce widget pour un aperçu rapide des données de session.

- Affiche les détections récentes et les totaux d'espèces des sessions enregistrées.
- Prend en charge un affichage compact ou étendu selon la taille du widget.
- L'affichage étendu inclut un bouton de réglages pour :
  - période : 24 heures, 7 jours ou 30 jours
  - transparence du fond
  - taille de police

Les statistiques se mettent à jour automatiquement quand des sessions sont enregistrées, modifiées ou supprimées.

Si le widget semble vide, terminez puis enregistrez d'abord au moins une session.

## Conseils

- Redimensionnez le widget de statistiques après l'ajout pour basculer entre affichage compact et étendu.
- Placez le widget shortcut près du dock pour des démarrages terrain rapides.
- Utilisez [Bibliothèque de sessions](session-library.md) et [Examen de la séance](session-review.md) pour valider et affiner les détections utilisées par le widget de statistiques.

# Point Count 모드

Point Count 모드는 BirdNET Live에서 정해진 시간 동안 한 지점에 머물러 관찰하는 작업 방식입니다.

## 열기

홈 화면에서 :app-locationOnRounded: 아이콘이 있는 **Point Count 모드** 카드를 누르세요.

## 설정 과정

Point Count 설정은 네 단계로 진행됩니다.

### 1. 관찰 시간과 위치

다음을 선택하세요:

- 관찰 시간 칩 중 하나: 3분, 5분, 10분, 15분, 20분, 25분 또는 30분
- 화면이 꺼진 상태에서도 관찰을 계속할지 여부(기본값은 켜짐)
- :app-myLocation: 버튼으로 현재 GPS 위치 사용
- :app-editLocationAlt: 버튼으로 좌표 직접 입력
- :app-locationOff: 버튼으로 위치 사용 안 함
- :app-mapSheet: 버튼으로 지도에서 지점 선택

시스템 권한 대화상자나 앱 설정에서 돌아오면 설정 화면이 GPS를 새로 고치므로, 새로
허용한 위치 권한은 마법사를 다시 시작하지 않아도 좌표에 반영됩니다. 같은 구역에는
날씨 카드도 있습니다. 날씨 접근이 꺼져 있으면 카드가 **날씨 조회 허용** 동의를
요청하고, 켜면 날씨 아이콘, 기온, 풍속만으로 해당 지점의 날씨를 미리 보여줍니다.
Point Count를 저장할 때는 캐시된 동일한 Open-Meteo 스냅샷이 재사용됩니다.

### 2. 분석 설정

추론 빈도, 신뢰도 임계값, 종 필터 모드 등 이 Session에만 적용할 분석 설정을
선택하세요. 이 값들은 전역 설정에서 시작하지만, 기본값을 바꾸지 않고 이번 관찰에
맞게 조정할 수 있습니다.

| 설정 컨트롤 | 아이콘 |
|---|---|
| 마이크 | :app-micRounded: |
| 녹음 모드 | :app-fiberManualRecordRounded: |
| 클립 여유 구간 | :app-timerOutlined: |
| 추론 빈도 | :app-speedRounded: |
| 신뢰도 임계값 | :app-verifiedRounded: |
| 민감도 | :app-hearing: |
| 종 필터 | :app-filterAltRounded: |

각 컨트롤 옆의 :app-helpOutline: 버튼은 해당 설정의 효과를 설명합니다. 첫 단계의 :app-timerRounded: 관찰 시간 컨트롤과 위치 선택기에도 같은 도움말 버튼이 있습니다.

**전체**를 선택하면 연속 오디오를 저장하고(기본값), **클립**을 선택하면 감지된 울음소리마다 클립을 저장하며, **끔**을 선택하면 오디오를 저장하지 않습니다. 이 선택은 Live Mode의 녹음 설정과 별개이며 다음 Point Count를 위해 기억됩니다. 클립은 Live Mode와 같은 피크 윈도우 선택과 클립 여유 구간을 사용하며, 위치 기반 간소화는 적용되지 않습니다. **클립**을 선택하면 **클립 여유 구간** 슬라이더로 분석된 각 윈도우 앞뒤로 몇 초를 남길지 조절할 수 있으며, 이 값은 Live Mode의 클립 여유 구간 설정도 함께 갱신합니다.

### 3. 현장 팁

이 화면은 시작 전에 점검할 짧은 앱 내 체크리스트를 보여줍니다.

### 4. 준비

준비 화면은 선택한 관찰 시간, 녹음 선택, 화면 꺼짐 시 동작을 요약합니다. :app-playArrowRounded: 버튼을 누르면 관찰이 시작됩니다.

## Point Count 진행 화면

진행 중인 Point Count 화면은 타이머 대시보드가 중심입니다.

### 상단 바

- :app-stopRounded: — Point Count 조기 종료
- :app-timerRounded: — 남은 시간 표시
- :app-helpOutlineRounded: — Point Count 도움말 열기
- :app-tuneRounded: — Point Count 설정 열기

### 주요 표시 항목

- 카운트다운 진행 막대
- 현재 감지, 고유 종 수, 총 감지 수를 보여주는 간단한 정보 막대
- 스펙트로그램 보기
- 감지 목록

## 관찰 종료 후

Point Count 설정에서 **화면 꺼짐 시 계속**이 켜져 있으면, 화면을 잠그거나 화면이 켜진 상태로 다른 앱으로 전환해도 관찰이 계속되며 선택한 시간이 되면 멈춥니다. 카운트다운은 실제 경과 시간을 사용하므로 화면이 꺼져 있어도 관찰 시간이 길어지지 않습니다. Android에서는 열기와 중지 동작이 있는 지속 알림이 표시됩니다. 화면을 잠그거나 다른 앱으로 전환할 때 관찰을 조기 종료하려면 설정에서 이 스위치를 끄세요. Point Count는 정해진 시간의 관찰을 끊지 않도록 일시 정지와 재개를 지원하지 않습니다. 관찰이 아직 시작되는 중에 앱을 벗어나면 관찰이 취소되고 메시지가 표시되므로, 새 관찰을 시작하려면 다시 설정하세요. Windows에서는 창을 최소화해도 관찰이 종료되지 않습니다.

Point Count가 끝나면 BirdNET Live는 [Session 검토](session-review.md)를 엽니다. 자동 저장 설정이 켜져 있으면 Session이 자동으로 저장되고, 그렇지 않으면 보관하려는 Session을 검토 화면에서 저장하세요.

자동 저장이 켜져 있으면 진행 중인 관찰도 시작 시, 30초마다, 그리고 앱이 포그라운드를 벗어날 때 저장됩니다. 비정상 종료나 전원 꺼짐 후에는 마지막으로 저장된 부분 관찰 결과를 Session 목록에서 찾을 수 있습니다.

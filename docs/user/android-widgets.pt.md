# Widgets do Android

O BirdNET Live inclui dois widgets do Android para acesso rápido pela tela inicial e, em dispositivos compatíveis, pela tela de bloqueio.

## Disponibilidade

- Somente Android. iOS e Windows não usam o mesmo sistema de widgets.
- A colocação na tela de bloqueio depende da versão do Android, do fabricante do dispositivo e do host de widgets.

## Tipos de widgets

### BirdNET Live shortcut

Use este widget quando quiser entrar no Live Mode com um toque.

- Abre o app diretamente em **Live Mode**.
- Sempre inicia a gravação automaticamente assim que o modelo estiver pronto.
- Se onboarding ou aceitação dos Terms ainda forem necessários, o app conclui esse fluxo primeiro, depois abre o Live Mode e inicia a gravação.

Esse comportamento é intencionalmente diferente da configuração normal **Iniciar gravação automaticamente** em [Configurações](settings.md): o widget shortcut é sempre de início rápido.

### BirdNET Live statistics

Use este widget para um resumo rápido dos dados de sessão.

- Mostra detecções recentes e totais de espécies de sessões salvas.
- Suporta layout compacto e expandido conforme o tamanho do widget.
- O layout expandido inclui um botão de configurações para:
  - período: 24 horas, 7 dias ou 30 dias
  - transparência do fundo
  - tamanho da fonte

As estatísticas são atualizadas automaticamente quando sessões são salvas, editadas ou excluídas.

Se o widget aparecer vazio, conclua e salve pelo menos uma sessão primeiro.

## Dicas

- Redimensione o widget de estatísticas após adicioná-lo para alternar entre layout compacto e expandido.
- Deixe o widget shortcut perto do dock do telefone para inícios rápidos em campo.
- Use [Biblioteca de Sessões](session-library.md) e [Revisão da sessão](session-review.md) para validar e ajustar detecções usadas no widget de estatísticas.

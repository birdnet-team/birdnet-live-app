# Guide de l'utilisateur

Ce guide présente BirdNET Live comme un outil de travail de terrain : le rôle de chaque écran, la signification des icônes récurrentes et l'effet des paramètres sur le comportement de l'application.

Il s'adresse aux écologues et aux praticiens des relevés ornithologiques qui connaissent déjà les méthodes de terrain et veulent une vue claire de l'application elle-même.

## Commencez ici

### [Mise en route](getting-started.md)

Installation, autorisations, premier lancement et navigation principale sur l'écran d'accueil.

### [Icônes et contrôles](icons-and-controls.md)

Les icônes, boutons, symboles et indicateurs d'état partagés qui apparaissent dans BirdNET Live.

### [Paramètres](settings.md)

Tous les paramètres actuellement exposés dans l'application, regroupés de la même manière que l'écran Paramètres de l'application.

## Ordre de lecture

1. Lisez [Mise en route](getting-started.md).
2. Parcourez [Icônes et contrôles](icons-and-controls.md) pour que les symboles récurrents aient un sens.
3. Ouvrez le guide du mode que vous utilisez le plus souvent.
4. Utilisez [Paramètres](settings.md) lorsque vous devez régler l'application pour un flux de travail différent.

## Astuce mobile

Sur mobile, la barre latérale de navigation est cachée derrière le bouton de menu dans le coin supérieur gauche. Cette page est censée être le point d’entrée mobile pour l’ensemble du guide de l’utilisateur.

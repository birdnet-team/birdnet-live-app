# Widgets de Android

BirdNET Live incluye dos widgets de Android para acceso rápido desde la pantalla de inicio y, en dispositivos compatibles, desde la pantalla de bloqueo.

## Disponibilidad

- Solo Android. iOS y Windows no ofrecen el mismo sistema de widgets.
- La colocación en la pantalla de bloqueo depende de la versión de Android, el fabricante del dispositivo y el host de widgets.

## Tipos de widgets

### BirdNET Live shortcut

Use este widget cuando quiera entrar a Live Mode con un solo toque.

- Abre la app directamente en **Live Mode**.
- Siempre inicia la grabación automáticamente en cuanto el modelo está listo.
- Si todavía se requiere onboarding o aceptar los Terms, la app completa primero ese flujo y luego abre Live Mode e inicia la grabación.

Este comportamiento es intencionalmente distinto del ajuste normal **Inicio automático de la grabación** en [Ajustes](settings.md): el widget shortcut siempre es de inicio rápido.

### BirdNET Live statistics

Use este widget para ver rápidamente datos de sesiones.

- Muestra detecciones recientes y totales de especies de sesiones guardadas.
- Soporta diseño compacto y expandido según el tamaño del widget.
- El diseño expandido incluye un botón de ajustes para:
  - período: 24 horas, 7 días o 30 días
  - transparencia de fondo
  - tamaño de fuente

Las estadísticas se actualizan automáticamente al guardar, editar o eliminar sesiones.

Si el widget aparece vacío, complete y guarde al menos una sesión primero.

## Consejos

- Cambie el tamaño del widget de estadísticas después de colocarlo para alternar entre diseño compacto y expandido.
- Coloque el widget shortcut cerca del dock para inicios rápidos en campo.
- Use [Biblioteca de sesiones](session-library.md) y [Revisión de la sesión](session-review.md) para validar y depurar detecciones que alimentan el widget de estadísticas.

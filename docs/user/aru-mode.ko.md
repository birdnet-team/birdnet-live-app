# ARU 모드

!!! note "초기 구현"
    ARU 모드는 예약된 운용 체크포인트를 저장하고, 예약된 주기를 녹음하고, 활성 주기 동안 실시간 추론을 실행하고, 해당 녹음 모드를 선택한 경우 보존된 감지 클립을 저장하며, Android 포그라운드 알림 컨트롤을 표시합니다. iOS 백그라운드 동작은 아직 현장 검증이 필요합니다.

ARU(Autonomous Recording Unit, 자동 녹음 장치) 모드는 예약된 음향 운용을 위한 고정 지점 작업 방식입니다.

## 현재 설정 과정

- **운용 정보 및 분석 설정**:
    - **메타데이터**: 운용 이름, ARU / 지점 ID, 관찰자 이름을 입력합니다.
    - **위치**: GPS :app-myLocation:, 수동 좌표 :app-editLocationAlt:를 사용하거나 위치를 건너뜁니다 :app-locationOff:. 지도 선택기는 :app-mapSheet:를 사용합니다. 일출·일몰 기준 일정을 사용하려면 위도와 경도가 필요합니다.
    - **분석**: 마이크, 추론 빈도, 신뢰도 임계값, 민감도를 선택합니다.
    - **녹음 형식**: FLAC(무손실 압축)과 WAV(무압축) 중에서 선택합니다.
    - **녹음 모드**:
        - *전체*: 각 활성 주기의 전체 길이를 녹음합니다.
        - *클립*: 감지된 새소리 주변의 짧은 오디오 클립을 저장합니다. 클립 여유 구간(감지 전후에 0~5초의 오디오 버퍼 추가)을 조정하고, 샘플링 방식(*전체*, *상위 N*, 또는 저장 공간 사용을 제한하는 *Smart* 샘플링)을 선택할 수 있습니다.
        - *끔*: 주기 동안 실시간 추론을 실행하고 감지를 기록하지만 오디오 파일은 저장하지 않습니다.
- **일정**:
    - **길이와 반복**: 각 활성 녹음 주기의 길이와 반복 간격을 선택합니다.
    - **녹음 시간대(일주기 패턴)**: 24시간 녹음(*연속*)하거나, 주기를 *주간*이나 *야간*으로 제한하거나, *일출 전후*, *일몰 전후*, *일출·일몰 전후*의 특정 시간대로 제한합니다. 일출/일몰 시간대는 운용 좌표를 기준으로 동적으로 계산됩니다.
    - **운용 종료**: 운용을 직접 중지할지, 정해진 수의 주기를 완료한 뒤 중지할지, 지정한 날짜와 시간에 자동으로 중지할지 선택합니다.
    - **배터리 관리**: 배터리가 완전히 소모되지 않도록 운용을 일시정지하는 저전력 중지 기준(0~50%)을 설정합니다. 설정한 경우 배터리가 회복되면(예: 태양광 충전) 녹음 주기를 자동으로 재개하는 저전력 재개 기준도 설정할 수 있습니다.
    - **테스트 실행**: 선택 사항인 1분 테스트 주기가 기본으로 켜져 있어, 시작 직후 마이크 입력과 추론을 바로 확인할 수 있습니다. 이 주기는 예약된 주기 수에 포함되지 않습니다.
    - **Session 묶기**: 각 주기를 별도 Session으로 저장할지(불러오기가 빠르고 나누어 보기 좋아 권장), 모든 주기를 여러 구간으로 이루어진 하나의 Session으로 합칠지 설정합니다.
- **준비**: 일정, 예상 오디오 저장 공간 사용량, 일주기 제한을 확인한 뒤 운용을 시작합니다.

설정 항목은 다른 마법사와 같은 아이콘을 사용합니다. :app-micRounded: 마이크, :app-speedRounded: 추론 빈도, :app-verifiedRounded: 신뢰도, :app-hearing: 민감도, :app-fiberManualRecordRounded: 녹음 모드, :app-timerOutlined: 클립 여유 구간과 주기 길이, :app-filterAltRounded: 감지 샘플링, :app-formatListNumberedRounded: 종별 클립 한도입니다. 반복 간격은 :app-repeatRounded:, 저전력 항목은 :app-batteryAlert:와 :app-batteryChargingFull:, 테스트 실행과 Session 묶기는 :app-scienceRounded:와 :app-libraryBooks:를 사용합니다. 설정 항목 옆의 :app-helpOutline: 버튼을 누르면 설명을 볼 수 있습니다.

운용을 시작하면 ARU 일정 메타데이터가 담긴 `SessionType.aru` Session이 즉시 저장됩니다. 녹음 주기도 감지가 없는 주기를 포함해 30초마다 체크포인트로 저장됩니다. 충돌이나 전원 차단 후에는 가장 최근의 부분 운용이 종료된 Session으로 Session 목록에 표시되며, 녹음은 자동으로 다시 시작되지 않습니다. 마지막 체크포인트 이후의 작업은 잃을 수 있습니다.

JSON 및 ZIP 내보내기에는 ARU 운용 메타데이터가 포함됩니다. ZIP 내보내기는 저장된 주기별 녹음 파일을 `aru_cycles/` 아래에 묶습니다.

## 운용 진행 화면

진행 중인 ARU 화면은 운용이 대기 중인지, 녹음 중인지, 완료되었는지 표시합니다. 화면은 네 개의 탭으로 구성됩니다.
- **상태**: 현재 운용 상태, 활성 일정 타이머, 실시간 감지 목록을 표시합니다.
- **오디오**: 오디오 입력을 확인할 수 있는 실시간 스크롤 스펙트로그램을 표시하며, 아래에 감지가 계속 보입니다.
- **일정**: 다음 10개의 예약 주기 시각을 나열하고, 일주기 제한이 켜져 있으면 일출/일몰과의 관계를 표시합니다.
- **요약**: 경과 시간, 녹음된 전체 오디오 길이, 감지 통계를 요약합니다.

Android에서는 진행 중인 운용에 "중지"와 "열기" 동작이 있는 포그라운드 알림이 표시됩니다.

운용을 중지하면 Session 검토가 열립니다. 주기를 하나의 Session으로 묶었다면 그 통합 Session이 열리고, 별도 Session으로 저장했다면 가장 최근에 완료된 주기 Session이 열립니다.

iOS에서는 예약 녹음과 백그라운드 동작이 해당 플랫폼에서 검증될 때까지 이 초기 구현을 포그라운드 작업 방식으로 취급하세요.

## 계획 중인 기능

- iOS 백그라운드 동작 검증.
- 여러 파일로 나뉜 ARU 녹음에 대한 Session 검토의 전체 재생 및 스펙트로그램 지원.

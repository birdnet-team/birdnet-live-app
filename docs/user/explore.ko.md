# 탐색

탐색은 BirdNET 지리 모델을 사용해 현재 위치와 계절에 예측되는 종을 보여 줍니다.

## 열기

홈 화면 하단 바의 :app-searchRounded: 버튼으로 **탐색**을 엽니다.

## 앱 바와 헤더

### 앱 바

- :app-refresh: — 위치를 새로 고치고 예측 종 목록을 다시 만듭니다

### 위치 헤더

헤더에는 다음이 표시됩니다:

- 역지오코딩으로 얻은 현재 장소명(가능한 경우)
- 장소명 아래의 좌표
- :app-helpOutlineRounded: — 탐색 도움말 시트 열기

## 종 목록

각 종 카드에는 다음이 포함될 수 있습니다:

- 내장 종 이미지
- 일반명
- 학명(선택)
- 출현 등급 칩

카드를 탭하면 종 상세 정보 오버레이가 열립니다.

### 출현 등급

각 카드는 원시 백분율 대신 현재 장소와 계절에 대한 **출현 등급**을 보여 줍니다. 등급 칩은 두 가지 신호를 결합합니다:

- 종의 출현 가능성이 높아질수록 ⅙에서 전체까지 채워지는 **원**
- 등급 이름의 **첫 글자**(전체 이름은 스크린 리더가 읽어 주며 종 상세 정보 오버레이에도 표시됩니다)

칩 색상은 앱의 공통 점수 색상 체계를 따르며, 등급이 올라갈수록 빨간색(가능성 낮음)에서 녹색(가능성 높음)으로 바뀝니다.

등급은 가능성이 높은 순서로 여섯 가지입니다:

| 등급 | 의미 |
| --- | --- |
| **매우 흔함** | 이곳에서 가장 강하게 예측된 종에 속함 |
| **흔함** | 매우 가능성 높음 |
| **자주 출현** | 가능성 높음 |
| **드문 편** | 가능성 있음 |
| **적음** | 가능성 낮음 |
| **희귀** | 이곳에서 가장 약하게 예측된 종에 속함 |

등급은 **현재 위치를 기준으로 한 상대값**입니다. 지리 모델이 이 지역의 종을 얼마나 강하게 예측하는지에 맞춰 조정되므로, 경계는 지역의 점수 분포에 따라 움직입니다. 확신도 높은 예측이 많은 곳에서는 종이 **매우 흔함**이 되려면 매우 높은 점수가 필요하지만, 예측이 약한 지역에서는 더 낮은 점수로도 같은 등급에 도달합니다. 즉 같은 점수가 장소에 따라 다른 등급에 들어갈 수 있고, 그 덕분에 순위가 어디서나 의미를 유지합니다.

## 종 상세 정보 오버레이

오버레이에는 다음이 표시될 수 있습니다:

- 더 큰 이미지
- 이미지 출처
- 일반명과 학명
- 내장 설명 텍스트(있는 경우)
- 주별 예상 출현 빈도 차트
- 해당 종에 제공되는 경우 eBird, iNaturalist, Wikipedia 등의 외부 링크

## 탐색의 용도

탐색은 앱 안에 있는 위치 기반 참고 화면입니다. 앱이 현재 파악한 위치 정보와 사용자가 마주칠 가능성이 있는 종을 비교하는 데 도움이 됩니다.

탐색 자체는 저장된 Session 데이터를 **변경하지 않습니다**. 감지 필터링은 [설정](settings.md)에서 별도로 제어합니다.

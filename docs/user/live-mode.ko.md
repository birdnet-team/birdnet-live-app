# Live Mode

Live Mode는 휴대전화 마이크로 소리를 듣고 감지 결과를 실시간으로 확인하는 가장 빠른 방법입니다.

## 열기

홈 화면에서 :app-micRounded: 아이콘이 있는 **Live Mode** 카드를 탭합니다.

## Quick Listen

Quick Listen은 앱을 열고 화면을 거치지 않아도 한 번의 동작으로 청취를 시작합니다. 울음이 멎기 전에 동정하고 싶은 소리가 들릴 때 유용합니다. 아래의 모든 진입 경로는 **녹음 자동 시작** 설정과 상관없이 Live Mode를 열고 곧바로 청취를 시작하며, 어느 것도 이 설정을 바꾸지 않습니다.

### Android: 홈 화면 위젯

다른 위젯과 같은 방법으로 추가합니다. 홈 화면의 빈 곳을 길게 누르고 **위젯**을 탭한 뒤 **BirdNET Live**를 찾아 두 타일 중 하나를 끌어다 놓습니다.

- **빠른 청취**(2×1) — 아이콘과 **청취 시작** 라벨
- **빠른 청취 (소형)**(1×1) — 아이콘만

두 타일의 동작은 같습니다.

### iOS: 단축어, Siri, 동작 버튼, 앱 아이콘

BirdNET Live는 **청취 시작** 동작을 시스템에 제공하므로 직접 만들 것이 없습니다.

- **동작 버튼**(iPhone 15 Pro 이상) — **설정 → 동작 버튼**을 열고 **단축어**를 선택한 뒤 BirdNET Live 아래의 **청취 시작**을 고릅니다. 이후 버튼을 길게 누르면 청취가 시작됩니다.
- **Siri** — "BirdNET Live으로 청취 시작", "BirdNET Live으로 새 소리 듣기" 또는 "BirdNET Live으로 새 식별하기"라고 말합니다.
- **단축어 앱** — **청취 시작** 동작이 BirdNET Live 아래에 표시됩니다. 직접 만든 단축어에 넣거나, 그 단축어를 홈 화면에 추가하거나, 뒷면 탭·집중 모드·NFC 태그로 실행할 수 있습니다.
- **앱 아이콘** — 홈 화면에서 BirdNET Live 아이콘을 길게 누르고 **청취 시작**을 탭합니다.
- **URL** — URL을 여는 자동화에서는 `birdnetlive://listen`을 사용할 수 있습니다.

Siri 문구와 동작 버튼 목록 표시는 iOS 17이 필요합니다. 단축어 동작, 앱 아이콘 메뉴, URL은 iOS 16에서도 동작합니다.

### 그 다음에 일어나는 일

Live Mode가 이미 열려 있으면 Quick Listen은 화면을 새로 만들지 않고 그 화면으로 돌아갑니다. 진행 중이거나 일시정지된 Session은 그대로 이어지고, 중지된 상태라면 기존 화면에서 청취를 시작합니다.

Quick Listen은 실행 중인 다른 모드를 절대 대체하지 않습니다. Point Count, Survey, 파일 분석 또는 [ARU 모드](aru-mode.md) Session이 실행 중이거나 시작되고 있으면 앱이 앞으로 나오면서 먼저 그 Session을 중지하도록 요청합니다. 해당 화면과 작업은 그대로 유지되며 중단되지 않습니다.

## 상단 바

상단 바에는 세 가지 요소가 있습니다:

- :app-arrowBackRounded: — Live Mode 나가기
- 가운데 상태 텍스트 — `초기화 중`, `모델 불러오는 중`, `준비됨`, `종 동정 중`, `일시정지됨` 또는 `오류`
- :app-tuneRounded: — Live 전용 설정 화면 열기

## 주 작업 버튼

하단 가운데의 큰 원형 버튼은 상태에 따라 바뀝니다:

- :app-mic: — 청취 시작
- :app-stopRounded: — 진행 중인 Session 중지
- :app-playArrowRounded: — 일시정지 대기 상태에서 재개

## 청취 중에 보이는 것

### 스펙트로그램

오디오를 수집하는 동안 스펙트로그램이 계속 스크롤됩니다. 설정에서 지정한 색상 맵, FFT 크기, 주파수 범위, 표시 시간을 사용해 시간에 따른 주파수 성분을 보여 줍니다.

### 감지 목록

최근 감지가 스펙트로그램 아래에 나타납니다. 각 행에는 다음이 표시될 수 있습니다:

- 종 이미지
- 일반명
- 학명(선택)
- 신뢰도 값

종 행을 탭하면 종 상세 정보 오버레이가 열립니다.

### Session 정보 표시줄

스펙트로그램 아래의 간단한 정보 줄은 현재 Session을 요약합니다. 예:

- 현재 표시 중인 감지
- 고유 종 수(`spp`)
- 총 감지 수(`det`)
- 경과 시간
- 녹음이 켜져 있을 때의 예상 녹음 크기

## 녹음 동작

녹음은 [설정](settings.md)에서 제어합니다.

- **전체**는 Session 전체를 녹음합니다.
- **클립**은 감지 전후의 클립만 녹음합니다.
- **끔**은 녹음하지 않습니다.

Live Mode를 중지하면 BirdNET Live가 Session을 저장하고 [Session 검토](session-review.md)를 엽니다.

Session 자동 저장이 켜져 있으면 Live Mode는 시작 시, 30초마다, 그리고 앱이 백그라운드로 갈 때 부분 Session도 저장합니다. 앱이 비정상 종료되거나 전원이 꺼진 뒤에도 마지막으로 저장된 스냅샷을 Session 목록에서 찾을 수 있습니다. 그 스냅샷 이후의 변경 사항은 사라질 수 있습니다. 자동 저장을 끄면 이 중간 저장도 함께 꺼집니다.

## 화면을 끈 상태로 청취

Live Mode는 보통 화면을 잠그거나 앱을 벗어나면 일시정지되고, 돌아오면 같은 Session을 이어서 진행합니다. 이런 상황이 처음 발생하면 제한된 백그라운드 청취를 제안하는 대화 상자가 나타납니다. [녹음 설정](settings.md)에서 **화면 꺼짐 시 계속**을 켜고 최대 시간을 15분, 30분, 60분 또는 120분 중에서 선택합니다(기본값 30분). 이 시간 제한은 앱을 벗어난 각 구간마다 따로 적용되며, 제한에 도달하면 Session이 종료됩니다. Android에서는 청취가 진행 중임을 알리는 고정 알림이 표시되고 열기와 중지 동작을 제공합니다. Windows에서는 창을 최소화해도 Live Mode가 계속 청취합니다.

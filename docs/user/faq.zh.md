# 常见问题

常见问题解答。

## 概况

**问：BirdNET Live 需要联网吗？**
答：不需要。全部推理都使用 ONNX 模型在设备上完成。唯一的网络功能都是可选的，且默认关闭：来自 OpenStreetMap 的地图瓦片和地名查询、来自 Open-Meteo 的天气快照，以及通过分类学 API 获取的物种图片和描述。参见[设置 → 隐私](settings.md#隐私)。

**问：它能识别多少物种？**
答：BirdNET+ V3.0 模型可识别全球 9,789 个物种——鸟类、两栖动物、哺乳动物和昆虫（音频分类器与地理模型经分类学匹配后的精简交集）。

**问：支持哪些平台？**
答：Android（8.0+）、iOS（15.0+）和 Windows（实验性）。

## 准确度

**问：为什么在我的置信度阈值下分数偏低？**
答：在设置中降低置信度阈值可以看到更多检测。背景噪声、风和距离都会影响准确度。

**问：物种筛选有什么作用？**
答：地理模型会预测在您的 GPS 位置和当前时节哪些物种可能出现。启用**位置筛选**可隐藏不太可能的物种，启用**自适应位置筛选**则只隐藏其中音频模型也不确定的那些，或启用**位置加权**按地理概率对结果加权。

**问：识别有多准确？**
答：准确度取决于录音质量、距离、背景噪声和物种本身。高置信度（>70%）的检测通常比较可靠。罕见物种请务必再做目视确认。

## 录音

**问：录音保存在哪里？**
答：保存在应用文档目录下的 `recordings/<session-id>/`，格式为 WAV 或 FLAC，取决于**设置 → 录音 → 格式**。

**问：可以分析已有的录音吗？**
答：可以。从主界面打开文件分析，选择音频文件，设置位置和参数，然后点按"分析"。支持的格式包括 WAV、FLAC、MP3、OGG、Opus、M4A、AAC、WMA 和 AMR。

## Point Count

**问：什么是 Point Count 模式？**
答：这是用于正规鸟类样点计数的计时调查模式。您设定固定时长（3–20 分钟）和地点，应用随后持续运行，并在计时归零时自动停止。

**问：可以暂停样点计数吗？**
答：不可以。为符合调查规范，录音必须不间断。不过您可以用停止按钮提前结束计数。

**问：样点计数的结果去哪了？**
答：它们会出现在 Session 库中，名称为"Point Count #1"、"#2"等。您可以像处理其他 Session 一样查看、编辑和导出它们。

## 性能

**问：为什么应用发热 / 耗电？**
答：ONNX 模型推理计算量大，而且实时 Session 期间屏幕保持常亮。对于实时神经网络处理来说，这是正常现象。

**问：语谱图看起来卡住了。**
答：请确认已授予麦克风权限且音频采集处于活动状态。检查是否有其他应用正在占用麦克风。

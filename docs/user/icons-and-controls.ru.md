# Значки и элементы управления

Эта страница поясняет повторяющиеся элементы управления и символы, используемые во всём BirdNET Live. Подписи ниже в точности соответствуют тому, что вы видите в приложении.

## Общие элементы навигации

| Элемент | Где встречается | Что делает |
|---|---|---|
| :material-tune: **Настройки** | Нижняя панель главного экрана, Live, Point Count, Survey, Анализ файлов, Просмотр Session | Открывает настройки. На экранах режимов открывает настройки, наиболее уместные для этого рабочего процесса. |
| :material-magnify: **Обзор** | Нижняя панель главного экрана | Открывает режим Обзор. |
| :material-music-box-multiple-outline: **Библиотека** | Нижняя панель главного экрана | Открывает Библиотеку Sessions. |
| :material-help-circle-outline: **Справка** | Нижняя панель главного экрана, заголовок режима Обзор, панель Survey, панель инструментов Просмотра Session | Открывает справку или справочную панель для конкретного экрана. |
| :material-information-outline: **Информация / О приложении** | Нижняя панель главного экрана, информационные строки, справочные панели | Показывает общие сведения или сводный контекст. |
| :material-arrow-left: **Назад** | Режим Live | Возвращает на предыдущий экран. |
| :material-open-in-new: **Открыть внешнюю ссылку** | Экран «О приложении», ссылки на документацию | Открывает внешнюю страницу, например онлайн-руководство пользователя. |
| :material-hand-heart: **Поддержать** | Экран «О приложении» | Открывает страницу пожертвований BirdNET. |

## Символы режима Обзор и видов

| Элемент | Значение |
|---|---|
| Миниатюра вида | Прилагаемое изображение вида, если оно есть. |
| Значок с достоверностью или процентом геомодели | Краткая числовая сводка выхода модели. Более высокие значения означают более сильную поддержку в контексте этого экрана. |
| Подписи месяцев (`янв`, `апр`, `июл`, `окт`, `дек`) | Ориентиры на графике ожидаемой недельной встречаемости в наложении вида. |

## Действия над отдельным обнаружением

Эти элементы встречаются в каждой строке обнаружения в приложении — в списке видов Просмотра Session, в панели проигрывателя фрагментов, в списке обнаружений во время Survey в реальном времени и на маркерах карты Survey. Полное описание поведения смотрите в [Просмотре Session → Действия над отдельным обнаружением](session-review.md#действия-над-отдельным-обнаружением).

| Элемент | Значение |
|---|---|
| :material-check: **Подтвердить** | Галочка в одно нажатие, помечающая обнаружение как проверенное визуально или на слух. Подтверждённые обнаружения получают небольшую зелёную галочку на строках кластеров и маркерах карты. |
| :material-dots-vertical: **Ещё** | Открывает меню обнаружения с пунктами **Поделиться обнаружением**, **Заменить вид**, **Удалить обнаружение** и **Удалить вид**. |
| :material-share-variant: **Поделиться обнаружением** | Отправляет одно обнаружение через системную панель отправки и прикладывает аудиофрагмент, если он доступен, — включая вырезку из идущей записи во время Survey в реальном времени. |
| :material-swap-horizontal: **Заменить вид** | Выбрать другой вид для этого обнаружения. Также открывается смахиванием строки просмотра влево. |
| :material-delete-outline: **Удалить обнаружение** | Немедленно убирает строку. На несколько секунд появляется SnackBar с отменой. Также вызывается смахиванием строки просмотра вправо. |
| :material-delete-sweep-outline: **Удалить вид** | Убирает из Session все обнаружения этого вида сразу, с той же отменой через SnackBar. |
| :material-ear-hearing: **Услышана** | У добавленного вручную обнаружения: птица была услышана. Задаётся флажком в панели подтверждения после выбора вида. |
| :material-eye: **Увидена** | У добавленного вручную обнаружения: птица была увидена. Оба значка вместе означают «услышана *и* увидена». |

| :material-delete-outline: **Удалить** | Отбросить Session. |

## Строки состояния отдельных экранов

### Режим Live

Информационная строка режима Live использует значок :material-information-outline:, за которым следуют компактные подписи, например:

- `now` — обнаружения, видимые сейчас в списке реального времени
- `spp` — число уникальных видов
- `det` — общее число обнаружений
- длительность и предполагаемый размер записи, когда идёт запись

### Point Count

Строка таймера точечного учёта объединяет :material-stop: **Стоп**, :material-timer: **Таймер** и полосу выполнения, чтобы показать, сколько Session осталось.

### Survey

Панель Survey использует:

- :material-map-outline: **Карта** — вкладка карты в реальном времени
- :material-equalizer: **Спектрограмма** — вкладка спектрограммы
- :material-chart-bar: **Сводка** — вкладка сводки
- :material-chart-bar: подписи статистики в сводном представлении Survey

## Если сомневаетесь

Если вы не уверены, что делает тот или иной элемент, откройте ближайшую справочную панель в приложении или посмотрите страницу об этом экране в данном руководстве пользователя.

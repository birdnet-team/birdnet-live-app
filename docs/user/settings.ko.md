# 설정

BirdNET Live는 여러 작업 방식에서 하나의 설정 화면을 함께 사용합니다. :app-tuneRounded: 버튼을 누르면 사용자가 들어온 화면과 관련된 섹션이 열립니다.

설정 항목 옆의 :app-helpOutline: 버튼은 짧은 설명을 열어 줍니다. Point Count, Survey, ARU, 파일 분석 설정 마법사도 같은 버튼을 사용하며, 설정이나 서로 간에 공유하는 컨트롤에는 같은 아이콘을 사용합니다.

## 설정 범위의 동작 방식

- 홈에서 설정을 열면 전체 화면이 표시됩니다.
- Live, Survey, Point Count 또는 파일 분석에서 설정을 열면 관련 섹션만 표시되도록 화면이 필터링됩니다.

## 일반

### 테마

**다크**, **라이트**, **시스템** 중에서 선택합니다.

**다이내믹 컬러**를 켜면 BirdNET Live가 Android 기기의 시스템 색상 팔레트에도 맞추려고 시도합니다. 이 기능은 지원되는 Android 기기에서만 효과가 있으며, iPhone과 iPad에서는 앱이 표준 BirdNET Live 테마를 계속 사용하므로 토글을 켜도 아무것도 바뀌지 않습니다.

**고대비 테마**를 켜면 색조가 들어간 카드 대신 더 굵은 글자와 테두리가 있는 표면을 사용하는 흑백의 라이트 또는 다크 UI 팔레트를 사용합니다. 이 테마는 **다크**, **라이트**, **시스템** 테마 선택을 따르고, 켜져 있는 동안에는 다이내믹 컬러보다 우선하며, 위험·경고·검증·모드·점수·스펙트로그램 색상은 그대로 유지합니다.

### 앱 언어

인터페이스 언어를 설정합니다.

### 종 이름

종 이름에 사용하는 언어를 제어합니다. **시스템**은 해당 이름이 있을 때 휴대폰의 기본 언어를 사용하며, 인터페이스가 영어로 대체되는 경우에도 그렇습니다. **앱 언어 따름**은 대신 인터페이스 언어를 사용합니다.

### 학명 표시

앱 전체에서 일반명 아래에 학명을 표시합니다.

### 감지된 모든 종 표시

Live Mode와 Point Count에만 적용됩니다. 기본값은 꺼짐이므로 이 화면들은 최근 추론 주기에서 감지된 종, 즉 현재 울고 있는 종만 계속 표시합니다. 켜면 진행 중인 Session 동안 감지된 모든 종이 울음을 멈추거나 신뢰도 임계값 아래로 떨어진 뒤에도 목록에 계속 남습니다.

이 설정을 켜면 **종 목록 정렬**이 나타납니다. **최신순**은 현재 울고 있는 종을 현재 신뢰도 순으로 먼저 보여 주고, 그 다음에 유지된 종을 가장 최근 감지 순으로 보여 줍니다. **신뢰도**는 각 종이 Session 중 도달한 최고 신뢰도 순으로, **가나다순**은 현지화된 일반명 순으로, **감지 횟수**는 감지된 횟수 순으로 정렬합니다. 어떤 정렬 모드에서든 신뢰도 백분율과 막대는 해당 종이 현재 울고 있을 때만 표시되며(울음을 멈춘 유지 행은 흐리게 표시), 반복 감지된 종은 일반명 행 끝에 횟수 칩이 표시됩니다.

### 관찰자 이름

Survey, Point Count, ARU 설정은 이 모드들 중 어디에서든 마지막으로 입력한 비어 있지 않은 관찰자 이름을 기억하고, 다음에 현장 Session을 설정할 때 미리 채워 줍니다. 덕분에 개인 현장용 휴대폰에서 반복 사용이 빨라지면서도, Session을 시작하기 전에 관찰자를 수정하거나 지울 수 있습니다.

### ARU/지점 ID

ARU 설정은 마지막으로 입력한 비어 있지 않은 ARU/지점 ID를 기억하고 다음 운용 때 미리 채워 줍니다. ID가 있으면 ARU Session 이름과 내보내기 파일 이름에 포함되므로, 같은 고정 지점에서 반복하는 운용을 앱 밖에서도 구분할 수 있습니다.

### 시간 표시

Session 검토에서 감지별 시간이 어떻게 표시되는지 제어합니다.

- **상대 시간**은 녹음 시작 기준 오프셋을 표시합니다(예: `00:12:34`). 단일 Session을 검토하면서 스펙트로그램 재생 헤드와 맞춰 볼 때 가장 적합합니다.
- **절대 시간**은 감지가 포착된 시점의 현지 시각을 표시합니다(예: `08:42:17`). 현장 노트, 날씨 기록, 동시 녹음과 대조할 때 가장 적합합니다.

감지가 Session 시작과 다른 날짜에 발생하면(예: 야간 Survey) 절대 시간에 `+1d` 접미사가 붙어, 검토하는 사람이 내일 새벽의 합창을 오늘 것으로 잘못 읽지 않도록 합니다.

**절대 시간**을 선택하면 **시간에 초 표시** 토글이 추가로 나타납니다. `08:42:17` 대신 더 간결한 `08:42`를 선호한다면 끄세요. 긴 감지 목록을 훑어볼 때 유용합니다. 상대 오프셋은 스펙트로그램 재생 헤드와 맞추려면 분 단위 이하의 정밀도가 필요하기 때문에 항상 초를 표시합니다.

이 설정과 관계없이 저장과 내보내기는 항상 UTC 시각을 사용하므로, 이 선택은 데이터에 영향을 주지 않고 표시 방식만 바꿉니다.

## 오디오

이 컨트롤들은 오디오 기반의 실시간 작업 방식에서 나타납니다.

### 오디오 입력

하나의 시트에 서로 독립적인 두 컨트롤이 있습니다. **마이크**는 어느 입력에서 녹음할지, **처리 방식**은 휴대폰이 입력 신호를 어느 정도까지 가공해도 되는지를 정합니다. 둘은 자유롭게 조합할 수 있으므로, USB 마이크를 *미처리*로 녹음하는 것도 완전히 유효한 구성입니다. 선택은 앱을 다시 실행해도 유지되며, 같은 선택기가 Survey, Point Count, ARU 설정 화면에도 나타납니다. 변경 사항은 즉시 적용됩니다. 녹음 중에도 앱은 다음 Session을 기다리지 않고 진행 중인 Session 아래에서 마이크를 교체합니다.

**마이크**는 휴대폰이 제공하는 모든 입력을 이름별로 나열합니다. USB, 유선, Bluetooth 마이크와 함께 많은 휴대폰에서는 개별 내장 마이크(예: *하단*, *후면*)도 표시됩니다. Rode Wireless GO나 DJI Mic 같은 무선 마이크 키트는 USB-C 수신기를 통해 연결되므로, 여기에서는 일반 USB 오디오 장치로 나타나며 음질도 그대로입니다.

**처리 방식**이 가장 중요한 부분이며, **Android 전용**입니다. 휴대폰은 마이크가 대부분 통화에 쓰이기 때문에 기본적으로 마이크 오디오에 음성용으로 조정된 DSP, 즉 잡음 제거, 스펙트럼 보정, 자동 Gain을 적용합니다. 이 처리는 새 소리를 억제해야 할 잡음으로 취급하며, 일반적인 설정으로는 끌 수 없습니다. 유일한 방법은 Android에 다른 *오디오 소스*를 요청하는 것입니다.

| 옵션 | 동작 |
|---|---|
| **폰 기본값** | 휴대폰이 평소에 하는 그대로이며, 음성 처리가 포함됩니다. 원래의 동작이자 여전히 기본값이므로 기존 사용자에게는 아무것도 바뀌지 않습니다. |
| **미처리** | 마이크의 원본 신호입니다. 잡음 제거도, 자동 Gain도 없습니다. 보통 새 소리에 가장 좋은 선택입니다. |
| **음성 인식** | 마찬가지로 잡음 제거와 자동 Gain을 끄며, 거의 모든 휴대폰에서 동작합니다. |

**직접 시험해 보고 비교하세요.** 어느 쪽이 나은지는 정말로 기기에 따라 다릅니다. *미처리*가 이상적이지만, Android는 제조사가 지원을 선언한 휴대폰에서만 이를 실제로 적용하며, 나머지 기기에서는 조용히 되돌아가 *시스템 기본값*과 똑같이 들립니다. *음성 인식*이 바로 이를 위한 옵션입니다. Android 호환성 규칙은 이 모드에서 자동 Gain과 잡음 억제를 끄도록 **요구**하므로, *미처리*를 무시하는 휴대폰에서도 처리되지 않은 오디오를 안정적으로 제공합니다. *미처리*로 바꿔도 아무 변화가 없다면 *음성 인식*으로 바꾸세요.

처리되지 않은 옵션은 소리가 **더 작게** 들리는 것이 정상입니다. 자동 Gain이 사라진 결과이며 고장이 아닙니다. 레벨 미터가 낮게 보이면 **Gain**을 올려 보정하세요.

**iOS에서는** 처리 방식 컨트롤이 숨겨지고 시트는 단순한 마이크 목록이 됩니다. iOS는 이미 사실상 처리되지 않은 오디오를 앱에 전달하므로, 여기에서 선택할 만한 것이 없습니다.

### Gain

스펙트로그램과 분류기에 도달하기 전의 입력 오디오에 적용되는 선형 증폭기입니다. 입력이 일관되게 너무 작은 경우가 아니라면 **1.0×**로 두세요. 예를 들어 휴대폰에 연결한 고임피던스 라발리에 마이크나 프리앰프가 너무 낮게 설정된 USB 인터페이스가 그런 경우입니다. Gain을 1.0 이상으로 올려도 마이크가 포착하지 못한 울음소리가 마법처럼 나타나지는 않습니다. 마이크가 전달한 신호의 크기만 다시 조정하므로, 가까운 큰 소리가 클리핑될 수 있습니다. 1.0 미만은 입력이 너무 강해 스펙트로그램이 포화되는 드문 경우에 유용합니다.

### 고역 통과 필터 (Hz)

추론 전에 24dB/옥타브 Butterworth 필터로 저주파 성분을 잘라냅니다. 슬라이더 값이 −3dB 차단 주파수입니다. **0Hz는 필터를 끕니다.** 100–200Hz 차단은 대부분의 종에 영향을 주지 않으면서 바람, 교통 소음, 손으로 쥘 때 나는 잡음을 제거합니다. 500–1000Hz 쪽으로 올리면 낮은 울음소리, 올빼미류, 들꿩류, 알락해오라기의 울림이 제거되기 시작하므로, 소음이 많은 도시 환경에서 훨씬 깨끗한 스펙트로그램을 얻는 대가로 이런 종을 의도적으로 무시할 때만 그렇게 높게 설정하세요. 선택한 차단 주파수는 실시간 스펙트로그램에 선명한 수평선으로 보여야 합니다.

## 추론

### 분석 구간 길이

분석 구간의 길이를 제어합니다. 선택 가능한 단계는 **1**, **3**, **5**, **7**, **10**, **15**초입니다.

### 신뢰도 임계값

감지를 얼마나 보수적으로 받아들일지 설정합니다. 기본값은 **35%**로, 실시간 목록을 더 강한 일치에 집중시키면서도 멀리서 들리거나 일부가 가려진 울음소리를 위한 여지를 남깁니다. 희귀하거나 조용한 종을 조사하면서 나중에 더 많은 후보를 검토할 계획이라면 낮추고, 배경 잡음이나 흔한 오탐이 Session을 가득 채운다면 높이세요.

### 민감도

score pooling, 지리 필터링, 신뢰도 임계값보다 앞서 모델의 원본 확률 점수에 적용되는 x축 오프셋입니다. BirdNET 오디오 모델에는 이미 sigmoid 활성화가 포함되어 있으므로, BirdNET Live는 먼저 각 확률을 logit 공간으로 되돌린 뒤 민감도 편향을 더하고 다시 확률로 변환합니다. 값이 높을수록 감지기가 더 관대해져 더 희미하거나 모호한 울음소리도 임계값을 넘지만, 그 대가로 오탐이 늘어납니다. 값이 낮을수록 더 엄격해져 확실한 감지만 통과시킵니다. 기본값 **1.0**은 오프셋을 적용하지 않으며 BirdNET 참조 구현과 일치합니다. 모델이 멀리서 들리는 울음소리를 놓치는 것 같다면 **1.25**를 시도해 보고, 흔한 종의 저품질 감지가 쏟아진다면 **0.75**로 낮추세요. 민감도는 즉시 적용되므로 Session 중에 변경하면 다음 추론 구간부터 반영됩니다.

### 추론 빈도

BirdNET이 추론을 실행하는 빈도를 제어합니다. 슬라이더는 Survey 및 ARU 설정과 같은 **0.10–1.00Hz** 단계를 사용합니다. 구간은 타이머 완료가 아니라 포착된 오디오 샘플에 고정되므로, 클립을 녹음하거나 모델 호출이 일시적으로 느려져도 이후 구간이 밀리지 않습니다. 추론 설정이 같다면 Live Mode, Point Count, Survey는 같은 구간을 분석하고 같은 감지를 보고합니다. 빈도를 낮추면 모델 연산과 배터리 사용이 줄지만 구간 사이의 간격이 넓어져 매우 짧은 울음소리를 놓치기 쉬워집니다. 새 Survey는 중간값인 **0.70Hz**를 기본으로 사용하고, **0.30Hz**는 배터리를 최대한 아끼는 명시적 옵션으로 남아 있습니다. 파일 분석에는 추론 빈도가 없으며, 대신 [중첩](file-analysis.md) 설정을 사용합니다.

기기가 선택한 빈도를 따라가지 못하면(추론이 여러 구간 연속으로 포착보다 한 홉 전체만큼 뒤처지면) Session이 빈도를 0.30Hz 낮추고, 계속 뒤처질 때마다 다시 낮추어 최저 0.10Hz까지 내립니다. 낮아진 빈도는 곧 모든 모드, 즉 Live Mode, Point Count, Survey, ARU와 그 설정 마법사의 빈도 설정이 되므로, 이후 어디에서 시작하는 Session이든 이 기기가 감당할 수 있는 빈도로 시작합니다. 설정과 마법사는 빈도 슬라이더 아래에 이 기기가 그 빈도 이상에서는 너무 느린 것으로 확인되었다는 안내를 표시합니다. 느린 기기는 계속 느리므로 이 안내는 계속 남아 있으며, 슬라이더는 여전히 자유롭게 조정할 수 있습니다. 이 장치가 없으면 느린 기기에는 처리 대기분이 쌓여 결국 감지 클립을 잘라내는 원본 오디오를 덮어쓰게 되어, 감지에 오디오가 없는 상태가 됩니다.

### 종 무시

이진 추론 필터가 있는 오버레이를 엽니다. **조류**, **포유류**, **양서류**, **곤충**을 체크하면 해당 분류군 전체를 억제합니다. 네 체크박스는 모두 기본적으로 꺼져 있습니다.

**흔한 종 무시 기준** 슬라이더는 **80–100%** 범위에서 움직이며, 현재 지리 모델 점수가 선택한 기준값보다 엄격히 높은 종을 억제합니다. 기본값은 **100%**로, 흔한 정도를 기준으로 어떤 종도 무시하지 않습니다. 값을 낮추면 점점 더 많은 흔한 종을 무시합니다. 오버레이는 현재 위치에 대해 지리 모델을 한 번 실행하고 그 결과로 무시되는 종의 총수를 표시합니다. 슬라이더를 움직이거나 체크박스를 바꾸면 추론을 다시 실행하지 않고 캐시된 예측을 재사용합니다. 흔한 종 규칙에는 위치 기반 지리 모델 결과가 필요하지만, 분류군 필터링은 위치 없이도 동작합니다.

이 필터는 sigmoid 활성화 직후에 지리 모델과 오디오 모델의 확률 모두에 적용됩니다. 무시된 점수는 시간 pooling 전에 정확히 0이 되므로, 이후 pooling 결과에 기여할 수 없고 표시·저장·안내·내보내기되는 감지가 될 수도 없습니다. 진행 중인 Live Mode, Point Count, Survey, ARU Session에서 변경하면 다음 추론 구간부터 적용되고, 파일 분석은 분석을 시작할 때 선택된 값을 사용합니다.

BirdNET Live는 일회성 오탐을 줄이기 위해 내부적으로 최근 추론 구간들의 점수를 평활화합니다. 이 pooling은 사용자 설정으로 노출되지 않으며, 기본값은 최근 다섯 구간과 10초의 실시간 유효 기간 상한을 사용하는 적응형 Log-Mean-Exp pooling입니다. 수락된 감지는 최근에 뒷받침된 모델 신뢰도 중 가장 강한 값을 표시하므로, 뚜렷한 울음소리는 평활화로 눌리지 않고 높은 신뢰도를 그대로 보여 줄 수 있습니다. 이제 모든 모드는 그 pooling 결과를 같은 방식으로 감지로 변환합니다. 감지는 가장 이른 뒷받침 구간에서 시작하고, 뒷받침된 가장 강한 점수를 가지며, 마지막 뒷받침 구간의 끝에서 끝납니다.

## 스펙트로그램

### 크기

Live Mode, Point Count, Survey, ARU에서 실시간 스크롤 스펙트로그램이 화면을 얼마나 차지할지 설정합니다. **전체**가 일반적인 높이입니다. **중간**과 **작게**는 그 높이의 75%와 50%로 줄이고 남는 공간을 감지 목록에 넘겨 줍니다. 세로 모드의 휴대폰에서 주로 목록을 볼 때 선택할 설정입니다. **끔**은 스펙트로그램을 완전히 제거하며, Survey와 ARU에서는 스펙트로그램 탭도 사라집니다. 가로 모드에서는 **중간**과 **작게**가 스펙트로그램을 화면의 절반 안에서 짧게 만들고(그 아래 공간은 당분간 비어 있습니다), **끔**은 화면 전체를 감지 목록에 넘겨 줍니다. Session 검토와 다른 재생 스펙트로그램은 영향을 받지 않습니다.

### FFT 크기

스펙트로그램의 주파수 해상도를 제어합니다.

### 색상표

**Viridis**, **Magma**, **Plasma**, **Cividis**, **Jet**, **Turbo**, **Grayscale**, **BirdNET** 중에서 선택합니다. **Turbo**는 Jet과 비슷한 현대적인 레인보우 옵션입니다.

### 표시 시간 (스크롤 속도)

스펙트로그램 창에 보이는 시간의 길이를 제어합니다.

### 주파수 범위

표시되는 상한 주파수를 설정합니다.

### 로그 진폭

눈으로 읽기 쉽도록 스펙트로그램에 로그 스케일을 적용합니다.

### 품질

스펙트로그램 이미지가 얼마나 부드럽게 스케일링되는지 제어합니다. **중간**이 기본 균형점입니다. 스크롤이 끊기거나 기기가 뜨거워지는 오래된 휴대폰에서는 **낮음**을 선택하고, 더 부드러운 화면을 원하고 기기의 GPU 여유가 충분하다면 **높음**을 선택하세요. 핵심은 이 설정이 렌더링 비용만 바꾸며 오디오 분석이나 감지 결과에는 영향을 주지 않는다는 점입니다.

## 음성 안내

이 섹션은 Session 녹음 중에 BirdNET Live가 **헤드폰이나 휴대폰 스피커로 감지 결과를 소리내어 읽어 줄지**를 제어합니다. 이 기능은 마이크 주변의 음향 환경을 바꾸기 때문에 전체가 **기본적으로 꺼져** 있으며, 켜는 것은 의도적인 선택입니다. 설정 마법사는 없습니다. 아래의 말하는 정도 × 빈도 선택기가 설정의 *전부*이므로, 언제든 다른 프리셋을 눌러 바로 차이를 들어볼 수 있습니다. 핵심은 이렇습니다. 긴 Survey에서는 화면을 계속 들여다볼 수 없는데, 귓가의 조용한 음성이 있으면 시선을 서식지에 둔 채로 방금 무엇이 들렸는지 알 수 있습니다.

### 감지 소리내어 읽기(마스터 토글)

기본값은 꺼짐입니다. 켜면 앱이 기기에 내장된 텍스트 음성 변환으로 수락된 각 감지를 읽어 줍니다. **헤드폰 사용을 강력히 권장합니다.** 휴대폰 스피커를 사용하면 안내가 마이크에 다시 들어가 재감지될 위험이 있으므로, 앱은 이 루프를 막기 위해 각 발화 전후에 녹음기를 잠시 음소거합니다(아래 *말하는 동안 마이크 음소거* 참조).

### 말하는 정도 프리셋

앱이 각 감지에 대해 얼마나 많이 말할지 정합니다. **최소**는 종 이름만 말합니다(신호만 원하는 아주 긴 Survey에 가장 적합). **보통**이 기본값으로, *"꼬까울새"*, *"꼬까울새가 들렸습니다"*, *"다시 꼬까울새"*처럼 짧고 다양한 문구를 사용합니다. **자세히**는 약간의 맥락을 더하며, 누군가 옆에서 해설해 주는 것에 가깝습니다. 고급의 수치를 직접 조정하면 **사용자 지정**이 자동으로 나타납니다. 핵심은, 같은 제한 설정이라도 문구에 따라 너무 조용하거나 너무 수다스럽게 느껴질 수 있다는 점입니다. 말하는 정도를 사용하면 리듬은 유지하면서 말의 양만 조절할 수 있습니다.

### 빈도 프리셋

앱이 말할 수 있는 빈도를 정합니다. 가장 조용한 것부터 가장 수다스러운 것까지 다섯 단계입니다. **드물게**와 **가끔**은 안내 사이에 오래 기다리고 속도에 상한을 두므로, 중계 없이 활동량만 감지하고 싶은 여러 시간짜리 Survey에 알맞습니다. **보통**은 기본적인 대화형 리듬입니다. **자주**는 간격을 줄이고 상한을 높이며, 짧은 Live Session이나 실시간에 가까운 피드백을 원할 때 적합합니다. **계속**은 시작 지연을 완전히 없애고 거의 모든 감지 주기마다 말하게 하므로, 시연, 접근성, 또는 *자주*에서 첫 안내까지의 간격이 너무 길게 느껴질 때 유용합니다. 고급의 타이밍 필드를 변경하면 **사용자 지정**이 나타납니다. 핵심은, 이것이 앱이 배경에 머물지 존재감을 드러낼지를 결정하는 단 하나의 조절기라는 점입니다. 다른 프리셋을 누르면 저장 버튼 없이도 다음 감지 주기 안에 새 리듬을 들을 수 있습니다.

### 음성

음성 행을 누르면 안내 언어용으로 설치된 텍스트 음성 변환 음성 중에서 선택할 수 있고, **기본 음성**을 선택한 채로 두면 기기가 선택합니다. 음성의 가용성과 품질은 운영 체제와 설치된 음성 패키지에 따라 다르며, 기기의 텍스트 음성 변환 설정에서 추가 음성을 설치할 수 있습니다.

**속도**는 0.5×–1.5× 범위이며, 기본값 1.0×는 플랫폼의 "보통" 속도입니다. **음높이**는 0.7×–1.3× 범위입니다. 음높이를 약간 낮추고 속도를 조금 늦추면 바람이나 흐르는 물소리가 배경에 있는 야외에서 안내를 알아듣기 쉬워집니다. *샘플 듣기*는 설정을 벗어나지 않고 선택한 음성, 현재 문구 스타일, 속도, 음높이를 미리 들려 줍니다. 변경 사항은 다음 안내부터 적용됩니다.

### 고급

몇 가지 오디오 라우팅 토글과 트리거 모드 선택기를 보여 주는 펼침 영역입니다. 보통은 열 필요가 없습니다. 위의 말하는 정도와 빈도 프리셋이 일상적으로 중요한 유일한 조절기입니다. 속도 제한 수치(시작 유예, 최소 간격, 분당 최대, 연속 감지 후 침묵, 최근 상태 초기화)는 **빈도** 슬라이더에 묶여 있어, 리듬을 올리거나 내리는 명확한 자리가 하나만 있습니다.

- **폰 스피커 허용** — 꺼져 있으면 헤드폰이나 외부 스피커가 연결되어 있지 않을 때 안내를 조용히 건너뜁니다. 켜면 휴대폰 스피커를 대체 출력으로 사용합니다. 집에서 가볍게 들을 때는 켜고, 현장 작업에서는 마이크로의 음향 피드백을 확실히 막기 위해 꺼 두세요.
- **말하는 동안 마이크 음소거** — 앱이 말하는 동안 입력 오디오를 무음으로 대체하여, 스피커 출력이 마이크에 들어가 재감지되지 않게 합니다. 강력히 권장되며 기본값입니다. 마이크가 휴대폰 스피커와 음향적으로 분리된 경우, 예를 들어 별도 케이블의 클립형 라펠 마이크나 Bluetooth 헤드셋을 사용할 때만 끄세요.
- **다른 오디오 줄이기** — 안내 중에 다른 앱의 음악이나 팟캐스트 볼륨을 잠시 낮추고 이후에 복원합니다. 기본값은 켜짐입니다. 끄면 원래 볼륨 그대로 재생됩니다.
- **말하기 전 알림음** — 각 발화 전에 짧고 조용한 알림음을 재생하여, 수동적으로 듣던 귀가 음성에 주의를 돌릴 시간을 줍니다. 기본값은 켜짐입니다. 안내가 드물거나 배경에 음악이 재생되고 있을 때 특히 유용합니다.
- **안내 대상** — 어떤 감지를 안내 대상으로 삼을지 정합니다. *모든 감지*(기본값)는 속도 제한에 판단을 맡깁니다. *Session당 처음 한 번*은 현재 Session에서 종이 처음 나타날 때만 안내합니다. *관심 목록만*은 안내를 관심 목록에 있는 종으로 제한합니다(우선 분류군만 듣고 나머지는 듣지 않으려는 목표 지향적 Survey 작업에 유용).

## 녹음

### 모드

이 설정은 Live Mode를 제어합니다. Point Count는 설정의 분석 설정 단계에 자체 녹음 선택이 있으며, 새 Point Count는 기본적으로 전체를 사용합니다. Survey도 설정에 별도의 녹음 선택이 있습니다.

- **전체** — 녹음 전체를 저장
- **클립** — 감지 주변의 클립만 저장
- **끔** — 오디오를 녹음하지 않음

### 클립 여유 구간

**클립**이 활성화되면 앱은 각 감지의 **양쪽**에 오디오를 얼마나 보존할지 정하는 **클립 여유 구간** 슬라이더(0–5초) 하나를 표시합니다. Point Count는 설정에서 클립을 선택했을 때 같은 값을 사용하며, 그곳에서 변경할 수 있습니다. 각 클립의 길이는 `분석 구간 + 2 × 클립 여유 구간`이므로, 3초 분석 구간과 기본값 1초 여유 구간이면 저장되는 클립은 5초입니다. 여유 구간을 2초로 설정하면 7초 클립(2초 앞부분 + 3초 분석 오디오 + 2초 뒷부분)이 됩니다. 값이 클수록 시각적 검사나 외부 검토 도구에 쓸 여지가 늘지만 디스크 공간을 더 차지하며, 0은 분석 구간 자체만 저장합니다.

### 형식

**WAV** 또는 **FLAC**을 선택합니다. WAV는 더 크지만 호환성이 넓고 빠르게 확인할 수 있습니다. FLAC은 같은 무손실 음질을 유지하면서 저장 공간을 덜 쓰므로 보통 긴 Session에 더 적합합니다.

이 설정은 BirdNET Live가 녹음한 오디오에 적용됩니다. **파일 분석**은 가져온 파일의 앱 관리 복사본을 원본 형식으로 보관하므로, MP3, AAC, WAV, FLAC 업로드는 추가 변환 없이 검토할 수 있습니다.

### 녹음 자동 시작(Live Mode 전용)

켜면 화면이 열리고 모델 로드가 끝나는 즉시 Live Mode가 녹음을 시작하므로 마이크 버튼을 누를 필요가 없습니다. 키오스크형 설치, 핸즈프리 사용(예: 기기를 현장에 거치), 또는 Live를 여는 것이 늘 "지금 시작"을 뜻한다고 이미 알고 있는 모든 작업 방식에 유용합니다. 홈 화면에서 Live 타일을 실수로 눌렀을 때 Session이 조용히 시작되지 않도록 기본값은 꺼짐입니다. 자동 시작은 화면 방문당 한 번만 동작하므로, Session을 중지한 뒤 마이크를 다시 누르는 수동 재시작은 그대로 동작합니다.

이 설정은 앱 안에서 Live Mode를 열 때에 적용됩니다. [Quick Listen](live-mode.md)(Android 위젯, iOS의 단축어·Siri 문구·앱 아이콘 동작)은 이 설정과 관계없이 실행하면 청취를 시작하며 설정을 바꾸지 않습니다. Point Count, Survey, 파일 분석, ARU 모드 Session이 이미 실행 중이거나 시작 중이면 그 Session을 보존하고 먼저 중지해 달라고 요청합니다.

### 화면 꺼짐 시 계속

**Live Mode**는 화면을 잠그거나 앱을 벗어나면 오디오 포착과 동정을 일시 중지하고, 돌아오면 같은 Session을 재개합니다. 기본값은 꺼짐입니다. 처음으로 이렇게 돌아오면 일회성 대화 상자가 백그라운드 청취를 켜는 방법을 설명합니다. Live Mode 설정에서 스위치를 직접 바꿀 수도 있습니다. 켜면 **최대 백그라운드 시간**을 15, 30, 60, 120분 중에서 선택합니다(기본값 30분). 타이머는 앱이 백그라운드로 들어갈 때 시작됩니다. 만료 전에 앱으로 돌아오면 타이머가 취소되고, 다시 벗어나면 새 타이머가 시작됩니다. 한도에 도달하면 Session이 자동으로 종료되고 중지 사유가 표시된 검토 화면이 열립니다. 완료된 Session을 즉시 보관할지 검토에서 저장되지 않음으로 표시할지는 기존의 자동 저장 설정이 그대로 결정합니다.

**Point Count**는 화면을 잠그거나 화면이 켜진 상태에서 다른 앱으로 전환해도 기본적으로 백그라운드에서 계속 진행되며, 선택한 관찰 시간이 끝나면 종료됩니다. Point Count의 **화면 꺼짐 시 계속** 스위치는 설정의 첫 단계에만 나타납니다. 두 동작 중 어느 쪽이든 Point Count를 조기에 끝내게 하려면 그곳에서 끄세요. 스위치 옆의 물음표가 이 동작을 설명합니다. Point Count는 정해진 시간의 프로토콜에 공백을 만들지 않고는 일시 중지했다가 재개할 수 없습니다. 준비 화면은 시작 전에 이 선택을 요약해 보여 주고, Point Count가 조기에 종료되면 Session 검토에 그 사유가 표시됩니다.

어느 모드든 백그라운드 실행이 허용되어 있는 동안 Android는 열기와 중지 동작이 있는 지속 알림을 표시합니다. 화면은 평소처럼 꺼져도 됩니다. 백그라운드 동작을 시작할 수 없으면 앱을 열어 두세요. 앱이 백그라운드로 가면 Live Mode는 일시 중지되고 Point Count는 종료됩니다. Point Count가 아직 시작 중일 때 앱을 벗어나면 Point Count가 취소되고 그 이유를 설명하는 메시지가 표시되므로, 다시 설정하여 새 Point Count를 시작하세요. Windows에서는 이 스위치들과 관계없이 창을 최소화해도 Live Mode가 일시 중지되거나 Point Count가 종료되지 않습니다.

### Session 자동 저장(Live 및 Point Count)

켜져 있으면(기본값) 완료된 Live 또는 Point Count Session이 끝나는 즉시 라이브러리에 자동으로 추가됩니다. 꺼져 있으면 끝난 Session이 **저장되지 않음** 상태로 검토 화면에 열립니다. 저장 아이콘이 강조 표시되며 Session을 보관하려면 그 아이콘을 눌러야 합니다. 저장하지 않고 검토 화면을 벗어나면 Session과 녹음이 삭제됩니다. 짧은 녹음을 모두 쌓아 두는 대신 가끔 주목할 만한 결과만 남기고 싶은 가벼운 청취 Session에 알맞습니다. Survey와 ARU 운용은 항상 자동으로 저장됩니다. 오랫동안 무인으로 돌린 결과를 저장 버튼을 잊어서 잃기에는 너무 값비싸기 때문이며, 따라서 이 토글은 그곳에는 적용되지 않습니다.

자동 저장이 켜져 있는 동안 Live Mode와 Point Count는 시작 시, 30초마다, 그리고 앱이 포그라운드를 벗어날 때 부분 Session도 저장합니다. 이렇게 하면 충돌이나 전원 끊김 뒤의 데이터 손실이 제한됩니다. 설정이 꺼져 있으면 이 부분 체크포인트는 보관되지 않습니다. Survey와 ARU는 이 설정과 무관하게 체크포인트를 저장합니다.

## 재생

### 검토 시 재생 오버레이

켜져 있으면(기본값) 클립만 있는 Session 검토(전체 오디오 녹음/스펙트로그램이 없는 경우)에서 오디오 클립을 들을 때, 클립을 백그라운드에서 재생하는 대신 재생 컨트롤과 스펙트로그램 미리보기가 있는 전용 모달 플레이어 오버레이가 열립니다. Session에 전체 오디오가 있으면 이 설정은 무시되며 재생 오버레이는 표시되지 않습니다.

### 음성 메모 자동 재생

기본값은 꺼짐입니다. 켜면 시간 지정 주석에 첨부된 음성 메모가 Session 검토 중 재생 헤드가 녹음된 위치를 지나는 순간 자동으로 재생됩니다. 메모는 녹음을 일시 중지하지 않고 녹음 위에 섞여 재생되므로, 원본 오디오와 함께 맥락 속에서 음성 노트를 들을 수 있습니다. 주석 칩을 눌러 메모를 직접 재생하는 쪽을 선호한다면 꺼 두세요.

### 음성 메모 더킹

**음성 메모 자동 재생**이 켜져 있을 때만 표시됩니다. 자동 음성 메모가 재생되는 동안 본 녹음을 얼마나 낮출지 제어합니다. 값이 높을수록 음성 메모가 잘 들리고, 낮을수록 메모 아래로 원본 녹음이 더 많이 들립니다.

## 위치

### GPS 사용

직접 입력한 좌표 대신 기기의 GPS를 사용합니다. Android에서는 위치 정보가 Google Play 서비스가 아닌 플랫폼 위치 제공자에서 오므로, 앱이 Google의 위치 정확도 해결 대화 상자를 띄우지 않습니다. 이 설정을 끄면 앱은 스스로 GPS를 읽거나 위치 권한을 요청하지 않습니다. Survey, Point Count, ARU 설정 마법사는 저장된 좌표로 직접 입력 상태로 열리고, Survey의 GPS 경로 기록은 실행되지 않으며, 오프라인 지도 준비도 그 좌표를 중심으로 합니다.

### 직접 입력 좌표

**GPS 사용**이 꺼져 있을 때 사용하는 좌표입니다. 위도와 경도는 모두 편집 가능한 텍스트 필드이므로 정확한 값을 **입력**하거나 다른 앱에서 복사한 값을 **붙여넣을** 수 있습니다. 터치 화면에서 슬라이더를 끄는 것보다 훨씬 정밀합니다. 십진수 도 단위로 입력하세요(예: `52.5200`과 `13.4050`). `위도, 경도` 형태로 합쳐진 문자열(쉼표, 세미콜론 또는 공백으로 구분)을 *어느 쪽* 필드에든 붙여넣으면 두 필드가 한 번에 채워지는데, 이는 대부분의 지도와 웹사이트가 클립보드에 넣는 형식과 일치합니다. 범위를 벗어나거나 숫자가 아닌 입력은 바로 표시되고 저장되지 않으며, 유효한 값은 입력하는 대로 저장됩니다. 핵심은, 위치를 직접 설정하는 가장 흔한 이유가 지금 있는 곳이 아닌 다른 곳에서 녹음한 소리를 동정하기 위해서이고, 그 위치는 보통 다른 곳에서 텍스트로 전달된다는 점입니다. 입력과 붙여넣기는 이를 정확한 한 단계로 만들어 줍니다. 숫자를 입력하는 대신 지점을 가리키고 싶다면, **지도에서 선택**이 설정 화면에서 사용하는 것과 같은 전체 화면 지도 선택기를 현재 좌표를 기준으로 열고, 누른 위치로 두 필드를 채웁니다.

### 지금 GPS 새로고침

앱이 캐시한 마지막 값을 재사용하는 대신 새 위치 측정을 강제합니다. 핵심은, GPS 조회는 화면별로 캐시되므로 설정 화면을 열 때마다 위성 측위를 기다리며 막히지 않지만, 마지막 Session 이후 차로 새 장소에 이동했다면 그 캐시가 수 킬로미터 어긋나 있을 수 있다는 점입니다. 이동한 뒤 지리 필터가 아침에 출발한 곳이 아니라 *지금 이곳*을 사용하게 하려면 이 항목을 누르세요. 현재 캐시된 좌표가 부제목에 표시되므로 앱이 사용자의 위치를 어디로 인식하는지 확인할 수 있습니다. 약 10초 안에 GPS 측위를 얻지 못하면 앱은 OS가 제공하는 마지막 알려진 위치로 대체하고, 그 값이 오래되었음을 알 수 있도록 스낵바로 경고합니다.

### 오프라인 지도 내려받기

BirdNET Live가 공개 OpenStreetMap 타일 서비스를 사용하는 동안 오프라인 지도 내려받기는 현재 숨겨져 있습니다. OpenStreetMap은 출처 표시, 명확한 user agent, 로컬 캐시를 갖춘 일반적인 대화형 지도 탐색은 허용하지만, `tile.openstreetmap.org`에서의 대량 사전 가져오기나 오프라인 지도 내려받기 기능은 허용하지 않습니다. 내려받기 구현은 오프라인 팩을 명시적으로 허용하는 향후 타일 소스를 위해 보존되어 있습니다.

### 종 필터

- **끔** — 지리 필터링 없음
- **위치 필터** — 지리 임계값 아래의 종을 제외
- **적응형 위치 필터** — 이 지역에서 종이 드물수록 더 높은 신뢰도를 요구
- **위치 가중치** — 지리 모델을 추가 가중 신호로 사용

### 지리 필터 임계값

**위치 필터** 또는 **위치 가중치**가 활성화되면 나타납니다. 적응형 필터는 지역의 종 구성에서 스스로 기준을 산출하므로 슬라이더가 없습니다.

### 적응형 필터의 판단 방식

**탐색** 화면에서 보는 것과 같은 출현 빈도 등급을 사용하여, 사용자의 위치에서 종이 얼마나 흔한지에 따라 기준을 조정합니다. *매우 흔함* 등급의 종은 결코 필터링되지 않으며, 그 아래로는 요구되는 감지 점수가 꾸준히 올라가고, 지역 목록에 전혀 없는 종은 약 0.92 이상이 필요합니다. 0.99 이상의 점수는 위치 모델의 판단과 관계없이 유지됩니다.

| 사용자 위치에서의 등급 | 필요한 감지 점수 |
|---|---|
| 매우 흔함 | 모두 |
| 흔함 | ~0.55–0.70 |
| 자주 출현 | ~0.70–0.82 |
| 드문 편 | ~0.78–0.89 |
| 적음 / 희귀 | ~0.83–0.92 |
| 지역 목록에 없음 | ~0.92–0.97 |

등급은 순위 기반이므로 종이 풍부한 열대림에서도 북극에서도 같은 방식으로 동작합니다. 통과한 감지는 원래 점수를 유지하며, 위치 모델은 표시 여부에만 관여합니다. 목표는 드문 종의 오탐을 줄이면서도 그 종의 진짜 선명한 녹음을 잃지 않는 것입니다.

## 내보내기 및 동기화

이 섹션의 옵션은 모든 공유의 **기본값**입니다. Session, Session 목록의 다중 Session 선택, 또는 단일 감지에서 **공유**를 누르면 먼저 **오디오**와 **메타데이터** 두 상자가 있는 작은 대화 상자가 열리며, 이 설정에 따라 미리 체크되어 있습니다. 오디오는 **오디오 파일 포함**이 켜져 있을 때 켜지고, 메타데이터는 형식 중 하나 이상, HTML 보고서, 또는 앱 메타데이터 파일이 켜져 있을 때 켜집니다. 각 상자에는 `?` 도움말 버튼과 정확히 무엇이 추가되는지 알려 주는 한 줄 부제목(예: "WAV로 변환" 또는 "Raven Selection Table, CSV, HTML 보고서")이 있습니다. 상자를 체크 해제하면 이번 공유에서만 그 부분이 제외되며, 저장된 설정은 바뀌지 않습니다. Session이나 감지에 저장된 오디오가 없으면 오디오는 비활성화되고, 여기서 모든 메타데이터 옵션이 꺼진 상태로 메타데이터를 체크하면 Raven Selection Table로 대체되며, 두 상자가 모두 꺼져 있는 동안에는 공유가 비활성화됩니다. 핵심은, 대부분의 공유는 평소의 묶음을 원하지만 iNaturalist용 WAV 하나만 또는 동료용 표만 담긴 ZIP이 필요한 그 한 번을 위해 설정을 두 번 오가야 할 이유가 없다는 점입니다.

### 형식

내보내기 형식을 원하는 대로 조합하여 체크하세요. 모든 저장/공유는 선택한 형식을 모두 하나의 ZIP 안에 함께 묶습니다. 오디오 클립과 HTML 보고서 없이 형식 하나만 선택하면, 이전 버전과의 호환성을 위해 ZIP 대신 원본 파일(예: `session.csv`)을 얻습니다.

- Raven Selection Table — Cornell Raven Pro에서 사용.
- CSV — 어떤 스프레드시트에서도 열 수 있음.
- JSON — 프로그램 처리에 가장 쉬우며, Session별 전체 메타데이터를 담음.
- GPX — 지도 도구에서 사용할 경로와 웨이포인트(GPS가 켜져 있었을 때만 의미 있음).

핵심은, 많은 작업 흐름이 동시에 둘 이상의 형식을 필요로 한다는 점입니다. 스프레드시트용 CSV, 데스크톱 검토자용 Raven 표, 분석 스크립트용 JSON처럼요. 단일 형식 토글로 이를 해결하려면 같은 Session을 세 번 내보내야 했습니다. 이제는 세 가지를 한 번에 체크하면 ZIP 안에 함께 담깁니다.

### 오디오 파일 포함

내보내기 작업 흐름이 지원하는 경우, 내보낸 표나 메타데이터와 함께 저장된 오디오를 포함합니다. 감지 하나를 공유할 때도 이 설정을 따릅니다. 전체 Session 녹음은 해당 감지의 정확한 시작–종료 타임스탬프로 잘라내고, 클립만 있는 Session은 보존된 클립을 사용합니다.

### 오디오를 항상 WAV로 공유

**오디오 파일 포함**이 켜져 있을 때만 표시됩니다. 켜면 FLAC 녹음을 공유나 내보내기 전에 WAV로 변환합니다. WAV는 어디서나 호환되지만 FLAC보다 훨씬 크므로, 받는 쪽 도구가 FLAC을 읽지 못하는 경우가 아니라면 꺼 두세요. 일부 오래된 데스크톱 분석 소프트웨어와 몇몇 업로드 양식은 아직 FLAC을 읽지 못합니다.

### 앱 메타데이터 포함

켜면 내보내기 ZIP에 Session이 어떻게 만들어졌는지 설명하는 `*.metadata.json` 보조 파일이 들어갑니다. BirdNET Live 버전, 모델 식별 정보, 내보내기에 사용한 기기를 나타내는 읽기 쉬운 `device`와 `os` 필드(예: `"device": "Pixel 10"`, `"os": "Android 17"`), Session 시작 시 포착한 날씨 스냅샷, 녹음 중 감지된 오디오 무결성 경고가 포함됩니다. 기기 ID나 사용자가 지정한 기기 이름은 포함되지 않습니다. 핵심은, 이 출처 정보가 있어야 사용자(또는 검토자)가 몇 달 뒤에도 Session을 재현하거나 검증할 수 있다는 점입니다. 앱 전용 파일을 끼워 넣지 않고 오디오와 선택한 형식만 깔끔하게 공유하고 싶다면, 예를 들어 WAV 하나를 iNaturalist나 eBird에 올릴 때는 꺼 두세요.

### HTML 보고서 포함

켜면 모든 내보내기 ZIP에 표, 오디오 클립, GPX와 함께 `<session>_report.html` 파일도 들어갑니다. 아무 웹 브라우저에서 열면 인쇄하기 좋은 Session 요약을 볼 수 있습니다. 날짜, 위치, 관찰자, 합계가 있는 머리글 카드, GPS 경로와 감지 마커의 대화형 지도, 감지별 카드(Cornell 분류 썸네일, 이름, 점수 표시, 사용자의 확인, 입력한 노트, 원본 오디오 클립을 인라인 플레이어로 제공), 그리고 사용한 분석 설정이 담깁니다. 핵심은, CSV는 분석 파이프라인에는 훌륭하지만 기술에 익숙하지 않은 협업자와 공유하거나 간단한 현장 요약을 인쇄하는 데는 쓸모가 없다는 점입니다. HTML 보고서가 한 번의 탭으로 그 공백을 채웁니다. 종 썸네일과 지도 타일은 파일을 처음 열 때 연결이 필요하지만(BirdNET 분류 API와 OpenStreetMap에서 실시간으로 가져옴), 텍스트, 레이아웃, 오디오 재생, 링크 등 나머지는 모두 오프라인에서 완전히 동작합니다. 원본 데이터만 필요하고 ZIP을 몇 KB라도 작게 유지하고 싶다면 꺼 두세요.

### 오디오만 공유

모든 형식**과** HTML 보고서**와** 앱 메타데이터 상자를 모두 체크 해제하고 **오디오 파일 포함**만 남기면, 공유가 ZIP 대신 원본 녹음(예: `BirdNET_Live_…flac`)을 플랫폼 공유 시트에 넘깁니다. 이것이 Session을 iNaturalist, eBird, 또는 포장되지 않은 오디오 파일을 원하는 다른 앱으로 바로 보내는 가장 간편한 경로입니다. 여러 감지 클립으로 이루어진 Session은 여전히 ZIP을 생성하고, 감지 하나를 공유하면 그 원본 클립 하나를 넘깁니다. 일회성 오디오 전용 공유라면 이 설정을 건드릴 필요가 전혀 없습니다. 대신 공유 대화 상자에서 **메타데이터**를 체크 해제하세요.

### 업로드 대상

완료된 Session을 업로드할 수 있는 WebDAV 저장 위치의 목록입니다. 예를 들어 프로젝트 책임자의 Nextcloud File Drop이나 `tools/webdav_drop_server`의 참조 드롭 서버가 있습니다. 받은 참여 링크나 공유 링크를 붙여 넣거나 카메라로 프로젝트의 QR 코드를 스캔해 추가합니다. 일반 WebDAV 주소에 사용자 이름과 비밀번호를 더해 고급 입력란으로 추가할 수도 있습니다. 연결 테스트를 통과하기 전에는 아무것도 저장되지 않습니다. 대상 화면에는 **참여 코드 표시**도 있어 같은 링크를 QR 코드(및 링크 복사)로 보여 주므로 두 번째 휴대전화가 입력 없이 참여할 수 있습니다. 테스트는 서버의 숨김 폴더 `.birdnet-live`에 기기의 등록 파일을 만들고, 자격 증명으로 폴더 목록까지 볼 수 있는 경우(쓰기 전용 공유가 모두에게 더 안전합니다) 경고하며, 그렇게 목록을 볼 수 있는 공유에 비밀번호가 없으면 추가로 경고합니다. 각 대상에는 고유한 이름, "Wi-Fi에서만 업로드" 스위치, "ARU Sessions 자동 업로드" 스위치가 있습니다. 후자는 완료된 모든 ARU Session을 확인 없이 해당 대상의 대기열에 추가합니다. 업로드하려면 Session이나 Session 라이브러리의 선택 항목에서 공유를 누르고 대화상자의 **보낼 곳** 탭에서 대상을 체크합니다(탭의 배지가 체크 수를 표시하고 목록은 스크롤되므로 대상이 아무리 많아도 대화상자 높이는 같습니다). 그곳에서 공유 시트의 체크를 해제하면 업로드만 할 수 있고, 지난번에 체크한 대상은 다음에 미리 체크되어 있습니다. 대기 중인 업로드는 앱이 열려 있는 동안(Android에서는 적절한 네트워크가 있으면 백그라운드에서도) 실행되고, 점점 긴 간격으로 다시 시도하며, 요청 시 Wi-Fi를 기다리고, Session 라이브러리에서는 Session 제목 아래 첫 줄로, Session 검토에서는 구름 아이콘으로 상태를 표시합니다(누르면 대상별 세부 정보, 지금 다시 시도, 제거를 볼 수 있습니다). 해당 대상이 설정에 하나도 남지 않으면 이 줄은 사라집니다. 각 업로드는 하나의 ZIP 파일로, 공유 내보내기와 같은 이름을 가지며 Session의 JSON 기록과 공유가 포함할 모든 내용을 담아 이 기기의 8자리 코드로 이름 붙은 폴더에 저장됩니다(참여할 때와 대상 목록 맨 위에 **내 업로드 ID**로 표시됩니다). 거기에 이름, 이메일, 참여자 ID 같은 참여자 식별자를 선택적으로 입력할 수 있으며, 이 값은 업로드 메타데이터와 기기 등록에만 들어가고 경로에는 절대 들어가지 않습니다. 같은 Session을 다시 업로드하면 그 파일을 대체합니다. Nextcloud File Drop은 덮어쓰지 않고 이전 복사본을 번호가 붙은 이름으로 보관합니다. 업로드는 한 방향으로만 진행됩니다. 아무것도 다운로드하지 않으며, 기기에서 Session을 삭제해도 서버에서는 절대 삭제되지 않습니다. 자격 증명은 기기의 키체인에 보관되며 내보낸 데이터에는 절대 포함되지 않습니다. 근거: 현장 프로젝트는 여러 휴대전화에서 데이터를 모으는데, 붙여 넣은 링크 하나와 검증된 테스트가 거의 모든 설정 실수를 없애 줍니다. 이슈 #284를 참고하세요.


## 개인정보

이 섹션은 **BirdNET Live가 사용자를 대신해 어떤 제3자 서비스에 접속할 수 있는지**를 제어합니다. 추론 자체는 전적으로 기기에서 실행되며, 이 토글들은 경험을 풍부하게 하는 선택적 네트워크 기능만 관장합니다. 세 토글은 새로 설치하면 모두 **기본적으로 꺼져** 있으며, 사용자가 허용하기 전까지는 아무것도 외부로 접속하지 않습니다. 핵심은, 각 토글이 구체적인 서비스 하나와 구체적인 이점 하나에 한정되어 있으므로 작업에 유용한 것만 정확히 선택하고 나머지는 선택하지 않을 수 있다는 점입니다.

### 지도 타일 허용

앱의 모든 대화형 지도(위치 선택기, Survey 실시간 지도, Session 지도)에 필요합니다. 켜면 지도 위젯이 공개 **OpenStreetMap** 서버에서 래스터 타일을 가져오며, 타일 좌표 요청은 사용자가 세계의 어느 지역을 보고 있는지 드러냅니다. 타일은 최대 6개월 동안 로컬에 캐시되며, 6000개 타일로 상한을 두어 반복해서 지도를 볼 때 효율을 유지하면서 무한히 커지지 않습니다. 이 설정을 켜면 **장소명 조회 허용**도 함께 켜지는데, 지도를 불러오는 대부분의 사용자는 Session에도 읽기 쉬운 장소명이 표시되길 기대하기 때문입니다. 장소명 조회는 별도로 다시 끌 수 있습니다. 지도 타일이 꺼져 있으면 모든 지도 화면이 자리 표시 카드로 대체되므로, 네트워크 유출 없이 앱의 나머지 부분은 계속 동작합니다.

### 장소명 조회 허용

켜면 앱이 녹음한 좌표를 **OpenStreetMap의 Nominatim** 서비스로 보내 짧은 장소명(예: *"독일 베를린"*)을 알아내고, 이를 Session 목록과 Session 검토에서 Session 옆에 표시합니다. 핵심은, 숫자 좌표는 정확하지만 긴 Session 목록을 스크롤하며 훑어보기에는 어렵고, 장소명이 있으면 목록을 한눈에 읽을 수 있다는 점입니다. 꺼져 있으면 Session에는 원본 위도/경도만 표시되며 Nominatim에는 결코 접속하지 않습니다.

### 날씨 조회 허용

켜면 저장되는 모든 Session이 **Open-Meteo**를 통해 녹음 좌표와 종료 시각의 현지 상황(기온, 강수, 바람, 운량) 스냅샷을 한 번 포착합니다. 스냅샷은 Session 검토의 위치 행 아래에 표시되며, JSON 내보내기, Session별 메타데이터 블록, HTML 보고서에도 그대로 반영됩니다. 핵심은, 날씨가 조류 활동의 가장 강력한 예측 변수 중 하나이며, 다른 앱을 따로 확인할 필요 없이 자동으로 기록하면 모든 Session이 더 완전한 기록이 된다는 점입니다. Open-Meteo는 무료 서비스로 계정도 API 키도 필요하지 않습니다. 꺼져 있으면 날씨 데이터를 가져오거나 저장하지 않습니다. Point Count와 Survey 설정도 위치 컨트롤 근처에 간결한 날씨 카드를 표시합니다. 이 카드는 필요할 때만 이 동의를 요청하고, 켜진 뒤에는 결과를 아이콘 + 기온 + 바람으로 미리 보여 주며, Session을 저장할 때 같은 캐시된 스냅샷을 재사용합니다.

## 위험 구역

### 온보딩 초기화

다음에 앱을 실행할 때 온보딩 과정을 다시 표시합니다.

### 모든 설정 초기화

이 화면의 모든 환경 설정을 기본값으로 되돌립니다. Session, 녹음, 음성 메모, 내보내기, 캐시된 지도 타일은 그대로 유지되며, 저장된 환경 설정(슬라이더, 스위치, 선택 항목)만 지워집니다. 확인 후 앱이 종료되어 다음 실행 때 새 기본값이 적용됩니다.

어느 슬라이더를 건드려서 문제가 생겼는지 확실하지 않을 때, 또는 수집한 데이터를 잃지 않으면서 깔끔한 구성으로 기기를 다른 사람에게 넘길 때 유용합니다.

### 모든 데이터 삭제

Session, 감지, 녹음, 음성 메모, 사용자 지정 종 목록, 저장된 환경 설정, 그리고 캐시된 지도·장소명·날씨·재생·검토·공유 데이터를 영구적으로 삭제합니다. 확인 대화 상자에서 `DELETE`를 입력해야 하며, 이후 앱이 종료되어 다음 실행은 깨끗한 로컬 상태에서 시작됩니다.

기기를 다른 관찰자에게 넘기거나 현장용 휴대폰을 퇴역시키거나 위치와 연결된 기록을 앱에서 제거하기 전에 사용하세요. 필요한 것은 먼저 내보내세요. 이 작업은 취소할 수 없습니다.

# 사용자 가이드

이 가이드는 BirdNET Live를 야외 작업 도구로서 설명합니다. 각 화면이 하는 일, 반복해서 등장하는 아이콘의 의미, 그리고 각 설정이 앱의 동작을 어떻게 바꾸는지를 다룹니다.

야외 조사 방법은 이미 알고 있고 앱 자체를 명확히 파악하기만 하면 되는 생태학자와 조류 조사 실무자를 위해 작성되었습니다.

## 여기서 시작하세요

### [시작하기](getting-started.md)

설치, 권한, 첫 실행, 그리고 홈 화면의 주요 메뉴 구성.

### [아이콘과 컨트롤](icons-and-controls.md)

BirdNET Live 전반에 공통으로 쓰이는 아이콘, 버튼, 기호, 상태 표시.

### [설정](settings.md)

현재 앱에서 제공하는 모든 설정을 앱 내 설정 화면과 같은 방식으로 묶어 설명합니다.

## 모드별 가이드

### [Live Mode](live-mode.md)

마이크로 계속 청취하기, 실시간 감지, 스펙트로그램, Session 정보 표시줄.

### [탐색](explore.md)

현재 위치와 계절에 맞게 예측된 종, 그리고 종 상세 정보 오버레이.

### [Session 목록](session-library.md)

저장된 Session, 검색, 정렬, 보기 모드, 종별로 묶어 둘러보기.

### [Session 검토](session-review.md)

재생, 편집, 자르기, 주석, 내보내기, 그리고 검토 화면의 도구 모음.

### [Point Count 모드](point-count-mode.md)

Point Count 설정 절차, 위치 옵션, 실시간 타이머 화면.

### [Survey 모드](survey-mode.md)

Survey 설정, 실시간 Survey 대시보드, 그리고 지도, 스펙트로그램, 요약 탭.

### [파일 분석](file-analysis.md)

4단계 파일 분석 마법사, 매개변수 선택, 그리고 결과가 Session 검토로 넘어가는 과정.

### [일괄 분석](batch-analysis.md)

여러 오디오 파일을 한꺼번에 처리하고 분석합니다. (준비 중)

### [ARU 모드](aru-mode.md)

예약된 ARU 운용 Session을 만들고, 전체 주기 오디오나 보관된 감지 클립을 녹음하고, 활성 주기 동안 실시간 추론을 실행하고, 계획된 녹음 주기를 추적합니다.

### [업로드](uploads.md)

완료된 Session을 프로젝트 폴더로 보내기: Nextcloud File Drop 또는 WebDAV 대상 설정, 참여 링크와 QR 코드, 보낼 곳 탭, 업로드 상태, 그리고 ARU 자동 업로드.

## 참고 자료

### [자주 묻는 질문](faq.md)

오프라인 사용, 녹음 동작, Point Count, 성능에 관한 간단한 답변.

## 읽는 순서

1. [시작하기](getting-started.md)를 읽습니다.
2. 반복해서 등장하는 기호를 이해할 수 있도록 [아이콘과 컨트롤](icons-and-controls.md)을 훑어봅니다.
3. 가장 자주 사용하는 모드의 가이드를 엽니다.
4. 다른 작업 방식에 맞게 앱을 조정해야 할 때 [설정](settings.md)을 참고합니다.

## 모바일 팁

모바일에서는 목차 사이드바가 왼쪽 위의 메뉴 버튼 안에 숨어 있습니다. 이 페이지는 사용자 가이드 전체의 모바일 진입점으로 만들어졌습니다.

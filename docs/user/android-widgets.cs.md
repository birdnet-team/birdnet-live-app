# Widgety Android

BirdNET Live obsahuje dva widgety Android pro rychlý přístup z domovské obrazovky a na podporovaných zařízeních i ze zamykací obrazovky.

## Dostupnost

- Pouze Android. iOS a Windows nepoužívají stejný systém widgetů.
- Umístění na zamykací obrazovce závisí na verzi Androidu, výrobci zařízení a hostiteli widgetů.

## Typy widgetů

### BirdNET Live shortcut

Použijte tento widget pro vstup do Live Mode jedním klepnutím.

- Otevře aplikaci přímo do **Live Mode**.
- Vždy automaticky spustí nahrávání, jakmile je model připraven.
- Pokud je stále potřeba onboarding nebo přijetí Terms, aplikace nejprve dokončí tento tok a potom otevře Live Mode a spustí nahrávání.

Toto chování je záměrně odlišné od běžného nastavení **Automatické spuštění nahrávání** v [Nastavení](settings.md): widget shortcut je vždy rychlý start.

### BirdNET Live statistics

Použijte tento widget pro rychlý přehled dat relací.

- Zobrazuje nedávné detekce a součty druhů z uložených relací.
- Podporuje kompaktní a rozšířené rozložení podle velikosti widgetu.
- V rozšířeném rozložení je tlačítko nastavení pro:
  - časové období: 24 hodin, 7 dní nebo 30 dní
  - průhlednost pozadí
  - velikost písma

Statistiky se automaticky obnovují při uložení, úpravě nebo smazání relací.

Pokud je widget prázdný, nejdříve dokončete a uložte alespoň jednu relaci.

## Tipy

- Po přidání změňte velikost widgetu statistik, abyste přepínali mezi kompaktním a rozšířeným rozložením.
- Umístěte widget shortcut blízko spodní lišty pro rychlé spuštění v terénu.
- Použijte [Knihovna relací](session-library.md) a [Recenze relace](session-review.md) k ověření a úpravě detekcí, které se promítají do widgetu statistik.

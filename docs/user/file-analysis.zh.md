# 文件分析

文件分析用与实时模式相同的 BirdNET 流水线处理已有的录音。

## 如何打开

在主界面点按带 :material-file-music: 图标的**文件分析**卡片。

## 应用栏

- :material-tune: — 打开文件分析设置
- :material-close: — 取消正在进行的分析

## 支持的输入

当前的文件选择器接受：

- WAV / WAVE
- FLAC
- MP3
- OGG / OGA / Opus
- M4A / AAC / MP4
- WMA / AMR

## 四步向导

### 1. 选择文件

选择文件并查看其元数据卡片：

- 文件名
- 格式
- 时长
- 文件大小
- 采样率

### 2. 位置与日期

您可以：

- 使用当前 GPS 位置
- 手动输入坐标
- 跳过位置
- 在地图上选点
- 可选地设置录音日期

### 3. 参数

向导提供：

- 窗口时长
- 重叠
- 灵敏度
- 置信度阈值
- 物种筛选模式

重叠决定每个分析窗口前进多少，它是文件分析特有的设置：整个文件始终都会被检查，重叠越多只是检查得越细。实时模式改用推理频率，因为它们要决定的是对不断到来的音频运行模型的频率，而不是以多细的粒度覆盖一段已经固定的录音。

无论文件分析以何种方式得到它的窗口，它都会用与 Live 模式、Point Count 和 Survey 相同的规则把它们变成检测：一次检测从其最早的支持窗口开始，带有支持范围内最高的分数，并在最后一个支持窗口的末尾结束。

### 4. 分析

进度界面显示：

- 已处理窗口数
- 找到的检测数
- 找到的物种数
- 取消按钮

## 结果

分析完成后，BirdNET Live 会把结果转换为已保存的 Session，并打开 [Session 回顾](session-review.md)。

# FAQ

자주 묻는 질문입니다.

## 일반

**Q: BirdNET Live를 사용하려면 인터넷 연결이 필요합니까?**
A: 아닙니다. 모든 추론은 ONNX 모델을 사용해 기기에서 실행됩니다. 네트워크 기능은 모두 선택 사항이며 기본적으로 꺼져 있습니다. OpenStreetMap의 지도 타일과 지명 조회, Open-Meteo의 날씨 스냅숏, 분류 API의 종 이미지와 설명 조회가 그것입니다. [설정 → 개인정보](settings.md#개인정보)를 참고하세요.

**Q: 몇 종을 동정할 수 있습니까?**
A: BirdNET+ V3.0 모델은 전 세계 9,789종(조류, 양서류, 포유류, 곤충)을 동정합니다. 이는 오디오 분류기와 지리 모델을 분류 체계로 맞춘 뒤 가려낸 교집합입니다.

**Q: 어떤 플랫폼을 지원합니까?**
A: Android(8.0 이상), iOS(15.0 이상), Windows(실험적)를 지원합니다.

## 정확도

**Q: 왜 신뢰도 임계값에서 낮은 점수만 표시됩니까?**
A: 설정에서 신뢰도 임계값을 낮추면 더 많은 감지를 볼 수 있습니다. 배경 잡음, 바람, 거리가 정확도에 영향을 줍니다.

**Q: 종 필터는 무엇을 합니까?**
A: 지리 모델은 사용자의 GPS 위치와 시기에 어떤 종이 나타날 가능성이 높은지 예측합니다. **위치 필터**를 켜면 가능성이 낮은 종을 숨기고, **적응형 위치 필터**를 켜면 그중 오디오 모델도 확신하지 못하는 종만 숨기며, **위치 가중치**를 켜면 지리적 확률로 결과에 가중치를 둡니다.

**Q: 동정은 얼마나 정확합니까?**
A: 정확도는 녹음 품질, 거리, 배경 잡음, 그리고 종에 따라 다릅니다. 신뢰도가 높은 감지(70% 초과)는 일반적으로 신뢰할 수 있습니다. 희귀종은 항상 눈으로 확인하세요.

## 녹음

**Q: 녹음은 어디에 저장됩니까?**
A: 앱 문서 디렉터리의 `recordings/<session-id>/` 아래에 **설정 → 녹음 → 형식**에 따라 WAV 또는 FLAC로 저장됩니다.

**Q: 기존 녹음을 분석할 수 있습니까?**
A: 예. 홈 화면에서 파일 분석을 열고 오디오 파일을 선택한 뒤 위치와 매개변수를 설정하고 "분석"을 누르세요. 지원 형식은 WAV, FLAC, MP3, OGG, Opus, M4A, AAC, WMA, AMR입니다.

## Point Count

**Q: Point Count 모드란 무엇입니까?**
A: 정식 조류 정점 조사를 위한 시간제 조사 모드입니다. 고정 시간(3~30분)과 위치를 설정하면 앱이 계속 실행되다가 타이머가 0이 되면 자동으로 중지합니다.

**Q: Point Count를 일시정지할 수 있습니까?**
A: 아닙니다. 조사 규약을 지키려면 중단 없는 녹음이 필요합니다. 다만 중지 버튼으로 조사를 일찍 끝낼 수는 있습니다.

**Q: Point Count 결과는 어디에 저장됩니까?**
A: Session 목록에 "Point Count #1", "#2" 등으로 표시됩니다. 다른 Session과 마찬가지로 검토, 편집, 내보내기를 할 수 있습니다.

## 성능

**Q: 왜 앱이 뜨거워지고 배터리를 많이 사용합니까?**
A: ONNX 모델 추론은 연산량이 많고, 실시간 Session 중에는 화면이 계속 켜져 있습니다. 실시간 신경망 처리에서는 정상적인 현상입니다.

**Q: 스펙트로그램이 멈춘 것처럼 보입니다.**
A: 마이크 권한이 허용되어 있고 오디오 캡처가 활성 상태인지 확인하세요. 다른 앱이 마이크를 사용하고 있지 않은지 확인하세요.

# Анализ файлов

Анализ файлов обрабатывает уже имеющуюся запись через тот же конвейер BirdNET, который питает режимы реального времени.

## Как его открыть

На главном экране нажмите карточку **Анализ файлов** со значком :app-audioFileRounded:.

### Из другого приложения

Запись также можно передать из другого приложения. В Android отправка аудиофайла в **BirdNET Live** или выбор команды **Открыть с помощью** сразу открывает Анализ файлов. В iOS команда **Открыть с помощью** тоже срабатывает сразу; после использования меню «Поделиться» откройте BirdNET Live или вернитесь в приложение — ожидающая запись будет выбрана автоматически. Перед анализом приложение копирует запись в собственное временное хранилище.

## Панель приложения

- :app-tuneRounded: — открыть настройки анализа файлов
- :app-helpOutlineRounded: — открыть справку по анализу файлов
- :app-close: — отменить идущий анализ

## Поддерживаемые файлы

Текущий выбор файлов принимает:

- WAV / WAVE
- FLAC
- MP3
- OGG / OGA / Opus
- M4A / AAC / MP4
- WMA / AMR

## Мастер из четырёх шагов

### 1. Выбор файла

Выберите файл и просмотрите его карточку метаданных:

- имя файла
- формат
- длительность
- размер файла
- частота дискретизации

### 2. Место и дата

Вы можете:

- использовать текущую позицию GPS :app-myLocation:
- ввести координаты вручную :app-editLocationAlt:
- пропустить местоположение :app-locationOff:
- выбрать точку на карте :app-mapSheet:
- при желании задать дату записи :app-calendarTodayRounded:

### 3. Параметры

Мастер предоставляет:

- длительность окна
- перекрытие
- чувствительность
- порог достоверности
- режим фильтра видов

| Элемент настройки | Значок |
|---|---|
| Длительность окна | :app-timerOutlined: |
| Перекрытие | :app-swapHoriz: |
| Чувствительность | :app-hearing: |
| Порог достоверности | :app-verifiedRounded: |
| Фильтр видов | :app-filterAltRounded: |

Нажмите кнопку :app-helpOutline: рядом с элементом настройки, чтобы увидеть пояснение. Кнопки справки есть и на шагах выбора файла, местоположения и даты записи.

Перекрытие определяет, насколько сдвигается каждое окно анализа, и относится
только к анализу файлов: файл всегда просматривается целиком, а большее
перекрытие лишь просматривает его подробнее. Живые режимы вместо этого
используют частоту вычислений, потому что им нужно решать, как часто
запускаться на поступающем звуке, а не насколько подробно покрыть готовую
запись.

Как бы анализ файлов ни получал свои окна, он превращает их в обнаружения по
тем же правилам, что режим Live, Point Count и Survey: обнаружение начинается
с самого раннего подтверждающего окна, несёт наибольшую подтверждённую оценку
и заканчивается в конце последнего подтверждающего окна.

### 4. Анализ

Экран выполнения показывает:

- обработанные окна
- найденные обнаружения
- найденные виды
- кнопку отмены

## Результат

Когда анализ завершается, BirdNET Live преобразует результат в сохранённую Session и открывает [Просмотр Session](session-review.md).

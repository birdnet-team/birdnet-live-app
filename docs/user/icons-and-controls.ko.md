# 아이콘과 컨트롤

이 페이지는 BirdNET Live 전반에서 반복해서 쓰이는 컨트롤과 기호를 설명합니다. 아래 이름은 앱에 표시되는 것과 정확히 일치합니다.

## 모드 아이콘

앱에서 사용하는 것과 같은 모양의 아이콘입니다. 여기서는 아이콘이 글자색을 따르며, 앱에서는 테마, 다이내믹 컬러, 고대비 설정에 따라 색이 달라집니다.

- :app-micRounded: **Live**
- :app-locationOnRounded: **Point Count**
- :app-routeRounded: **Survey**
- :app-timerRounded: **ARU 모드**
- :app-audioFileRounded: **파일 분석**
- :app-sdStorage: **일괄 분석** (준비 중)

## 감지별 작업

이 컨트롤은 앱의 모든 감지 행에 나타납니다 — Session 검토의 종 목록, 클립 재생 시트, 실시간 Survey 감지 목록, Survey 지도 마커. 전체 동작은 [Session 검토 → 감지별 작업](session-review.md#감지별-작업)을 참고하세요.

| 컨트롤 | 의미 |
|---|---|
| :app-checkCircleOutline: **확인** | 한 번 탭하면 체크 표시가 붙어, 해당 감지를 눈이나 귀로 확인했음을 나타냅니다. 확인된 감지는 묶음 행과 지도 마커에 작은 녹색 체크가 표시됩니다. |
| :app-moreVert: **더보기** | 해당 감지의 추가 메뉴를 엽니다. **감지 공유**, **종 교체**, **감지 삭제**, **종 삭제**가 있습니다. |
| :app-share: **감지 공유** | 플랫폼 공유 시트로 감지 하나를 공유하며, 오디오 클립이 있으면 함께 첨부합니다 — 실시간 Survey 중 진행 중인 녹음에서 잘라낸 구간도 포함됩니다. |
| :app-swapHoriz: **종 교체** | 이 감지에 다른 종을 선택합니다. 검토 행을 왼쪽으로 밀어서도 열 수 있습니다. |
| :app-deleteOutline: **감지 삭제** | 해당 행을 즉시 제거합니다. 몇 초 동안 실행 취소 SnackBar가 표시됩니다. 검토 행을 오른쪽으로 밀어서도 실행됩니다. |
| :app-deleteSweep: **종 삭제** | 해당 종의 모든 감지를 Session에서 한 번에 제거합니다. 같은 SnackBar로 실행 취소할 수 있습니다. |
| :app-hearing: **청취** | 직접 추가한 감지에서: 새 소리를 들었습니다. 종을 선택한 뒤 나타나는 확인 시트의 체크박스로 설정합니다. |
| :app-visibility: **목격** | 직접 추가한 감지에서: 새를 보았습니다. 두 기호가 함께 표시되면 청취*와* 목격을 모두 했다는 뜻입니다. |

## 화면별 상태 표시줄

### Live Mode

Live 정보 표시줄은 :app-infoOutline: 뒤에 다음과 같은 간단한 라벨이 붙습니다:

- `now` — 현재 실시간 목록에 보이는 감지
- `spp` — 고유 종 수
- `det` — 총 감지 수
- 녹음 중일 때의 경과 시간과 예상 녹음 크기

### Point Count

Point Count 타이머 표시줄은 :app-stopRounded: **중지**, :app-timerOutlined: **타이머**, 진행 막대를 함께 보여 주어 시간이 정해진 Session의 남은 부분을 나타냅니다.

### Survey

Survey 대시보드는 다음을 사용합니다:

- :app-map: **지도** — 실시간 지도 탭
- :app-graphicEq: **스펙트로그램** — 스펙트로그램 탭
- :app-summaryChart: **요약** — 요약 탭
- :app-summaryChart: Survey 요약 화면의 통계 라벨

## 잘 모를 때

컨트롤의 동작이 확실하지 않으면 앱에서 가장 가까운 도움말 시트를 열거나, 이 사용자 가이드에서 해당 화면의 작업 흐름 페이지를 확인하세요.

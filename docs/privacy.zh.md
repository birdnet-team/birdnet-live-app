# 隐私政策

**最后更新：** 2026 年 7 月

BirdNET Live 尊重您的隐私。本文档说明本应用如何处理您的数据。

## 设备端处理

所有音频分析和鸟类物种识别**完全在您的设备上**完成。应用使用两个在本地运行的神经网络模型：

- **BirdNET+ 音频分类器** —— 分析麦克风音频以识别鸟类物种。
- **BirdNET 地理模型** —— 预测在您所处的位置和季节可能出现哪些物种。

任何音频数据都不会被传输到外部服务器。

## 数据收集

BirdNET Live **不会**收集、传输或共享任何个人数据。没有分析统计，没有追踪，也没有遥测。

### 存储在您设备本地的数据：

| 数据类型 | 用途 | 存储位置 |
|-----------|---------|---------|
| 音频录音 | 鸟类识别、播放、导出 | 本地文件 |
| 检测结果 | 物种、置信度、时间戳 | 本地 JSON Session 文件 |
| GPS 坐标 | 为检测添加地理标记、Survey 轨迹、地理模型预测 | 本地 JSON Session 文件 |
| Session 元数据 | Session 历史、复核、导出 | 本地 JSON Session 文件 |
| 天气快照（可选） | 开启**允许天气查询**时，每个 Session 记录一次气温、降水、风力、云量和天气代码 | 本地 JSON Session 文件 |
| 应用设置 | 用户偏好 | SharedPreferences |

### 内置离线数据

物种图片、描述和分类数据均**内置于应用中**，从本地资源加载。获取物种信息不会发起任何网络请求。

## 外部资源

应用可能访问以下外部资源。每项资源都由**设置 → 隐私**下的独立开关控制，且在全新安装时**三项全部默认关闭**。在您主动开启之前，没有任何数据会离开您的设备。

| 资源 | 用途 | 由何控制 | 每次请求发送的内容 |
|----------|---------|----------|----------------------|
| 地图瓦片（OpenStreetMap） | 位置选择器、Survey 实时地图和 Session 地图的底图 | **设置 → 隐私 → 允许地图瓦片** | 瓦片坐标 `(z, x, y)` 和 BirdNET Live 的 user-agent 字符串 —— 不含个人身份信息 |
| 反向地理编码（OpenStreetMap Nominatim） | 将 GPS 坐标解析为可读地名（例如“德国柏林”）以便在 Session 中显示 | **设置 → 隐私 → 允许地名查询** | 该 Session 的经纬度，以及 BirdNET Live 的 user-agent 字符串 |
| 天气快照（Open-Meteo） | 一次性获取录音坐标和结束时间处的当地天气状况（气温、降水、风力、云量、WMO 天气代码） | **设置 → 隐私 → 允许天气查询** | 该 Session 的经纬度和结束时间戳，以及 BirdNET Live 的 user-agent 字符串 |

地图瓦片请求是向 `tile.openstreetmap.org` 发起的标准 HTTPS GET 请求，附带 BirdNET Live 的 user-agent 字符串。只发送瓦片坐标 —— 不含任何可识别个人身份的信息。

反向地理编码请求会通过 HTTPS 将该 Session 的经纬度发送至 `nominatim.openstreetmap.org`，并按 [Nominatim 使用政策](https://operations.osmfoundation.org/policies/nominatim/)的要求附带 BirdNET Live 的 user-agent 字符串。解析出的地名会与该 Session 一起保存在本地，因此每个 Session 只会进行一次地理编码。若 Session 没有 GPS 坐标或设备处于离线状态，则不会发起请求。

天气请求会通过 HTTPS 将该 Session 的经纬度和结束时间戳发送至 `api.open-meteo.com`，并附带 BirdNET Live 的 user-agent 字符串。[Open-Meteo](https://open-meteo.com/) 是免费服务，无需账号或 API 密钥。返回的天气快照会与该 Session 一起保存在本地，同时也会写入 JSON 导出文件、每个 Session 的 `metadata.json` 区块以及 HTML 报告。

**数据留存：** 上述第三方服务均不会被用于*上传*或*存储*用户数据。返回的值（地名、天气快照）仅存在于您设备上的本地 Session 记录中，并且只会进入您主动生成的导出文件。

**撤销授权：** 您可以随时在**设置 → 隐私**中停用这三项服务中的任意一项。已保存在本地的地名和天气快照仍会附着在采集它们的 Session 上；如需删除这些历史数据，请在 Session 列表中删除相应 Session，或使用**设置 → 危险操作 → 清除所有数据**。

**不会发起其他任何网络请求。** 本应用可完全离线使用。

## 外部链接

BirdNET Live 包含一些您可以选择打开的第三方网站链接 —— 例如物种的 **eBird**、**iNaturalist** 和**维基百科**页面，物种视图中的*“在 eBird 上聆听该物种”*音频链接，以及**关于**界面中指向 BirdNET 项目网站、源代码、用户指南和捐助页面的链接。会离开应用的链接都标有外部链接图标（↗），便于您在点击前识别。

链接仅被显示时不会发送任何数据，也绝不会自动打开任何外部链接 —— 只有在您点击时浏览器才会启动。点击后，链接会在您设备的默认浏览器中打开，您将离开 BirdNET Live。目标网站由第三方运营，受**其自身**的隐私政策和条款约束，而非本政策。这类网站可能会独立收集有关您访问的信息 —— 例如您的 IP 地址、设备或浏览器详情，以及您与其页面的交互方式 —— 并可能设置自己的 Cookie。我们无法控制外部网站的内容和数据处理方式，也不对此负责；请自行查阅各网站的隐私政策。

## GPS 与位置

应用将 GPS 位置用于：

- **物种筛选** —— 预测在您所在位置可能出现哪些物种。
- **Survey 模式** —— 记录 GPS 轨迹并沿样线为检测添加地理标记。
- **Point Count 模式** —— 标记观察地点。

GPS 数据保存在本地，仅当您主动分享或导出 Session 时才会包含在导出文件中。使用位置需要您的授权，并可随时通过系统设置撤销。

## 数据导出

您可以将 Session 数据导出为多种格式（Raven 选区表、CSV、JSON、GPX），并可在**设置 → 导出 → 格式**中同时勾选任意组合；所选格式会与音频片段以及可选的独立 HTML 报告一起打包进同一个 ZIP 文件。导出文件在本地生成，通过系统分享面板分享。应用不会将导出数据上传到任何服务器。

## 数据删除

单个 Session 及其录音可在 Session 列表中删除。若要在应用内清除 BirdNET Live 的本地 Session、录音、语音备忘、自定义物种列表、偏好设置和缓存，请使用**设置 → 危险操作 → 清除所有数据**。您也可以在操作系统设置中清除 BirdNET Live 的应用存储，或直接卸载本应用。
